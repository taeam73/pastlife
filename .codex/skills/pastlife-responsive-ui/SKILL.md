# 전생록 반응형 UI 필수 규칙

모든 모바일 화면은 휴대폰과 태블릿에서 모두 사용할 수 있어야 한다. 특정 화면 폭에 맞춘 고정 레이아웃을 새로 만들지 않는다.

## 구현 규칙

- 화면 바깥 배경은 viewport 전체를 채운다.
- 본문 콘텐츠는 `width: '100%'`와 적절한 `maxWidth`를 사용해 태블릿에서 중앙 정렬한다.
- 모바일 폭에서 가로 스크롤이 생기지 않도록 한다.
- 터치 대상은 작은 화면에서도 충분한 높이와 간격을 유지한다.
- 텍스트는 고정 폭·고정 줄 수에 의존하지 않고 줄바꿈을 허용한다.
- 질문·결과 로직과 데이터 구조를 변경하지 않고 표현 계층에서 반응형을 해결한다.
- 기존 모바일 화면이 깨지지 않도록 320px 폭을 최소 QA 기준으로 삼는다.

## 검증 규칙

반응형 화면 변경 후 다음을 확인한다.

1. `corepack pnpm --filter @pastlife/mobile typecheck`
2. 모바일 브라우저 E2E
3. 320px 폭에서 가로 오버플로 없음
4. 태블릿 폭에서 콘텐츠 중앙 정렬 및 배경 전체 채움

반응형 검증을 통과하지 못한 화면은 완료로 간주하지 않는다.
