# 76번째 원고·그림 검수 — 「갈대 매듭 두 고리」

- **선행 설정과 근거:** `docs/story-setting-register.md`에 1190년 크메르 제국 앙코르 주변 논, 여성 다라(1154~1214)의 평생을 원고보다 먼저 확정했다. 유네스코의 앙코르 저수지·수로·벼농사 자료, 메트로폴리탄 미술관의 자야바르만 7세 재위·당시 문화 자료를 확인했다. 특정 유적의 수문·토지법·실제 흉작 기록을 재현하지 않는다. 작은 흙 마개, 갈대 매듭, 인물과 가족은 창작이다.
- **01:** 어머니에게 배운 논일, 친구 소마와의 어린 시절, 첸과 결혼·딸 니어의 성장, 농사·노년의 이사까지 세 쪽에 담았다. 성격·취향·가까운 사람·바람·걱정을 짧게 소개한다. 1190년 한 번의 물길 조작으로 전체 인생을 규정하지 않았다.
- **02:** 물이 부족한 밤 흙 마개를 옮김 → 다라 논에 물이 더 흐르고 소마의 모가 마름 → 수로에 있던 키리가 의심받음 → 딸 니어가 두 고리 매듭을 알아봄 → 답변별 장면에서 다라가 행동을 밝히고 물길을 되돌림 → 자기 어린 모·씨를 내주지만 소마의 모와 키리의 신뢰는 바로 돌아오지 않음. 전생록 화자의 도입·마무리, 물의 방향·장면·대화·인과·대가를 검수했다.
- **03·04:** 출생~죽음 14개 이정표에 어린 시절 친구, 결혼·출산, 어머니·남편과의 사별, 딸 독립, 친구와의 둑 수리, 노년 이사가 포함된다. 1190년 다라 36세·니어 14세, 1206년 다라 52세, 1214년 60세를 맞췄다. 첸·니어·소마의 평가는 서로 다른 관계를 보여 준다.
- **그림:** 고유 앙코르 인근 논·수로 배경 **1254×1254**와 다라 **1024×1536** 실제 투명 WebP를 API·모바일에 연결했다. 첫 인물 생성본은 1290×1219의 가로형이라 규격 검사에서 탈락해 새 세로형으로 교체했다. 젖은 흙 마개·두 논·어린 모와 농부의 소박한 복식이 원고에 맞는다. 생성본의 미세한 가장자리 잔색은 실제 합성 스크린샷에서 눈에 띄지 않았다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 76쌍 그림·투명도·매핑 검사, 다양성 4개, 콘텐츠 37개와 점수 13개, API E2E 2개 통과. Playwright `e2e/mobile-one-reed-knot.spec.ts`가 독립 서버에서 320×720·768×1024의 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침을 검사해 통과했다. 두 폭의 첫 결과 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않는다.
