# 75번째 원고·그림 검수 — 「기울어지는 소리」

- **선행 설정과 근거:** `docs/story-setting-register.md`에 1962년 독립 국가 자메이카 킹스턴, 남성 에즈라(1921~1998)의 출생~사망 생애를 집필 전에 기록했다. 자메이카 국립도서관의 독립 기념 행사·1960년대 사운드 시스템과 스카 자료, 미국 의회도서관의 시대 음악 자료를 확인했다. 특정 공식 행사·실존 연주자·스피커 사고는 재현하지 않는다. 인물·가족·동네 춤자리·고장·금전 관계는 창작이다.
- **01:** 아버지에게 배운 목수 일, 라이오넬과 가구 수리, 조이·마커스와 가족, 음향 장비 제작, 손의 통증과 노년을 세 쪽에 요약했다. 성격·취향·바람·걱정은 항목별로 간결하게 담았다. 1962년 실수 하나로 평생을 정의하지 않았다.
- **02:** 목재 받침의 작은 금 발견 → 납기 때문에 그대로 설치 → 스카 음악 중 받침이 벌어지고 아이들이 가까이 감 → 답변별로 금을 확인하거나 공개해서 말하거나 동료·아들과 함께 음악을 멈추고 스피커를 내림 → 마벨에게 비용 일부를 돌려주고 예약을 잃음 → 작은 장비로 늦게 춤이 재개됨. 전생록 도입·마무리, 장면·대화·선택·대가가 있다. 멈춘 시간이 돌아오지 않고 아들 앞에서의 실수도 남는다.
- **03·04:** 출생~사망의 16개 사건에 어린 시절 일, 친구, 결혼·아들, 모친 사별·부친 돌봄, 아들의 다른 진로, 손주, 관절 통증, 배우자 사별과 이사가 포함된다. 1962년 에즈라 41세·마커스 15세, 1986년 65세, 1998년 77세로 맞췄다. 조이·마커스·라이오넬이 서로 다른 면을 기억한다.
- **그림:** 고유 킹스턴 동네 춤자리 배경 **1254×1254**와 에즈라 **1024×1536** 실제 투명 WebP를 API·모바일에 연결했다. 1960년대 목재 사운드 시스템, 검정·초록·금색 장식, 에즈라의 수평자와 작업복이 원고에 맞는다. 실제 동네 행사나 건물의 사진 복제는 아니다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 75쌍 그림·투명도·매핑 검사, 다양성 4개, 콘텐츠 37개와 점수 13개, API E2E 2개 통과. 첫 브라우저 실행에서 결과 화면 한 줄 소개가 80자 제한을 넘어 실패해 뜻을 보존하며 줄였다. 재실행한 Playwright `e2e/mobile-swaying-speaker.spec.ts`가 독립 서버에서 320×720·768×1024의 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침을 검사해 통과했다. 두 폭의 첫 결과 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않는다.
