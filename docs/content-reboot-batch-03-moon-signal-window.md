# 승격 원고: MOON_SIGNAL_WINDOW — 화면 밖의 첫걸음

상태(2026-10-22): **라이브 31/120편 중 하나**. 설정은 `docs/story-setting-register.md`에 집필 전에 기록했다. 고유 배경·투명 인물, 정적 매핑, 도달성, 320px·768px 화면 검사를 통과했다.

## 사실과 창작

- 확인한 사실: 아폴로 11의 첫 달 표면 발자국은 호주 동부 표준시 **1969년 7월 21일 낮 12시 56분**에 생중계됐다. 첫 화면은 허니서클크리크 지상국이 받았고, 약 **8분 30초 뒤** 파크스 관측소가 받은 화면이 선택됐다. [CSIRO 파크스 기록](https://www.csiro.au/en/about/facilities-collections/ATNF/Parkes-radio-telescope-Murriyang/Apollo-11-Moon-landing), [NASA 통신망 역사](https://www.nasa.gov/communicating-with-missions/history-of-the-networks/). 확인일 2026-10-22.
- 창작한 것: 메이, 파크스 마을의 수리점·회관, 화면 고장, 전시용 수상기 운반, 손상과 판매 연기는 모두 이 원고를 위한 허구다. 메이는 관측소 안으로 들어가거나 역사적 중계 경로를 바꾸지 않는다.

## 답변 행동 연결 후보

| 신호 | 결과에 보일 구체적 행동 |
| --- | --- |
| notice | 메이는 소리가 들려도 화면이 한 줄뿐이고 안쪽에서 열 냄새가 나는 것을 확인해, 회관 수상기의 전원을 먼저 껐다. |
| repair | 고칠 부품이 없는 것을 알고, 가게의 전시용 수상기를 옮겨 다시 연결했다. 다음 날 탄 부품도 꺼내 확인했다. |
| connect | 혼자 볼 수 있던 전시용 수상기를 회관으로 가져가 수상기가 없는 이웃과 함께 볼 자리를 만들었다. |

## 편집 점검

- 흥미: 방송이 시작될 때 화면이 선 하나로 접히는 문제를 첫 문장에 둔다.
- 재미: 우주 신호의 거대한 이동과 동네 수상기 한 대를 손수레로 옮기는 작은 소동을 병치한다.
- 공감: 함께 보도록 돕는 선택에 실제 손상과 판매 연기가 따른다. 주인공은 첫발을 못 봤다는 아쉬움을 지우지 않는다.
- 사실 검토: 첫발 당시 파크스 관측소 화면이 쓰였다고 쓰지 않는다. 수상기 결함의 구체적 전자 원인은 후속 검증 전까지 단정하지 않는다.
- 그림 검수: 1254×1254 배경 `moon-signal-parkes-hall-bg.jpg`는 낮빛이 드는 빈 회관에 꺼진 수상기, 손수레 위 켜진 수상기와 케이블을 둔다. 1024×1536 `moon-signal-may.webp`는 실제 알파가 있는 40대 여성 수리공 한 명이며 짧은 곱슬머리, 갈색 작업 재킷, 공구 가방과 케이블이 앞선 해안 구조대원·전당포 주인과 구별된다. 배경의 첫발 장면을 정확한 방송 화면으로 주장하지 않는다.

## 라이브 검수

- 독자 관점: 화면이 한 줄로 접히는 첫 장면과 수상기 운반의 작은 소동이 연결된다. 메이는 모두가 본 첫걸음을 놓치고 판매도 미루므로 선택의 아쉬움이 남는다.
- 기획 관점: 전원 차단 뒤 회관 밖에서 방송 음성이 들린다는 모순을 사람들의 웅성거림으로 수정했다. 수리점의 전시품 손상과 회관 수상기의 미수리는 각각 남는 대가다. `notice`, `repair`, `connect`는 관찰·대체 연결·공유로 구분된다.
- 기술 검수: `typecheck`, 단위 테스트(콘텐츠 21건·API 94건), `content:check`(31쌍과 도달성·다양성), API E2E 2건, 이 편의 320px·768px 브라우저 검사 및 스크린샷 확인이 통과했다. 두 폭에서 인물·수상기·글이 보이고 가로 넘침은 없었다. `git diff --check`도 통과했다. 커밋·푸시·배포는 하지 않았다.
