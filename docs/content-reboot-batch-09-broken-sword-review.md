# 49번째 라이브 검수 — 칼을 들지 못한 기사

> **2026-10-24 생애 보강 초안:** 아래 초기 라이브 검수는 당시 원고의 검사 결과다. 이후 1903년 살바토레가 관객 감소에도 공연을 고집해 마리아의 바깥 재봉 일이 늘고, 1906년 평일 공연을 줄여 수선을 맡은 흐름을 01·02 후일담·03·04·결과 카드에 반영했다. 루치아의 독립적인 공연 결정과 니노의 다른 진로 및 불편한 가족 기억도 보강했다. 1887년 02 사건·세 답변 신호와 생몰은 유지한다. 새 판본의 낭독·화면·삽화 교차 검수와 마지막 순간 원고·삽화는 남아 있어 새 편집 기준 승인이나 출시 완료로 세지 않는다.

**살바토레 벨라 · 남성 · 1853~1925년 · 1887년 팔레르모, 이탈리아 왕국.** 역사 배경과 평생의 변화는 [선행 설정 대장](story-setting-register.md)에 원고보다 먼저 확정했다. [UNESCO의 시칠리아 인형극 설명](https://ich.unesco.org/en/RL/long-song-00011)과 [팔레르모 소장품 보고서](https://ich.unesco.org/doc/src/Signed%20periodic%20report%20-%20Periodic%20report-53836.pdf), [이탈리아 대통령실 왕국 연표](https://palazzo.quirinale.it/luoghi/pdf/it/sala-regno-italia.pdf)를 **2026-10-22** 확인했다. 기사 인형극의 가족 운영·즉흥 대사·팔레르모식 무대라는 배경은 자료와 맞고, 벨라 가족과 막대 파손·대사·환불·생애는 창작이다.

## 원고 자체 검수

- **01** 세 쪽에 신원·일·성격·취향·관계·바람·걱정을 짧게 기록했다. 삶 한 줄은 아버지에게 배운 기술, 마리아와 극장, 자녀의 선택, 수선 일과 루치아에게 맡긴 말년까지 이어진다. 1887년 한 공연의 결론으로 평생을 규정하지 않는다.
- **02** 전생록 화자가 시기·장소와 이야기를 소개하고 말년에 다시 마무리한다. 결투 기대 → 팔 막대 파손 → 고장 고지·다른 장면 선택 → 딸이 방패를 제안 → 관객 일부 환불·다음 날 휴연·수선으로 이어진다. `notice`·`speak`·`repair`는 각각 막대 확인, 관객에게 선택권 제시, 팔 보호와 수선 준비라는 구체 행동이다. 7세 루치아는 짧은 말을 하고 작은 인형 둘을 직접 밀 뿐, 전문 공연을 홀로 지휘하지 않는다. 막대 파손을 숨기지 않아도 떠난 관객이 돌아온다고 보장하지 않는다.
- **03** 출생에서 사망까지 친구·혼인·두 자녀·부친과 배우자와의 이별·수입 감소·수선·은퇴를 담았다. 1887년 살바토레 34세, 루치아 7세이고 1925년 72세다. 1853년은 이탈리아 왕국 성립 전이므로 출생 항목에 이를 밝혔다.
- **04** 극장, 식탁, 니노의 다른 진로, 남긴 말, 마리아·피에트로·루치아·니노의 서로 다른 기억을 담았다. 한 공연의 평가만 반복하지 않는다.
