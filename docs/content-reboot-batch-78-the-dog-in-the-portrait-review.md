# 118번째 「가족사진에 들어온 개」 검수

- **완료:** 2026-10-23. 시작 전에 실제 `storyCards`·원고·그림 연결 117쌍을 다시 세었다. 최근 후에 궁중 음악가·페스 운반·베를린 제빵과 시대·지역·역할·사건이 다른 레이캬비크 사진가를 택했다. 등록 뒤 118편과 고유 그림 118쌍을 확인했다.
- **선행 설정과 자료:** [설정 대장](story-setting-register.md)에 집필 전에 1895년 덴마크 국왕 통치 아래 레이캬비크, 아스타의 창작 생애 1863~1937년, 가족·작업실·돌봄과 개가 들어온 가족사진 사건을 확정했다. [아이슬란드 국립박물관의 여성 사진가 전시](https://thjodminjasafn.is/en/syningar/i-skugganum), [여성 사진사 연구](https://www.thjodminjasafn.is/en/baekur-og-syningarskrar/betur-sja-augu-ljosmyndun-islenskra-kvenna-1872-2013), [미국 의회도서관 유리 건판 설명](https://www.loc.gov/static/collections/civil-war-glass-negatives/articles-and-essays/taking-photographs-during-the-civil-war/), [아이슬란드 의회 역사](https://www.althingi.is/pdf/enska_2000.pdf)를 2026-10-23 확인했다. 여성 사진가·건판 작업·당시 정치권은 역사 배경이고 아스타·가족·사진관·사건·대사는 창작이다. 특정 건판 가격이나 아이슬란드 최초 도입 연도는 주장하지 않는다.
- **원고 검수:** 01 세 쪽에 이름·생몰·일·생활·성격·취향·가족·바람·걱정을 담았다. 삶 한 줄은 농가 출생부터 도시 사진관, 어머니 돌봄과 일의 변화, 노년의 조카까지 이어지고 02의 교훈으로 평생을 규정하지 않는다. 02에는 화자의 도입과 마무리, 개가 뛰어든 첫 노출·어두운 방 현상·서로 다른 사진을 원하는 가족·다시 찍기로 한 선택과 추가 재료비·첫 장을 원하는 아이의 반응이 장면과 대화로 이어진다. 03은 1863~1937년의 이주·가족·일과 은퇴를 기록한다. 04는 남긴 말과 여동생·조카·동료·어머니의 서로 다른 평가다. 1895년 32세, 1937년 74세를 대조했다.
- **그림:** 사람 없는 1254×1254px 창작한 레이캬비크 사진관과 1254×1254px 실제 투명 아스타 인물을 제작했다. 목제 대형 카메라·삼각대·유리 건판 상자와 평범한 긴 치마·숄을 사용했다. API·모바일의 고유 경로 및 투명 알파를 검사했다. 특정 실존 사진관의 복제는 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e`, 전용 모바일 브라우저 E2E 통과. 새 카드를 등록하자 기존의 2048개 결정론적 답변 샘플에서 오래된 한 카드가 빠져, 6개 보기 전체를 탐색하는 샘플을 4096개로 넓혀 비희귀 117편의 도달성을 확인했다. 전용 검사는 질문마다 6개 보기와 첫 질문 여섯째·둘째 질문 다섯째 선택, 01 세 쪽·02~04 이동, 320×720px·768×1024px 그림 로드·가로 넘침을 통과했다. 두 폭의 실제 화면을 육안 확인했다. 이미지 목록은 118쌍+오류 배경 1개, 총 237개다.
- **한계:** 320px에서 인물 몸 일부가 프로필 카드 뒤에 있다. 실제 독자·실기기 반응, 해당 사진관의 정확한 배치·사진 재료 가격, 초기 44편의 01·03 전수 보강은 미검증이다. 커밋·푸시·배포 없음.
