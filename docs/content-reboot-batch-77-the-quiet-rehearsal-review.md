# 117번째 「소리 없는 밤의 박자」 검수

- **완료:** 2026-10-23. 시작 전에 실제 `storyCards`·원고·그림 매핑 116쌍을 다시 세었다. 직전 페스 운반·서베를린 제빵·아보메 장터와 시대·지역·일·정서가 다른 후에의 음악가를 택했다. 등록 뒤 117편과 고유 그림 117쌍을 확인했다.
- **선행 설정과 자료:** [설정 대장](story-setting-register.md)에 집필 전 1850년 응우옌 왕조 수도 후에, 쩐반호아의 창작한 1819~1887년 생애, 가족과 동료·일의 변화, 밤 연습 한 사건을 확정했다. [UNESCO 후에 기념물군](https://whc.unesco.org/en/list/678/)과 [UNESCO 나냐크 궁중음악](https://ich.unesco.org/en/RL/nha-nhac-vietnamese-court-music-00074)을 2026-10-23 확인했다. 후에의 수도 지위, 응우옌 왕조의 궁중 음악 제도, 타악기와 의식의 집중 요구는 역사 배경이다. 호아·가족·동료 빈·이웃·주택·연습과 연주의 세부는 창작이다.
- **원고 검수:** 01 세 쪽은 이름·성별·생몰·집·일·성격·취향·가까운 사람·바람·걱정과 출생부터 노년까지의 일을 담는다. 02의 실수나 선택이 평생의 성격으로 제시되지 않는다. 02에는 전생록 화자 도입·마무리, 불안한 첫 박자·아기의 울음·지친 이웃·동료와의 손짓 연습·이튿날 작은 지각·선배와 빈의 다른 반응이 장면과 대화로 이어진다. 선택에 따른 작은 대가를 남겨 두고 아기가 잠들었다고 단정하지 않는다. 03은 출생부터 1887년 사망까지 가족·가르침·자리 변화도 기록한다. 04는 남긴 말과 아내·빈·아들·후배의 서로 다른 평가다. 1850년 31세, 1887년 68세와 관계를 대조했다.
- **그림:** 사람 없는 1254×1254px 창작한 후에 안뜰과 1254×1254px 실제 투명 인물을 제작했다. 나무 기둥·기와·강가의 낮은 지붕, 남색 긴 옷과 나무채를 사용했고 만화식 외곽선을 피했다. API와 모바일에서 각각 별도 경로를 연결했다. 특정 1850년 집이나 왕실 행사 사진의 복제는 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e`, 전용 모바일 브라우저 E2E 통과. 전용 검사에서 질문당 보기 6개·첫 질문 여섯째·둘째 질문 다섯째 선택, 01 세 쪽과 02~04 도달성, 320×720px·768×1024px 이미지 로드·가로 넘침을 확인했다. 두 폭의 결과 화면을 직접 보았고 프로필 카드와 문구가 겹치지 않았다. 6개 보기 전체를 샘플링한 점수 경로 검사에서 비희귀 116편 모두 도달했고, 이미지 목록은 117쌍+오류 배경 1개로 총 235개다.
- **한계:** 320px 첫 화면에서는 프로필 카드가 인물 몸 일부를 가린다. 실기기·실제 독자 반응, 1850년 후에의 특정 평민 주택 평면과 옷 매무새, 초기 44편의 01·03 전수 보강은 미검증이다. 커밋·푸시·배포 없음.
