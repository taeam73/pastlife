# 71번째 원고·그림 검수 — 「앞줄의 빈자리」

- **결과:** `EMPTY_FRONT_ROW`를 71번째 라이브로 등록했다. 총 71/120편, 남은 49편.
- **선행 설정과 근거:** `docs/story-setting-register.md`에 1927년 이집트 왕국 카이로, 여성 파리다(1888~1962)의 가족·가게·노년까지의 생애를 원고·그림 제작 전 기록했다. 펜실베이니아대 도서관의 1920년대 카이로 연극 자료와 미국 의회도서관의 1927년 카이로 식료품점 사진 등으로 배경을 확인했다. 인물·가게·극단·대사는 창작이다.
- **01:** 세 쪽 프로필에 아버지·언니의 가게, 어린 살마를 돌본 시기, 나빌라와의 일, 하산에게 가게를 넘긴 노년까지 담았다. 1927년의 정치권을 평생의 국가명처럼 읽지 않도록 지역 표기도 조정했다. 희곡 사건 하나로 평생을 정의하지 않는다.
- **02:** 살마의 표, 저녁 주문을 놓친 선택, 객석 뒤쪽에 앉아 앞줄의 빈자리를 보는 동선, 배우가 말버릇과 사적인 가족 이야기를 연기하는 장면, 끝까지 보고 살마에게 두 감정을 함께 말하는 행동을 확인했다. 살마의 창작 의도와 파리다의 노출 불편함이 동시에 남는다. `notice`·`speak`·`connect`의 답변별 행동과 전생록 화자의 도입·마무리가 있다.
- **03·04:** 출생~사망 16개 연대기 사건이 02 밖의 일·관계·건강·가게 이양을 담고, 살마·나빌라·하산이 서로 다른 삶의 면을 평가한다. 살마는 1907년 출생으로 1916년 아홉 살, 1927년 스무 살이다.
- **그림:** 1280×1280 카이로 가게 배경과 1024×1536 진짜 투명 인물 WebP를 따로 만들고 API·모바일에 연결했다. 저울·장부·곡식 자루·극장 거리와 인물의 장부·표가 원고와 맞는다. 특정 실존 가게·극장의 재현으로 제시하지 않는다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 71쌍 그림·투명도·매핑 검사, 다양성 검사, 콘텐츠·도달성·결과 단위 검사 27개, API E2E 2개 통과. Playwright `e2e/mobile-empty-front-row.spec.ts`에서 320×720·768×1024, 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침을 통과했다. 두 크기의 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않았다.
