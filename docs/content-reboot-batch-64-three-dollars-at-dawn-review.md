# 104번째 이야기 검수: 새벽의 3달러

- **설정과 사실·창작 구분:** 1852년 미국 캘리포니아주 투올러미 카운티 컬럼비아. [캘리포니아 주립공원의 컬럼비아 역사](https://www.parks.ca.gov/?page_id=30226)와 [1852년 생활 자료](https://www.parks.ca.gov/?page_id=24249), [1852년 캘리포니아 법령](https://clerk.assembly.ca.gov/sites/clerk.assembly.ca.gov/files/archive/Statutes/1852/1852-resolutions.pdf), [당시 금가루 거래 기록](https://tile.loc.gov/storage-services/service/gdc/calbk/117.pdf)을 2026-10-23 확인했다. 광산촌의 음식 장사와 외국 출신 광부의 월 3달러 허가세는 역사적 배경이다. 로사·마테오·가족, 돈 부탁, 대화와 그 이후의 삶은 창작이다. 이 가족을 실존 인물로 소개하지 않는다.
- **한 사람의 삶:** 로사는 1824년 소노라에서 태어나 음식을 만드는 일을 배웠다. 1851년 동생과 캘리포니아로 옮겨 빵과 식사를 팔았고, 뒤에 라몬과 딸 엘레나의 가족을 꾸렸다. 다른 도시의 식당에서 일하다 라몬을 먼저 보내고, 몬터레이에서 딸 가족 가까이 지내다 1891년에 사망했다. 01의 세 쪽은 신원·생활·성격·취향·관계·바람·걱정과 이 변화를 담는다. 02의 거절 한 번으로 평생을 정의하지 않는다.
- **02의 독립성:** 새벽의 가마·빈 밀가루 자루·3달러를 먼저 보여주고, 동생의 부탁과 이전 빚을 대화로 드러낸다. 로사는 허가세를 대신 내지 않고 유급 빵 운반 일을 제안한다. 마테오는 그 제안을 거절하고 다른 짐 운반 일을 찾는다. 장사는 이어지지만 남매가 한동안 같은 식탁에 앉지 못하는 대가가 남는다. 도입·장면·선택·결과·화자의 마무리를 갖춘다.
- **질문·결과 연결:** 3.0 질문 24개는 각각 여섯 보기를 가진다. 이 편의 `notice`는 밀가루와 돈 계산, `speak`는 지난 빚에 관한 질문, `connect`는 유급 일자리 제안으로 이어진다. 다섯째·여섯째 보기도 기존 신호 경로를 통해 해당 장면에 도달하는지 콘텐츠·브라우저 경로를 검사했다. 초기 44편과 2.5 질문은 보기 확장만을 위해 수정하지 않았다.
- **연대·관계:** 사건 때 28세, 사망 때 67세다. 1854년 마테오의 소노라 귀환, 1856년 라몬과의 혼인, 1860년 엘레나 출생, 1878년 라몬 사망, 1883년 몬터레이 이주가 01·03·04와 충돌하지 않는다. 03은 사건 밖의 일과 가족·노년을 기록하고, 04는 마테오·라몬·엘레나가 서로 다른 면을 기억한다.
- **그림:** `columbia-rosas-kitchen-bg.jpg`는 1254×1254, `columbia-rosa-vega.webp`는 1024×1536의 실제 알파 채널을 가진 인물이다. API와 모바일에 고유 그림으로 매핑했다. 생성 그림의 복식·건축 세부가 학술적 복원이라고 주장하지 않는다.
- **검증:** `pnpm typecheck`, `pnpm content:check`(104개 고유 그림쌍·콘텐츠 도달성·다양성), `pnpm test`(API 110개 포함), `pnpm test:e2e`(API 2개), Edge Playwright 320×720·768×1024 결과 화면 검사가 통과했다. 01 세 쪽과 02~04 도달성, 가로 넘침과 그림 로드를 확인했다. 실제 독자 이해도, 실기기 화면, 역사적 그림 세부는 별도 검증 전이다.

이 검수는 로컬 3.0 원고와 그림 연결을 대상으로 한다. 커밋·푸시·배포하지 않았다.
