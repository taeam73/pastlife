## 초기 해석

- 질문이 거의 없는 무작위 결과는 차별화 기회가 될 수 있다는 가설을 세울 수 있다.
- 광고·결제·복원 문제는 사용자 신뢰를 훼손할 수 있으므로 결과 접근과 해금 실패 복구를 우선 검증해야 한다.
- 현재 자료만으로 한국·영어권의 수요 규모, 경쟁 우위, 수익성을 확정할 수 없다.
- 경쟁 서비스에서 반복되는 보편 기능은 짧은 진입, 결과 카드, 공유, 기록·컬렉션, 무가입 시작이다.
- 전생 장르의 차별화 후보는 질문의 개연성, 역사적 장면의 구체성, 결과의 챕터형 서사, 재방문 가능한 기록 구조다.
- 광고는 전생 장르와 심리테스트 장르 모두에서 보편 수익화 방식이지만, 과도한 광고·결과 접근 지연·결제 복원 실패는 반복적인 불만 위험으로 분류한다.

## 전략 제안 초안

### 보편 기능

- 6단계 이하의 짧은 질문 흐름
- 로그인 없이 기본 결과 확인
- 결과 카드와 공유
- 결과 기록·재방문
- 명확한 오락성 고지와 개인정보 최소 수집

### 차별화 후보

- 단순 직업·별자리 결과가 아니라 시대·권역·직업·관계·사건이 연결된 이야기
- 질문 선택과 결과 장면 사이의 연결을 결과에서 설명
- 역사적 배경과 창작 서사를 구분한 신뢰 표현
- 기본 결과 이후 심화 이야기와 현생 가이드로 이어지는 단계적 탐색

### 제외 또는 보류

- 시장 근거 없는 구독 강제
- 결과를 과학적 진단이나 실제 전생 사실처럼 표현하는 기능
- 광고 시청 실패 시 결과 자체를 잃게 만드는 흐름
- 초기부터 과도한 소셜 피드·채팅 기능

이 절은 시장 조사에 기반한 전략 제안이며, 확정 결정은 아니다.

## 추가 조사 항목

1. Google Play와 App Store에서 전생·운세·심리테스트·AI 자기탐색 앱을 국가별로 10개 선정한다.
2. 각 앱의 평점, 리뷰 수, 다운로드 표기, 업데이트일, 가격, 광고 방식, 구독·인앱 결제를 같은 날짜에 기록한다.
3. 최근 리뷰를 긍정·부정·기능 요청·광고 불만·결과 신뢰·중도 이탈로 분류한다.
4. Google Trends에서 한국어·영어 검색어를 동일 기간·동일 지역으로 비교하고 CSV를 보관한다.
5. 앱스토어 정책과 개인정보 고지를 확인해 광고·결제·로그인·AI 이미지 운영 제약을 정리한다.
6. 실제 사용자 5~8명의 짧은 사용성 테스트로 첫인상, 질문 흥미, 결과 만족, 광고 수용성을 검증한다.
