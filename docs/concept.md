# 전생록 콘셉트

## 현재 확인된 방향

전생록은 실제 전생이나 과학적 진단을 주장하지 않고, 6단계 선택을 통해 신비로운 상상과 짧은 이야기 경험을 제공하는 엔터테인먼트 앱이다. 최상위 목적은 사용자의 **흥미·재미·공감**이다. 신비로움은 이 경험의 분위기이며, 사용자가 다음 장면을 궁금해하고 선택을 즐기며 결과에서 자신의 모습을 떠올릴 수 있어야 한다.

주요 타깃은 중·고등학생이다. 질문의 상황과 감정은 전 연령이 공감할 수 있게 구성하고, 표현은 초등학생도 쉽게 이해할 수 있는 수준으로 쓴다. 특정 연령의 학교생활을 질문의 기본 전제로 삼지 않는다.

질문과 결과는 연결되어야 한다. 사용자가 고른 답이 전생 이야기의 구체적인 선택에 반영되고, 결과에서 지금의 자신과 닮은 점을 생각해 볼 여지를 제공한다. 실제 전생이 현재 성격의 원인이라고 단정하지 않는다.

## 코드에서 확인된 범위

- 모바일, API, 관리자, 워커가 분리된 모노레포다.
- 질문 콘텐츠는 `packages/content`에 있고 6단계 타입이 정의되어 있다.
- 점수와 결과 판정은 `packages/scoring`에 있다.
- 결과·광고 해금·아카이브·이미지 폴백 흐름이 API와 모바일에 연결되어 있다.

## 가설

- 회원가입 없이 시작하는 짧은 흐름이 첫 사용 진입장벽을 낮출 수 있다.
- 결과를 역사적 장면과 공유 카드로 표현하면 재방문·공유 동기가 생길 수 있다.
- 한국어와 영어권을 우선 대상으로 조사하는 것이 적절하다.

위 가설은 시장 조사 전에는 검증된 사실로 취급하지 않는다.

## 보호 대상

질문 ID, 선택지 ID, 점수 태그, 결과 산정 순서, 결과 데이터 계약, 콘텐츠 버전 규칙을 승인 없이 변경하지 않는다.

## 미확정 사항

- 국가별 우선순위
- 무료·광고·유료 콘텐츠의 최종 조합
- 디자인 방향 3안 중 선택 결과
- 실제 운영 환경의 외부 API·스토리지·광고 연동

## 시장 조사 반영 전략 초안

### 보편 기능

- 짧은 질문 흐름과 무가입 기본 시작
- 결과 카드와 공유
- 결과 기록과 재방문
- 무료 기본 결과와 명확한 오락성 고지

### 차별화 방향

전생 결과를 단일 직업명으로 끝내지 않고, 질문 선택과 연결된 시대·권역·직업·관계·사건을 챕터형 이야기로 보여준다. 기본 결과에서 끝나지 않고 심화 이야기와 현생 가이드로 자연스럽게 확장한다.

### 제외·보류 방향

- 과학적 진단이나 실제 전생 사실처럼 보이는 표현
- 결과를 보기 위해 반복 광고를 강제하는 흐름
- 초기부터 소셜 피드·실시간 채팅을 핵심 기능으로 추가하는 것

이 전략은 조사 기반 제안이며, 구현 전 제품 방향으로 확정한다.
