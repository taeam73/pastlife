# 라비 마지막 순간 검수 기록

**2026-10-24 새 편집 기준 재판정:** 아래는 집필 당시 원고·그림·웹·PDF/PNG의 기술 검수 기록이다. 라비가 43세 약초 일을 떠나 흙그릇을 배우고 48세 돌아와 다른 생활을 이어 간 생애를 [설정 대장](story-setting-register.md)과 01·03·04에 추가했다. 현재 마지막 원고·삽화는 할머니 지도·약초 잎·젊은 후계자·은비 곁의 임종으로만 끝나 새 생애와 맞지 않는다. **마지막 원고·삽화 모두 재작업 대상**이며, 아래 과거 기술 검사를 새 기준의 서사 승인으로 세지 않는다. 실제 PDF 다운로드와 공유 이미지의 최종 일괄 검수는 120편 확정 뒤 수행한다.

2026-10-24 기준. `HERBALIST`는 **허구의 하론 세계** 이야기이며 실제 역사 인물이나 장소를 가리키지 않는다. 마지막 장면의 대사·죽음의 구체적 상황·남은 이들의 반응도 창작이다.

## 원고 정합성

- 01·03: 여성 라비, 숲력 206~272년, 안개숲 마을 남쪽 비탈, 66세에 사망. 27세에 할머니가 세상을 떠난 뒤 손그림 지도를 이어 그렸고, 44세부터 은비와 숲길을 함께 돌봤으며 59세에 다음 약초지기에게 기록을 넘겼다.
- 04: 할머니 지도, 잎 말리는 버릇, 은비의 밭일 기억을 마지막 아침의 물건과 관계에 연결했다. 젊은 약초지기는 03의 후계자다.
- 02의 빨간 실·아이·큰비·흙 자루 사건은 마지막 장면에서 다시 벌이지 않았다. 떠나기 전 숲길을 다시 걷고 싶은 마음, 일을 넘겨준 안도와 섭섭함을 같은 인물의 말년 변화로 썼다.
- 그림은 원고상 여성과 기존 기본 인물의 얼굴·어두운 겉옷·연한 속옷을 참고했다. 첫 삽화에서 라비가 66세보다 젊게 보여 머리의 흰빛과 얼굴·손의 나이 표현을 보정했다. 1536×1024 JPEG, 382,356바이트. 원본 시안은 앱 매핑에 쓰지 않았다.

## 확인한 범위

- `final-moment:check` 9/120, `content:check` 120쌍·마지막 장면 9개, 모바일/API 타입 검사, API E2E 2건 통과.
- 인메모리 3.0 API의 실제 보기 6개 답변을 제출해 22번째 시도에 라비 결과를 선택했다. 320px 결과에서 저장 잠금과 두 번째 **테스트 광고** 진입, 마지막 순간 화면, 읽음 표시, PDF·공유 PNG 해제를 확인했다.
- 삽화를 보정한 뒤 웹 앱 캐시를 비우고 다시 실행했다. 320px·768px 마지막 화면에서 그림·본문·맺음말·마치기 버튼을 확인했고 가로 넘침과 브라우저 오류가 없었다. 320px의 상단·하단 캡처를 직접 열어 확인했다.
- 다시 받은 `output/pdf/full-final-herbalist-web-qa.pdf`는 A4 9쪽이다. 전체를 렌더링한 `output/pdf/herbalist-final-contact.jpg`에서 표지, 01~04, 삽화가 있는 마지막 순간과 전생록 맺음말을 확인했다. `output/playwright/herbalist-share-qa.png`는 1080×1800이며 배경·투명 인물·짧은 관계 및 01 소개가 들어간 것을 확인했다. PDF는 현재 이미지형이라 텍스트 선택은 되지 않는다.

## 남은 검증

운영 광고, 실제 DB 지속성, 휴대폰 PDF 파일 저장·이미지 공유는 이 인메모리 웹 검사로 검증하지 못했다. 120편 전체의 결과 카드별 크롭과 기기별 화면 검증도 남아 있다. 따라서 이 편은 원고·그림과 **웹 시범 여정**만 확인했으며, 전체 출시 경험 완료로 세지 않는다.
