# 마누엘 마지막 순간 검수 기록

**2026-10-24 새 편집 기준 보강:** 며칠째 밭에 나가지 못한 마누엘이 문가에서 이사벨·손녀와 노래를 듣는 기존 장면을 유지했다. 흙잔을 놓기 힘든 손, 긴 말을 잇기 어려운 호흡, 딸의 손을 누른 뒤 멎는 숨을 구체적으로 적고, 사후 사실은 전생록 화자로 옮겼다. 급작스러운 구조 요청이 있는 에디스 편과 달리 가족이 기력 저하를 함께 지켜본 저녁이다. 직접 병명·사인은 미설정이고 이 마지막 저녁은 창작이다. `final-moment:check`의 40편 원고·삽화 매핑과 콘텐츠 타입은 통과했다. 아래 웹·PDF·PNG 검사는 **이전 판본**의 기록이다. 수정판의 낭독·가장 닮은 세 편·삽화·실제 화면 검수가 남아 새 기준 승인으로 세지 않는다.

2026-10-24 기준. `COCHINEAL_SCALE`의 인물·가족·마지막 대사와 사후 반응은 모두 창작이다. 실제 역사 배경은 1806년 스페인 제국 **누에바에스파냐 부왕령**, 오늘날 멕시코 오악사카 계곡의 안테케라 근교다. [Cambridge University Press의 오악사카 교역 연구 요약](https://www.cambridge.org/core/books/abs/politics-and-trade-in-mexico-17501821/oaxacaenvironment-and-trade/5F23B717B63C715F174FB250111351DA)과 [Metropolitan Museum의 1500~1800년 직물 교역 전시 설명](https://www.metmuseum.org/exhibitions/listings/2013/interwoven-globe)을 2026-10-24 다시 확인했다. 오악사카의 연지벌레 염료 생산·교역은 시대 배경의 근거이나, 특정 마누엘 가족의 생활이나 마지막 날을 입증하지는 않는다.

## 원고·그림 대조

- 01·03의 **1738~1806년, 68세**, 재배자·한때 도시 운반 일꾼, 딸 이사벨(1761년생, 이때 45세), 아들 니코(1765년생, 41세), 손녀(1798년생, 8세)를 유지했다. 배우자 후아나는 **1802년 사망**했으므로 마지막 장면에 살아서 등장시키지 않았다.
- 04의 아버지가 빚어 준 작은 흙잔과 서툰 노래를 장면의 물건·소리로 삼았다. 딸이 자기 거래를 시작했고 아들이 그릇 일을 배웠다는 03의 후반기를 짧게 잇는다. 02의 1777년 저울 재검·상인과의 갈등을 마지막 순간에 반복하지 않았다.
- 삽화는 기존 39세 마누엘 그림의 얼굴·크림색 옷·붉은 허리띠를 참고한 새 1806년 장면이다. 첫 생성본이 젊어 보여 흰머리·눈가·손과 자세를 68세에 가깝게 보정했다. 딸과 손녀, 흙잔, 선인장 밭이 함께 보이는 **1536×1024 JPEG, 278,326바이트**다. 옷 재단·집 구조·그날의 날씨는 사료 재현으로 주장하지 않는 창작 시각화다.

## 실행 검사와 남은 일

- `final-moment:check` **11/120**, `content:check`의 원고·기본 그림 120쌍·마지막 삽화 11개, 모바일 타입, API E2E 2건 통과.
- 2026-10-24 추가 웹 검증: 3.0 질문 여섯 개의 실제 API 답변 경로로 마누엘 결과를 생성하고 첫 테스트 광고를 해제했다. 별도 8282 웹 앱에서 320px 결과의 PDF 잠금 → 두 번째 테스트 광고 → 마지막 순간과 고유 삽화 → 읽음 저장 → 결과 재진입과 PDF·이미지 공유 해제를 통과했다. 마지막 화면을 320px·768px에서 캡처하고 이미지 로딩·가로 넘침 없음·본문 끝 버튼 도달을 확인했다. 재현 가능한 검사 `e2e/mobile-final-moment-historical.spec.ts`가 자체적으로 새 결과를 생성해 **1건 통과**했다.
- 앱 버튼에서 내려받은 PDF를 다시 열어 **A4 10쪽, 약 2.0MB**, 전 쪽을 렌더링해 표지·01~04·마지막 삽화/장면·전생록 맺음말의 배열과 잘림을 확인했다. 공유 PNG는 **1080×1800 RGBA**, 약 3.7MB로 열어 기존 배경·투명 인물, 12번째 전생 표기, 이름·생몰·지역·직업·가까운 사람·삶 한 줄을 직접 확인했다. PDF는 이미지 쪽으로 구성되어 텍스트 검색·복사가 되지 않는다. 검사 산출물은 `output/playwright/manuel-record.pdf`, `manuel-pdf-contact.jpg`, `manuel-share.png`에 있다.
