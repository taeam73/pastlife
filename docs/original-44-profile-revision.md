# 초기 44편 01·03·04 보강 기록

기준일: 2026-10-23. 대상은 실제 `storyCards` 배열의 첫 44편이다. 원고는 모두 연결돼 있었지만, 작업 시작 때 44편 모두 01의 `profilePages`가 없었다. 03·04에는 항목이 있으나 평생의 관계와 변화가 사건 하나에 치우친 편을 작품별로 다시 읽는다. 45번째 이후의 역사 배경 원칙을 이 44편의 기존 가상 세계에 소급 적용하지 않는다.

현재 44/44편 원고 보강과 01·03·04 화면 검사 완료, 남은 원고 0편. 라이브 이야기 총수는 120편 그대로다. 15·20·22·44번째의 기존 인물 그림 외형은 별도 시각 정합성 확인 항목이다. 이 문서의 완료는 초기 44편의 원고 보강과 화면 도달성 검사를 뜻하며 기존 그림의 외형 문제까지 해결했다는 뜻은 아니다.

## 첫 묶음의 개별 점검

- `CLOWN`: 수레 제작자의 집에서 자란 점과 아버지·피노·아이·젊은 배우의 관계를 01·03에 이어 놓았다. 04의 피노·제자 평가에 공방 이웃의 시선을 추가했다. 02의 객석 사건은 그대로 두었고 01에서 그날의 결말을 말하지 않는다.
- `ROOM7`: 열한 살의 인형 만들기, 여관 인계, 계단에서 숨이 차는 생활, 조카에게 일을 나눈 뒤 인형을 수선한 시기까지 연결했다. 병명은 만들지 않았다. 04에 아이의 기억을 더했다.
- `BLANK_ORDER`: 안개 왕국의 창작 세계라는 표기를 유지했다. 왕궁 이전 시장 견습과 이후 성 밖 기록소의 삶, 친구 유진과 젊은 기록자의 관계를 연결했다. 04에는 일 밖에서 세아를 본 친구의 평가를 더했다.
- `SILENT_BELL`: 갈대강 나루의 어린 시절, 탐정 일, 친구 소미와 강가 생활, 후배에게 장부를 넘긴 시기를 연결했다. 04에 소미의 칭찬만은 아닌 평가를 더했다.
- `NIGHT_GUIDE`: 아버지의 길표시, 누이와 나눈 살림과 몸이 아픈 시기, 후배에게 쉬운 길부터 맡긴 말년을 연결했다. 04에는 후배의 평가를 보탰다.
- `MIRROR`: 스승·친구 연주·제자와 골목에서 보낸 기간을 연결했다. 04에 일할 때와 쉴 때 달랐던 모습을 본 친구의 평가를 더했다.
- `HERBALIST`: 할머니에게 배운 숲길, 이웃 은비와 밭일, 할머니 사후의 지도 보완, 후임 교육을 연결했다. 04에는 은비의 기억을 더했다.
- `DRAGON_DREAM`: 도서관 기록과 제본사 라엔과의 일상, 후배에게 일을 넘긴 뒤의 책 수선을 01·03에 넣었다. 기존 04는 라엔·니아·마을 사람의 서로 다른 평가와 평생의 버릇이 있어 유지했다.

## 검증 범위와 발견한 문제

- 실제 카드·원고 배열은 각 120개이며 첫 44편의 원고 ID가 모두 존재했다.
- 첫 브라우저 실행에서는 새 한 줄 소개 네 개가 결과 API의 `signatureQuote` 80자 제한을 넘어 실패했다. 소개를 줄인 뒤 같은 경로를 다시 실행했다.
- `corepack pnpm content:check`와 `corepack pnpm test:e2e` 통과. `e2e/mobile-original-profile-revision.spec.ts`는 4편 각각의 320px·768px 결과에서 01의 세 쪽 이동, 03·04 문구 도달, 가로 넘침 없음을 확인했고 4/4 통과했다. 320px 전체 화면 캡처 네 장을 직접 확인했다.
- 둘째 묶음은 콘텐츠 단위 검사·타입 검사 통과. 같은 브라우저 검사로 5~8번째도 4/4 통과했으며 320px 캡처 네 장을 직접 확인했다. API 응답은 이 브라우저 검사에서 실제 `buildContentStoryResult`로 생성했다. 전체 API E2E는 첫 묶음 직후 통과했으며 둘째 묶음 뒤에는 재실행하지 않았다.
- 셋째 묶음 9~12번째도 콘텐츠 단위·타입 검사와 320px·768px 브라우저 검사 4/4 통과. 01 세 쪽과 03·04 도달성, 가로 넘침을 확인하고 320px 캡처 네 장을 직접 읽었다. `SHORE_ROCK`은 사람이 아닌 해안 바위이므로 말과 성격을 꾸며 넣지 않고 물길·계절·사람의 관찰을 썼다. 01은 02의 결말을 먼저 말하지 않게 조정했다. 전체 API E2E는 이 묶음 뒤 재실행하지 않았다.
- 넷째 묶음 13~16번째는 콘텐츠 단위·타입 검사와 320px·768px 브라우저 검사 4/4 통과. 캡처 네 장을 직접 읽었다. 15번째 `FESTIVAL_KING`의 기존 인물 그림은 원고의 남성 배우와 외형이 다르게 읽힐 여지가 있어, 원고와 별도로 그림 정합성을 다시 확인해야 한다. 이 그림은 이번 원고 수정에서 교체하지 않았다.
- 다섯째 묶음 17~20번째도 콘텐츠 단위·타입과 320px·768px 브라우저 검사 4/4 통과, 전화면 캡처 네 장을 직접 읽었다. 20번째 `DOORLESS_KEEPER`의 기존 인물 그림 역시 남성 설정과 외형이 다르게 읽힐 수 있어 그림 정합성 재검토 대상으로 기록했다. 그림은 이번 원고 수정에서 교체하지 않았다.
- 여섯째 묶음 21~24번째는 콘텐츠 단위·타입, `content:check`(120쌍 파일·매핑·다양성), API E2E 2건과 320px·768px 브라우저 검사 4/4를 통과했다. 320px 캡처 네 장을 직접 읽었다. 22번째 `THEATRE_VILLAIN`의 인물 그림은 원고의 여성 배우 비안과 뚜렷이 다른 남성 외형이라 시각 정합성은 미통과로 기록한다. 파일·매핑 검사는 의미 정합성을 확인하지 못한다. 그림은 원고 보강 범위에서 교체하지 않았다.
- 일곱째 묶음 25~28번째는 콘텐츠 단위·타입, API E2E 2건과 320px·768px 브라우저 검사 4/4를 통과했다. 320px 캡처 네 장을 직접 읽고 새 문장의 가독성과 기존 이미지의 원고 설정을 살폈다. 콘텐츠 자산 전체 검사(`content:check`)는 직전 묶음에서 통과했고 이 묶음 뒤에는 재실행하지 않았다. 29번째 실존 인물 원고는 자료 확인 뒤 보강한다.
- 29번째 존 T. 대니얼스: 2026-10-23에 [노스캐롤라이나주 국가사적지 등록 자료](https://files.nc.gov/historic-preservation/nr/DR0286.pdf)와 [미국 국립공원관리청 첫 비행 설명](https://home.nps.gov/wrbr/learn/historyculture/thefirstflight.htm)을 다시 확인했다. 주 등록 자료는 1873년 7월 출생, 1892년 어맨다와 결혼, 여섯 자녀, 1900년 일용 노동 기록, 1902년 킬데빌힐스 구조소 근무, 1912년 구조대 퇴직, 이후 조선소 기계공·1930년대 연락선 일·1948년 1월 폐렴 사망을 뒷받침한다. NPS는 1903년 12월 17일 미리 맞춘 사진기의 셔터를 대니얼스가 눌렀다고 설명한다. 01의 성격·취향·바람·걱정과 04 인용 대사는 자료로 확인되지 않아 창작으로 표시했다. 실존 가족의 발언은 만들지 않았다. 첫 콘텐츠 단위 검사는 04의 `평가` 라벨 누락으로 실패했고 라벨을 고친 뒤 37/37 통과했다. 타입·API E2E 2건과 320px·768px 브라우저 1/1도 통과했으며 전화면 캡처를 읽었다.
- 30번째 김해원과 31번째 메이: 2026-10-23에 [국가기록원의 전당포 기록](https://www.archives.go.kr/archivesdata/upFile/palgan/1372744126687.pdf)과 [CSIRO의 파크스 관측소 기록](https://www.csiro.au/en/about/facilities-collections/ATNF/Parkes-radio-telescope-Murriyang/Apollo-11-Moon-landing)을 다시 확인했다. 전자는 일제강점기 전당업의 제도와 서민의 물건 거래를, 후자는 1969년 7월 21일 오스트레일리아 시간 달 표면 방송과 파크스 신호의 역할을 뒷받침한다. 해원·메이·가족·손님·후배의 개인사는 창작으로 표시했다. 두 편의 01 세 쪽, 03 평생 변화, 04 서로 다른 평가를 보강했다. 콘텐츠 단위 37/37, 전체 `content:check`, API E2E 2/2, 각 편의 320px·768px 결과 화면 검사를 통과했고 320px 캡처를 직접 읽었다. 첫 브라우저 시도에서 30번째 검사의 03 탐색 문구가 실제 원고와 일치하지 않아 테스트 문구를 고친 뒤 다시 통과했다. 이는 원고 결함이 아니었다.
