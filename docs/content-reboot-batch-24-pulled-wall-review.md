# 64번째 라이브 검수 — 내가 허문 벽

**겐지 · 남성 · 1805~1871년 · 대표 에피소드 1846년 에도 막부 통치 아래 일본 에도 니혼바시.** [선행 설정 대장](story-setting-register.md)에 실제 시기·장소·정치권과 창작 인물의 성별·생몰·평생의 흐름을 원고보다 먼저 확정했다. [에도도쿄박물관의 동네 소방대 기록](https://www.edo-tokyo-museum.or.jp/asset/2026/01/EdohakuNews_E25.pdf), [에도 나가야 전시 설명](https://edo-tokyo-museum.or.jp/en/p-exhibition/), [도쿄 미나토구의 에도 소방대와 방화선 철거 설명](https://www.city.minato.tokyo.jp/documents/13331/azabu48e_1.pdf)을 2026-10-23 확인했다. 특정 1846년 화재, 겐지의 작업장, 가족과 대사는 창작이다. 그림은 당시 골목의 분위기를 그린 것이며 실존 건물의 복원이 아니다.

## 원고 자체 검수

- **01** 세 쪽에 신원·생몰·목수 일, 성격·취향·솜씨, 아낀 물건·관계·바람·걱정을 짧게 배치했다. 삶 한 줄은 아버지에게 목공을 배운 때부터 미네·유키와 꾸린 살림, 작은 작업장 재건, 견습생과 손자가 있는 노년으로 이어진다. 화재의 선택 하나로 평생을 정의하지 않는다.
- **02** 전생록의 도입·마무리 사이에 불길이 다가옴, 작업장을 허물라는 지시, 문 옆의 먹줄 상자와 뒤쪽의 미네 상자, 지붕에 떨어진 불씨, 자기 벽을 무너뜨리는 행동, 유키가 본 장면과 오래 남은 갈등이 이어진다. `notice`는 불씨와 선반의 거리를 보고, `protect`는 옆집 처마를 확인하고, `speak`는 유키에게 상자를 못 꺼냈다고 먼저 알린다. 세 경로 모두 실제 철거와 유품·도구의 손실로 이어진다. 빈 작업장을 허물어 이웃집으로 번지는 길을 줄였지만 모든 피해를 막거나 가족 갈등을 즉시 해결하지 않는다.
- **03** 1805년 출생부터 1871년 사망까지 16개 사건에 아버지·미네·유키, 견습·독립·혼인, 두 번의 사별, 재건·제자·손자·무릎 통증과 은퇴를 넣었다. 1846년 41세, 사망 때 66세가 맞다. 사망 당시 지명은 도쿄로 바로잡았다.
- **04** 먹줄 상자·좋아한 소리·다시 꾸린 작업장·남긴 말과 유키·타로·이웃 목수의 다른 평가로 평생을 돌아본다. 두 상자의 위치와 겐지가 실제 들고 나온 물건을 모든 섹션에서 맞췄고, 중학생 독자가 누가 무엇을 잃었는지 따라갈 수 있도록 문장과 인과를 다시 읽었다.

- 고유 배경 `pulled-wall-edo-bg.jpg` **1254×1254, 262KB**, 실제 알파 인물 `pulled-wall-genji.webp` **1024×1536, 151KB**를 API·모바일에 연결했다. 배경의 해체된 목조 골목과 인물의 누비 소방복·긴 갈고리·먹줄 상자를 원고에 맞췄다. [메트로폴리탄 미술관의 에도 소방복 소장품](https://www.metmuseum.org/art/collection/search/53910)도 복식 참고로 확인했다.
