# `MIRROR` 모아 마지막 순간 검수 기록

**2026-10-26 v2 재작업:** 아래는 당시 v1의 역사적 기록이다. 현행 원고는 68세 가을비 뒤 연주의 집에서 식사하고 자기 집으로 돌아가다가 젖은 돌계단에서 미끄러져 머리를 부딪치는 마지막 순간이다. 연주는 건너편 자기 집에서 보고 곁으로 오며 제자는 사후 소식을 듣는다. 설정 대장·03·원고/화자·지붕 위에서 두 별도 집을 보는 `mirror-final-moment-v2.jpg`와 앱 URI를 맞췄다. 사고는 허구 세계의 새 창작 개인사이며 02의 거울 조각이나 48세 화재의 결과로 설명하지 않는다. `content:check`·`final-moment:check`·모바일 타입·API E2E 통과. 유사 낙상 장면 비교·소리 내어 읽기·실제 화면 전에는 서사 승인이 아니다. v1의 아래 PDF·공유 검사 기록은 현행 결과 검수가 아니다.

**2026-10-24 새 편집 기준 재판정:** 아래는 당시 3.0 기술·화면 검사의 역사적 기록이다. 생애 재설계로 모아의 48세 골목 화재와 연주의 빈방에서 지낸 시기, 53세 가게 재개를 [설정 대장](story-setting-register.md)에 추가했다. 현재 마지막 원고는 60세 가게 인계와 장갑·거울·연주 곁 임종만 반복하여 새 기준의 `02와 독립된 전체 삶`과 구체적 사망 경위 게이트를 통과하지 못한다. 삽화도 그 장면을 그려 **원고·삽화 모두 재작업 대상**이다. 아래의 과거 PDF·PNG 열기 결과는 새 편집 승인이나 최신 데이터 검사가 아니며, 사용자의 지시에 따라 최종 PDF·공유 이미지 검수는 120편 확정 뒤 일괄 진행한다.

검수일: 2026-10-24 (KST)

- 기존 01·03·04 기준: 미렌 세계 창력 301~369년, 여성 모아, 동부 비늘빛 골목 출생·사망. 유리 상인의 집에서 자라 거울 수선공이 되었고 60세에 가게를 제자에게 넘겼다. 수선 스승, 골목 친구 연주, 제자와 오래 관계를 맺었다.
- 새 장면: 창력 369년, 모아가 예전 작업대에서 제자의 장갑 수선을 지켜보고 연주와 저녁을 보낸다. 02의 잃어버린 거울 조각을 찾는 사건을 재현하지 않고, 가게를 넘긴 뒤에도 남은 일에 대한 마음과 두 사람의 곁을 그렸다. 특정 사망 원인은 단정하지 않는다.
- 창작·사실 구분: 미렌 세계·창력·비늘빛 골목과 인물·사건은 기존 작품의 허구 설정이다. 제자의 장갑 수선, 마지막 대화, 연주의 반응은 이번 장면에서 창작했다. 실제 역사나 확인된 사망 기록으로 설명하지 않는다.
- 전용 그림: 기존 모아의 어두운 남색 겹옷·묶은 머리와 골목 화풍을 참조해 제작한 1536×1024 JPEG(390,902바이트). 첫 시안에서 주인공이 68세보다 젊어 보여 얼굴선·희끗한 머리·손을 보정한 그림을 채택했다. 친구 연주와 젊은 제자, 작업대·장갑·거울이 보이며 현대 물건과 읽을 수 있는 문구는 없다. 장면 속 오래된 거울은 02의 사물과 이어지지만, 삽화의 중심 사건은 제자에게 일을 맡기는 저녁이다.

- 실제 웹 여정: 인메모리 3.0 API에 여섯 답변을 제출해 140번째 시도에서 모아를 선택했다. 320px 결과의 저장·공유 잠금 → 두 번째 테스트 광고 → 마지막 순간 읽기 → API `finalMomentRead=true` → 파일 버튼 해제를 확인했다. 320px·768px 마지막 순간에 가로 넘침이나 브라우저 오류가 없고, 삽화·본문·맺음말·끝 버튼을 직접 읽었다.
