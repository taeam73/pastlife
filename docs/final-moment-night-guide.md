# `NIGHT_GUIDE` 마루 마지막 순간 검수 기록

**2026-10-24 새 편집 기준 재판정:** 아래는 당시 원고·삽화·웹 및 PDF/PNG 기술 검수 기록이다. 새 [설정 대장](story-setting-register.md)과 01·03·04에서는 누이가 45세 장터 마을로 이사하고, 52세 새 돌길 뒤 마루가 옛집에 홀로 지낸다. 현재 마지막 순간은 누이·후배·흰 돌·지도·등불이 한자리에 모인 뒤 소리가 멀어지고 눈을 감는 구성이라 다른 편의 후계자 곁 임종과 닮고, 누이의 독립된 생활도 드러나지 않는다. **마지막 원고·삽화 재작업 대상**이며 아래의 과거 기술 검사는 새 서사 승인으로 세지 않는다. 최종 PDF·공유 이미지 검수는 120편 확정 뒤 일괄 진행한다.

검수일: 2026-10-24 (KST)

- 기존 01·03·04 기준: 소라든 세계 등불력 190~251년, 남성 마루, 북부 솔등 산골 출생·사망. 산지기 아버지와 길표시를 만들며 자라 밤길 안내자가 됐고, 누이와 산 아래 집에서 살았다. 52세에 지도를 후배에게 넘긴 뒤 쉬운 구간만 안내했고 58세에는 누이와 흰 돌을 손질했다.
- 기본 인물 그림: 기존 그림의 외형이 01의 남성 설정과 어긋나 보여 복식·자세·등불·화풍을 유지한 1024×1536 투명 WebP 새 버전으로 교체 연결했다. 원본 파일은 보존했다. 320px·768px 실제 결과 표지에서 배경과 합성한 모습을 확인했다.
- 새 장면: 등불력 251년 집에서 누이와 국을 나누고, 북쪽 갈림길을 다녀온 후배에게 길표시를 묻는다. 아버지와 놓은 첫 돌을 다시 보고 싶은 마음, 누이의 아픈 손목에 대한 걱정, 후배에게 길을 맡기는 마음이 함께 있다. 02의 병이 돈 비 오는 밤과 약 꾸러미를 든 아이 사건을 반복하지 않는다. 사망 원인은 새로 단정하지 않는다.
- 창작·사실 구분: 소라든 세계·등불력·솔등 산골과 인물·사건은 기존 작품의 허구 설정이다. 마지막 날의 대사, 후배의 북쪽 길 점검, 누이와 후배의 사후 반응은 이번 장면에서 창작했다. 실존 역사 기록으로 설명하지 않는다.
- 전용 그림: 기존 인물·배경을 참조해 만든 1536×1024 JPEG(384,693바이트)다. 61세로 읽히는 마루, 손목에 천을 감은 누이, 문가의 젊은 후배, 지도와 흰 돌 세 개, 등불을 확인했다. 현대 물건과 읽을 수 있는 문구는 없다.
- 자동 검사: `final-moment:check` 8/120, content/mobile 타입과 API E2E 2건이 통과했다. 기본 그림 교체 뒤 `content:check`의 120쌍, API 이미지 단위 66건, API/모바일 타입도 통과했다.
- 실제 웹 여정: 인메모리 3.0 API에 여섯 답변을 제출해 18번째 시도에서 마루를 선택했다. 320px 결과의 저장·공유 잠금 → 두 번째 테스트 광고 → 마지막 순간 읽기 → API `finalMomentRead=true` → 파일 버튼 해제를 확인했다. 첫 공유 이미지 다운로드 대기는 시간 초과였으나, 같은 결과에서 버튼을 다시 눌러 실제 파일을 받았고 뒤이은 PDF·PNG 동시 재검사도 통과했다. 320px·768px 마지막 순간 화면에 가로 넘침·브라우저 오류는 없고 삽화·본문·맺음말·끝 버튼을 직접 읽었다.
- 파일 검사: 앱 버튼으로 받은 PDF는 9쪽 A4이며 전체 접촉 시트를 렌더링해 01~04·마지막 삽화·전생록 맺음말과 페이지 나눔을 확인했다. 공유 PNG는 1080×1800 RGBA이며 새 남성 마루, 배경, 35번째 표기·01 관계 문구를 확인했다. PDF는 이미지형이다.
- 남은 검증: 네이티브 저장·공유, 운영 DB·광고, 다른 112편의 마지막 순간과 편별 크롭·화면 검증은 남았다. 전체 경험 완료 편수는 0/120이다.
