# 83번째 원고·그림 검수 — 빗자루 속의 반지

- ID: `RING_IN_BROOM`. 헬렌 프레이저(1940~2011)는 1967년 뉴질랜드 와이라라파 마스터턴 근교의 창작 양모 작업장에서 일한 가상 인물이다. [1966년 뉴질랜드 백과사전](https://teara.govt.nz/mi/1966/shearing)의 당시 기계·양모 작업 설명, [테 아라 작업 분담](https://teara.govt.nz/en/shearing/page-1)과 [1960년대 계약팀 설명](https://teara.govt.nz/en/shearing/page-4), [골든 시어스 공식 회고](https://www.goldenshears.co.nz/media-releases-2018/2018/3/3/surprise-entrant-surprise-winner)의 여성 양모 노동자 기록을 2026-10-23 확인했다. 헬렌·조이·목장·반지 사건·대사는 창작이다. [설정 대장](story-setting-register.md)에 평생과 역사 근거를 원고 전에 확정했다.
- 01: 부모의 수리 일, 양모 분류로 오기 전의 일들, 조이와의 우정, 부상 뒤 업무 변화, 고향에서 보낸 노년을 세 쪽에 소개한다. 반지 소동 하나로 삶을 규정하지 않는다. 결과 요약은 80자 제한을 지킨다.
- 02: 조이의 반지가 압축 직전 양모에 들어갔다고 생각해 헬렌이 작업을 멈추게 한다. 둘이 양모를 뒤진 끝에 반지가 빗자루 털에 걸린 것을 발견한다. 웃고 끝나는 대신 늦어진 작업과 팀장 톰의 경고가 남는다. `speak`·`explore`·`protect`는 각각 톰에게 설명하기·더미 먼저 살피기·압축 전 손짓으로 다른 행동이다. 전생록 화자의 도입과 이후 삶의 마무리가 있다.
- 03: 출생부터 사망까지 15개 사건으로 부모, 첫 일, 조이와의 이동·긴 우정, 독립 생활, 부모와의 사별, 부상 뒤 일의 변화, 후배 교육, 정원·도서관의 노년을 담았다. 04에는 조이·톰·젊은 동료·어머니의 서로 다른 평가를 썼다. 생몰·나이·관계·소품의 이동·선택의 대가와 문장 난도를 점검했다.
- 그림: `apps/mobile/assets/stories/v3/masterton-woolshed-bg.jpg`(1254×1254)와 `masterton-helen.webp`(1024×1536, 알파 0~254)를 별도로 만들었다. 양모 작업대·빗자루·1960년대 작업장과 작업복을 맞췄고, 직전 맘루크 카이로 제본 공방과 시대·공간·직업·감정의 결을 달리했다.
- 검증: `corepack pnpm typecheck`, `corepack pnpm content:check`, `corepack pnpm test`, `corepack pnpm test:e2e` 통과. 첫 브라우저 검사에서 결과 계약의 80자 요약 제한을 발견해 평생 요약을 간결히 고친 뒤 `e2e/mobile-ring-in-broom.spec.ts`를 재실행해 통과했다. 320×720·768×1024에서 그림 로드, 01 세 쪽, 02~04 도달성, 가로 넘침과 카드 간격을 검사하고 실제 합성 화면을 살폈다. 라이브 카드·원고·고유 그림 매핑은 각각 83이며 ID 중복은 없다.
- 한계: 실제 독자 반응과 실기기 검증은 아직 없다. 기존 44편의 01·03 전수 보강도 미완료다. 커밋·푸시·배포하지 않았다.
