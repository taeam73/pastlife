# 키야 — 「다리 앞의 한 올」 마지막 순간 검수

확인일: 2026-10-24. 이야기 ID `THE_CORD_BEFORE_THE_BRIDGE`.

## 작품 정합성

- 키야는 1451~1514년, 63세. 1490년 사건 때 39세이며 마지막 장면은 24년 뒤인 1514년 쿠스코 고원 마을이다.
- 01의 언니에게 배운 첫 풀줄, 루미·딸·어린 친척과의 관계, 굳은 손가락을 03·04와 대조했다. 딸은 1480년 출생 설정으로 마지막 장면에서 34세 성인이다.
- 02의 약한 풀줄을 다시 꼬는 다리 공동 작업은 재현하지 않았다. 마지막 장면은 집 문가에서 어린 시절의 첫 줄을 딸에게 건네는 별도 사건이다.
- 딸·루미·언니의 죽음 이후 반응은 짧게 전생록 화자가 전한다. 딸이 02의 어린 조카와 혼동되지 않도록 본문에서 가족 관계를 명시했다.

## 역사와 창작의 경계

- [Metropolitan Museum의 남부 안데스 연표](https://www.metmuseum.org/toah/ht/08/sanc.html)는 1514년 쿠스코 고원이 타완틴수유 영역인 시기임을 뒷받침한다. [Smithsonian의 Q’eswachaka 자료](https://americanindian.si.edu/inkaroad/engineering/video/bridge-qeswachaka.html)는 현대까지 전승된 풀줄 꼬기와 현수교 기술을 설명한다. 현대 다리의 갱신 절차를 1514년 마을의 정확한 생활 기록으로 취급하지 않았다.
- 키야, 가족, 집, 첫 줄, 마지막 날의 대화·감정과 사후 반응은 모두 창작이다. 삽화는 1514년 주택의 정확한 복원이 아니라 시대와 기술에 맞춘 해석 그림이다.

## 제작·검증

- 기존 키야 투명 인물과 아푸리막 배경을 참조해 내장 imagegen으로 노년의 가족 장면을 생성했다. 최종 프롬프트 핵심은 ‘같은 키야를 63세로 자연스럽게 나이 든 모습, 쿠스코 고원 석조·초가지붕 집 문가, 딸과 루미, 짧은 풀줄, 다리 사건·현대 물건·문자 제외’였다. 최종 파일은 `apps/mobile/assets/stories/v3/the-cord-before-the-bridge-final-moment.jpg` (1536×1024)이다. 얼굴·직조 옷·장면 구성을 직접 확인했다.
- `final-moment:check` 19/120, `content:check`, 모바일 타입 검사, API E2E 2건을 통과했다.
- 인메모리 3.0 API와 웹 브라우저에서 여섯 답변→첫 테스트 광고→결과→두 번째 테스트 광고→마지막 순간→저장·공유 해제를 확인했다. 320px와 768px에서 삽화 로딩·가로 넘침을 확인했다.
- 실제 버튼으로 받은 A4 PDF는 10쪽, 2,161,784바이트이며 10쪽 모두 렌더링해 확인했다. 공유 이미지는 1080×1800 RGBA PNG로 열어 확인했다.
- 처음 웹 테스트는 `EXPO_PUBLIC_API_BASE_URL`로 잘못 실행해 기본 결과 로딩에 실패했다. 코드가 실제 읽는 `EXPO_PUBLIC_API_URL`로 서버를 재시작하자 통과했다. 이 실패를 작품 오류나 통과로 숨기지 않는다.
