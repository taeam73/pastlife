# 72번째 원고·그림 검수 — 「썰매 밑의 공」

- **결과:** `BALL_UNDER_SLED`를 72번째 라이브로 등록했다. 총 72/120편, 남은 48편.
- **선행 설정과 근거:** `docs/story-setting-register.md`에 1652년 네덜란드 공화국 홀란트 주 하를럼, 여성 안네케(1614~1677)의 가족·여관·노년까지의 생애를 집필 전에 기록했다. 암스테르담 시립기록관의 콜프 놀이 자료와 네덜란드 국립미술관의 17세기 중엽 얼음 풍경·하를럼 산업 자료를 확인했다. 특정 1652년 얼음판 기록이나 경기 실화를 주장하지 않으며 여관·경기·인물은 창작이다.
- **01:** 부모의 일과 피터르와의 여관, 리스·마르턴의 성장, 배우자와의 사별, 아들에게 일터를 넘긴 노년을 세 쪽에 소개했다. 성격·취향·가까운 사람·바람·걱정을 짧게 넣고 경기 하나로 평생을 정의하지 않았다.
- **02:** 상인의 공이 먼저 멈춘 뒤 아이의 썰매에 가려지고 얀의 공이 보이는 순서, 손님들의 잘못된 환호, 썰매를 치우고 줄로 거리를 재는 행동, 상인의 승리와 얀의 서운함을 검수했다. 돈을 거절해도 편파 소문이 바로 사라지지 않는다. `notice`·`speak`·`connect` 장면과 전생록 화자의 도입·마무리가 있다. 짧은 내기 규칙은 가상의 즉석 약속으로 명시해 후대의 정규 콜프 규칙과 섞지 않았다.
- **03·04:** 출생~사망 15개 연대기 사건에 결혼·자녀·부모 돌봄·일꾼·배우자 사별·일 이양을 담았다. 피터르·얀·리스·마르턴의 관점은 서로 다르다. 사건 시점 1652년 안네케 38세, 얀 고용 4년째와 생몰 연도를 맞췄다.
- **그림:** 별도 1280×1280 얼음판·여관 배경과 1024×1536 진짜 투명 인물 WebP를 API·모바일에 연결했다. 말뚝·공·썰매·줄·나무판이 원고에 나온다. 특정 실존 하를럼 여관·겨울날의 재현은 아니다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 72쌍 그림·투명도·매핑 검사, 다양성 검사, 콘텐츠·도달성·결과 단위 검사 27개, API E2E 2개 통과. Playwright `e2e/mobile-ball-under-sled.spec.ts`는 320×720·768×1024에서 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침 검사를 통과했다. 두 크기의 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않았다.
