# 연화 · 마지막 순간 검수

**기록 보존:** 이 문서는 종전 북·그릇·딸과의 평온한 저녁 장면을 검수한 기록이다. 당시 PDF·공유 파일 확인은 2026-10-25 새 원고·v2 삽화의 승인으로 세지 않는다. 최신 장면은 [재작업 기록](final-moment-deep-audit-the-ox-and-the-hemp.md)을 따른다.

- 2026-10-24 확인. `THE_OX_AND_THE_HEMP`는 1080~1149년, 고려 개경의 여성 삼베 장수 연화다. 마지막 장면은 1149년 69세, 딸 솔은 1108년 출생으로 41세다. 도윤은 1137년 먼저 사망했다.
- 02의 1120년 소·찢긴 삼베·보상 사건을 재사용하지 않았다. 어머니의 베틀 북, 도윤의 나무 그릇, 솔의 독립된 장터와 이웃의 베 짜기를 01·03·04에서 가져왔다. 인물 시점의 미련과 안도, 솔·이웃의 짧은 반응, 전생록 화자의 맺음말을 각각 확인했다.
- 역사 조건: 고려의 수도 개경과 시장은 [한국민족문화대백과의 상업](https://encykorea.aks.ac.kr/Article/E0027204), 당시 삼베·모시 사용은 [국립중앙박물관의 고려 직물 설명](https://www.museum.go.kr/MUSEUM/contents/M0701040000.do?arcId=14768&catCustomType=post&catId=93&cp=147&schM=view&sv=), 길쌈의 베틀·북은 [한국민족문화대백과의 길쌈](https://encykorea.aks.ac.kr/Article/E0008546)을 2026-10-24 확인했다. 연화·솔·도윤·이웃과 마지막 날의 대사·죽음 장면은 창작이다. 삽화의 집·복식도 특정 유적을 복원한 것이 아니다.
- 기존 투명 인물의 얼굴·옷 색을 참조해 69세 얼굴과 흰머리를 보정한 고유 1536×1024 삽화를 만들었다. 아트 URI와 모바일 정적 매핑을 확인했다.
- `final-moment:check` 16/120, `content:check`, 모바일 타입 검사, API E2E 2건을 통과했다. 인메모리 API에서 실제 6개 답변→첫 광고 완료→결과 잠금→두 번째 테스트 광고→320px·768px 마지막 순간→완독→PDF·PNG 해제를 웹에서 통과했다. 두 화면 가로 넘침 없음. 받은 A4 9쪽 PDF 전 페이지를 렌더링해 문단 잘림을 확인했고, 1080×1800 공유 PNG를 열어 글·배경·인물 합성을 확인했다.
