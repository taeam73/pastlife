# 77번째 원고·그림 검수 — 「잘린 빨랫줄」

- **선행 설정과 근거:** `docs/story-setting-register.md`에 1910년 영국령 인도 캘커타, 여성 아샤(1872~1940), 세탁 노동과 15개 생애 사건을 원고보다 먼저 확정했다. 영국도서관의 캘커타 발행 세탁터 엽서·여성 세탁 노동자 사진, 미국 의회도서관의 당시 세탁 직종·캘커타 정치 지위 자료를 확인했다. 여성 사진은 중부 인도 자료이므로 캘커타 촬영이라고 주장하지 않는다. 아샤·가족·염소·빨랫줄 사고·배달 손실은 창작이다.
- **01:** 어머니에게 일 배우기, 나빈과의 세탁 일·가족, 아이들의 독립, 나빈 사별, 미나와의 일, 손이 아픈 노년을 세 쪽으로 소개한다. 성격·취향·가까운 사람·바람·걱정도 짧게 담았다. 염소 소동 한 번으로 평생을 규정하지 않는다.
- **02:** 세탁터의 가벼운 농담 → 어린 염소가 줄을 몸에 감고 목까지 걸림 → 줄을 자르면 배달할 옷이 흙에 떨어지는 선택 → 답변별로 발견·보호·일손 연결의 실제 행동 → 재세탁·늦은 배달·세탁비 반환과 다음 주문 손실로 이어진다. 염소 주인, 손님, 아샤 가족에게 각각 다른 일이 중요함을 남겼다. 전생록 화자의 도입·마무리와 장면·대화·인과·대가를 확인했다. 교훈을 미리 설명하던 타라 독립 문장은 저녁 장면의 짧은 대화로 바꿨다.
- **03·04:** 출생~죽음 15개 이정표에 일뿐 아니라 결혼·두 아이·어머니와 남편의 죽음·타라의 독립·미나와의 관계·노년의 손 건강이 있다. 1910년 아샤 38세·타라 16세·지투 9세, 1940년 68세로 맞췄다. 나빈·타라·미나·그날 손님의 관점이 서로 다르다.
- **그림:** 1910년 동네 세탁터의 고유 배경 **1254×1254**와 아샤 **1024×1536** 실제 투명 WebP를 API·모바일에 연결했다. 첫 배경에는 1910년 화면에 부적절할 수 있는 큰 흰 돔이 있어 작은 벽돌집만 남는 새 그림으로 교체했다. 인물 주변에는 생성 이미지의 연한 투명 색이 남지만 실제 합성 화면에서 눈에 띄는 테두리나 텍스트 방해는 없었다. 두 폭의 첫 결과 스크린샷을 직접 확인했다. 직전 다라의 논·갈대·짙은 노동복과 달리 빨랫줄·흰 천·실내외 세탁 공간·밝은 면 사리와 다른 얼굴·자세가 보인다.
- **검사:** 전체 워크스페이스 타입·단위 검사, 77쌍 그림·투명도·매핑 검사, 다양성 4개, 콘텐츠 37개·점수 13개, API E2E 2개 통과. Playwright `e2e/mobile-cut-cloth-line.spec.ts`에서 320×720·768×1024의 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침·요약 패널 겹침을 검사해 통과했다. 첫 브라우저 시도는 화면 계약의 한 줄 요약 80자 제한을 찾아냈고 요약을 다듬어 다시 통과했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않는다.
