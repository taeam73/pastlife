# 3묶음 원고 후보 — 따뜻한 돌 배달부

상태(2026-10-22): **`WARM_STONES`로 라이브 승격, 현재 27/120편.** 선행 설정은 [신규 이야기 선행 설정 대장](story-setting-register.md#warm_stones--단우)에 원고보다 먼저 기록했다. 아래는 편집 대장이며 최종 결과 원고는 `packages/content/src/story-catalog-batch-03.ts`에 있다.

## 사건 영감과 창작 범위

1816년 ‘여름이 없던 해’에 나타난 이례적 한랭과 서리, 작물 피해에서 **따뜻해져야 할 때 다시 찾아온 추위 때문에 식량과 난방 계획이 함께 흔들린다**는 긴장을 빌렸다. [NOAA에 소장된 기후 관측 연구](https://repository.library.noaa.gov/view/noaa/22105)와 [1816년 기록 연구](https://repository.library.noaa.gov/view/noaa/45591)를 2026-10-22에 확인했다. 오르넬, 솔마루 골짜기, 단우, 화덕돌 배달 관습, 바구니를 바꾼 사건과 결말은 모두 창작이다. 실제 탐보라 분화나 역사 속 피해자를 이 이야기의 인물로 옮기지 않았다.

## 답변 신호 연결

| 신호 | 결과에 드러날 장면 |
| --- | --- |
| `notice` | 단우는 첫 꾸러미의 매끈한 끈을 보고 줄무늬 빵 끈과 다르다는 것을 알아차린다. |
| `repair` | 단우는 길을 되짚어 주문을 다시 맞추고, 다음 배달을 위해 두 바구니에 서로 다른 매듭을 만든다. |

## 편집 검토

- **흥미:** 늦봄의 눈과 빵 대신 도착한 돌이 첫 문장에서 질문을 만든다. 바뀐 바구니의 끈이 관찰 가능한 원인이다.
- **재미:** 돌을 받고 웃는 아이의 반응은 실수가 완전히 헛일만은 아니었다는 방향 전환이다. 빵을 기다리던 집과 돌을 기다리던 집 모두 남겨, 손쉬운 해피엔딩으로 끝내지 않는다.
- **공감:** 단우의 답변 신호가 관찰·되돌리기·사람에게 직접 말하기라는 서로 다른 행동으로 보인다. 지금의 독자를 부주의한 사람이라고 판정하지 않는다.
- **차별화:** `TASTER`의 음식 추리나 `FIREWORKS`의 겨울 축제와 달리, 배달 착오를 수습하는 작고 빠른 소동이다. 전쟁·재난 등 무거운 사건도 앞으로 후보에서 배제하지 않되, 이 편은 한랭 사건의 생활 압박만 빌린다.
- **승격 전 확인:** 화덕돌의 크기와 손에 닿는 온도, 두 바구니의 시각적 구분, 빵을 돌려 주문을 채우는 동선이 그림과 원고에서 모순되지 않아야 한다. 배경·인물 레이어, 320px·태블릿 크롭, API/콘텐츠·경로 검사를 통과한 뒤 라이브로 센다.

## 승격 검수

배경의 빵집·눈길·두 바구니와 인물 손의 빵·점토 돌은 같은 새벽빛에 놓였다. 첫 인물 원본에는 돌을 싼 천에도 빵과 같은 붉은 줄무늬가 있어 원고의 구분 단서와 충돌했다. 돌 천만 무늬 없는 색으로 고친 편집본을 채택했다. 320px에서는 배경의 바구니가 인물 뒤로 가려지지만, 인물 손의 두 꾸러미가 구별되고 제목·첫 문장·인물이 읽힌다. 768px에서는 빵집과 두 바구니도 드러난다. 두 폭 모두 가로 넘침이 없었다.

타입 검사, 전체 단위 테스트, 콘텐츠 검사(27쌍의 고유 그림과 경로 다양성), API E2E와 `warm-stones` 320px·768px 브라우저 검사가 통과했다. 브라우저 실행기는 점유된 기본 포트에서 서버 시작 오류를 냈지만 이미 열린 서버를 재사용한 대상 검사는 통과했다. 실제 독자의 이해도·공감과 실기기 화면은 아직 확인하지 않았다.
