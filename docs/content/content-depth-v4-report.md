# 콘텐츠 깊이 v4 반영 보고서

## 반영 결과

| 항목 | 반영 수량 |
|---|---:|
| 역사 배경 | 16 |
| 배경별 이미지 슬롯 | 3 |
| 앱에 연결된 이미지 슬롯 | 48 |
| 서로 다른 실제 이미지 | 48 |
| 직업별 고유 작업 에피소드 | 65 |
| 지역별 생활·전환 사건 | 65 |
| 관계 유형 | 4 |
| 관계 사건 | 16 |

작업 에피소드는 배경에 허용된 직업만 선택하며, 생활 사건은 배경의 실제 생활상 문장을 포함한다. 선택은 답변 해시와 기록 번호를 사용하므로 동일 결과에서는 동일한 콘텐츠와 이미지가 재현된다.

## 사용자 경험 변화

- 같은 배경에서도 `daily`, `work`, `turning` 중 서로 다른 이미지가 결정론적으로 노출된다.
- 청년기에는 선택된 직업에 맞는 작업 도구·행동·대가가 추가된다.
- 전환기에는 해당 배경의 생활 조건을 사용한 지역 사건이 표시된다.
- 관계 사건은 유형당 2개에서 4개로 늘어나 반복 가능성을 절반 수준으로 낮췄다.
- 심화 결과의 `인생을 바꾼 사건` 요약에도 새 지역 사건 제목과 선택 결과가 노출된다.

## 남은 제한

- 모든 역사 콘텐츠는 편집 검토 상태이며 전문 역사학자의 최종 감수는 별도 필요하다.
- 48개 이미지 슬롯은 모두 서로 다른 실제 이미지로 연결되어 있다.
