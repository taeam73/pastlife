# v4 역사 이미지 프롬프트 기록

## 공통 제작 규칙

- Use case: `historical-scene`
- 용도: 모바일 전생 결과의 가로형 대표 일러스트
- 화풍: 사실적인 재료 질감이 있는 시네마틱 페인터리 역사 일러스트
- 구도: 16:9, medium-wide, 중심부 안전 크롭, 행동이 한눈에 보이는 장면
- 인물: 왕이나 영웅보다 일하고 이동하고 서로 돕는 평범한 사람
- 금지: 글자, 로고, 워터마크, 마법 효과, 시대착오적 복식·도구·건축

## 장면 구성

각 배경은 다음 세 슬롯을 사용한다.

1. `daily`: 기존 v3 검수 이미지를 이어받은 일상·환경 장면
2. `work`: 해당 배경에 연결된 직업의 도구와 실제 행동이 보이는 장면
3. `turning`: 재난·부족·이동·공동체 결정 등 선택과 대가가 보이는 장면

## 생성 상태

- built-in ImageGen으로 신규 32장을 생성했다.
- 기존 검수 이미지 16장을 `daily` 슬롯으로 이관했다.
- `industrial-hanseong-work`와 `industrial-hanseong-turning`을 별도 장면으로 제작해 임시 중복 이미지를 교체했다.
- 따라서 현재 상태는 `48 슬롯 / 48 고유 이미지`다.
