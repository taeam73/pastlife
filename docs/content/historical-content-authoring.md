# 역사 콘텐츠 작성 기준

역사 배경은 `packages/content/src/historical/settings.ts`, 직업은 `occupations.ts`에서 관리한다. 새 배경은 안정적인 ID, 실제 연도 범위, 기존 지역·시대 ID, 직업 2개 이상, 구체적인 생활상 3개 이상을 반드시 포함한다.

각 생활상은 결과 서사에 바로 사용할 수 있도록 사람이 하는 행동, 사용하는 물건, 이동 방식 또는 공간을 명시한다. 현대 국가·민족 정체성을 과거에 그대로 투영하거나, 한 문화권을 전쟁·왕실·종교 하나로 환원하지 않는다.

출처는 배경마다 최소 2개를 기록한다. 박물관, UNESCO, 국가 기록·문화유산 기관의 자료를 우선하며 접속일과 어떤 사실을 뒷받침하는지 함께 쓴다. 내부 편집을 마친 항목은 `EDITORIAL_REVIEWED`, 관련 분야 전문가가 검토한 뒤에만 `HISTORICALLY_REVIEWED`로 바꾼다.

시각 브리프에는 환경과 복식을 구체적으로 적고, 시대착오·인접 문화 혼합·관광 이미지화를 막는 `avoid` 항목을 둔다. `fallbackAssetKey`는 실제 파일 제작 전에도 안정적으로 유지하며, 이미지 파일이 없으면 출시 준비 완료로 표시하지 않는다.
