1. 다섯 사용자 지정 복합 경위(`TWO_FINAL_FERRIES`, `SILVER_REED_MONSTER`, `KNEELING_PUPPET`, `OPEN_GOAL_LEFT`, `TWO_MARKET_VOICES`)는 가족·형사 절차·노모·강도 동선·수로를 먼저 확정한다. 이미 사용자 요청을 처리한 치매·심근경색·아픈 자녀·빙판 성공·중년 장애·무자녀 이웃 헌신 편은 이 17개에 중복 배치하지 않는다.
2. 나머지 열한 **창작 인물**은 위 사망 방식이 확정이 아니다. `LOOSE_HEM_RIDE`/`MOON_SIGNAL_WINDOW`, `TWO_SPOONS_DABBA`/`HOLLOW_STAGE_WALL`, 열병 후보들처럼 실질적으로 닮은 쌍은 병명·공간만 바꿔 등록하지 않는다. 서사 원고 전 02 사건·후일담, 같은 사인의 가장 가까운 세 편을 대조한다.
3. `FIRST_FLIGHT_CAMERA`는 실존 인물의 기록 가능한 끝을 별도 방식으로 처리한다. 실제 임종의 창작 장면을 승인 기준 통과로 세지 않는다.
4. 각 편의 설정 대장→01·필요한 02 후일담·03·04→마지막 장면/화자→고유 1024px 가로 삽화→앱 URI 순서를 지킨다. 17편을 한 비교판에서 관리하며 콘텐츠·타입·API/파일 매핑 검사는 묶음 끝에 실행한다. **PDF/공유 전편 검수는 120편 최종 원고·삽화 확정 후**로 미룬다.
