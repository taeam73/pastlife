# 105번 마누엘 마지막 순간 재작업 기록

2026-10-25, ID `THE_MOON_ON_THE_STAIRS`. **원고·삽화 연결 초안이며 새 편집 기준 승인 아님.** [생애 감사](life-deep-audit-the-moon-on-the-stairs.md)에서 기존 생애를 유지 후보로 분류했다.

## 기존과 새 장면

- 기존 등록 장면은 1935년 집에서 조카 루스에게 화분 자리를 정하게 하고 필라르가 지켜보는 대화 뒤 열린 창을 바라본다. 마누엘이 죽음에 이르는 몸의 변화는 없어 화자의 사망 진술로 건너뛴다. 붓 상자·파란 천·화분도 1900년 공연 일을 말년에 다시 끌고 온다.
- 새 장면은 1935년 흐린 오후, 칠레 비냐델마르에서 필라르의 집 가까이에 따로 얻은 방이다. 몇 주간 기력이 줄고 계단에서 숨이 찼던 마누엘에게 누나 필라르가 국을 가져온다. 마누엘은 창을 닫으려 일어서다 무릎이 풀려 탁자를 짚고, 필라르가 어깨를 받친다. 그는 루스를 부르겠느냐는 말에 잠깐만 있으라고 답한다. 다시 앉은 뒤 숨이 얕아지고 손이 떨어지며, 곁의 누나에게 답하지 못한다. 화자가 그날 방에서의 사망과 사후 도착한 루스·필라르의 반응을 전한다.
- 1862~1935년, 사망 73세와 1900년 38세의 공연·1906년 이주·따로 얻은 방이라는 생애는 유지했다. 오래된 무릎 통증이나 공연 선택을 죽음의 원인으로 연결하지 않았다. 병명과 직접 사인은 알 수 없다. 증상·국·대화·마지막 오후는 창작한 개인사다.

## 관계·표현·삽화

마누엘은 남성이므로 필라르를 `언니`라 했던 01~04·결과 카드·설정·기존 검수의 지칭을 `누나`로 바로잡았다. 루스는 필라르의 딸이자 마누엘의 조카이며 사망 장면에 없고 뒤늦게 도착한다. 아우렐리오의 1935년 생존 여부가 미설정이므로 사후 반응을 만들지 않는다. 그의 1900년 손실과 평가는 02·04에 남긴다.

기존 마지막 그림을 보존하고 `the-moon-on-the-stairs-final-moment-v2.jpg`를 새 장면 URI에 연결했다. 그림에는 의자에서 일어서다 탁자를 짚는 노년 마누엘, 어깨를 받치는 필라르, 국그릇·열린 창만 보인다. 루스·공연 달·붓·화분은 보이지 않는다. **1536×1024** 창작 삽화이며 주거·복식의 학술 복원이라고 단정하지 않는다.
