**2026-10-25 v2 재작업(기술 등록, 서사 승인 아님):** [현행 설정](story-setting-register.md)의 57세 여관 양도와 고개 아래 방으로의 이주를 기준으로 63세의 마지막을 새로 썼다. 창작 경위는 우물에서 돌아오던 초가을 오전, 바퀴가 빠진 돌 수레가 굽은 길에서 미끄러져 이루를 벽 쪽으로 밀어 크게 다치게 한 사고다. 수레꾼은 곁에 있고 조카는 사후 도착한다. 정확한 장기 손상·병명은 단정하지 않는다. 인형·7번 방·종이 모자·여관 작업대를 죽음 장면에 다시 쓰지 않았고, 조카는 사후에도 그 방을 손님에게 내준다. 기존 v1의 여관 임종과 아래 PDF·화면 검사는 **현행 v2의 검증 근거가 아니다.**

고유 삽화 `room7-final-moment-v2.jpg`는 1536×1024 새 파일이다. 높은 사선에서 굽은 돌길을 내려다보며, 벽으로 피하는 이루·넘어진 물통·바퀴 하나가 빠져 다가오는 돌 수레를 한 장면에 둔다. 생성 결과를 육안으로 확인해 금지된 쓰러짐·부축·도움을 부르러 뛰는 제3자 구도가 없고 원고의 사고 직전 순간과 맞는다고 판단했다. 이전 황갈색 여관 작업대 그림은 보존하되 앱 연결에서 제외했다. `content:check`·`final-moment:check` 69/120·모바일 타입·API 콘텐츠 E2E 통과. 작품별 전체 낭독·다른 사고 편과의 연속 비교·실제 320px/태블릿 화면은 아직 보류한다. 최종 데이터 확정 전 PDF·공유 파일을 새로 만들거나 열지 않았다. 전체 편집 승인 0/120, 출시 경험 완료 0/120이다.

**2026-10-24 재작업 판정:** 아래는 생애 보강 전의 기술·화면 검사 기록이다. 새 01·03·04에서 이루는 57세 조카가 7번 방을 객실로 쓰면서 고개 아래 다른 방으로 옮겨 인형을 고친다. 아래의 63세 **여관 아래층**에서 조카와 인형·종이 모자 곁에 눈을 감는 원고와 삽화는 거주지·관계·02 소품 사용을 다시 확인해야 한다. 원고·삽화를 재작업하고 전편을 읽어 검수하기 전까지 **새 편집 기준 승인에 포함하지 않는다**. 39세 비 오는 밤의 02 사건·답변 신호는 유지한다.

검수일: 2026-10-24 (KST)

- 기존 01·03 기준: 로엔 세계 길력 88~151년, 여성 이루, 비돌개 고개 여관. 57세에 조카에게 여관을 넘기고 아이들의 나무 인형을 수선했으며 63세에 비돌개에서 삶을 마쳤다. 어린 시절 만든 인형 둘과 손님이 접은 종이 모자를 아꼈다. 계단을 오르내리면 숨이 차는 날이 있었다.
- 새 장면: 151년 여관 아래층에서 인형 팔을 고치다가 조카에게 매듭을 맡기고, 열리지 않은 인형극과 비가 그친 뒤 걷고 싶은 마음을 생각한다. 조카가 여관을 이미 맡은 상태라 운영 역할이 거꾸로 되지 않는다. 질병의 원인이나 직접 사망 원인은 단정하지 않는다.
- 02와 구분: 원고의 비 오는 밤 7번 방을 손님에게 내준 사건을 다시 쓰지 않는다. 나무 인형의 손바닥 소리만 평생 이어진 감각으로 쓴다. 조카가 의자와 인형을 대하는 사후 반응은 새 창작 장면이다.
- 창작·사실 구분: 로엔 세계, 길력, 비돌개와 모든 인물·사건은 기존 작품의 허구 설정이다. 실존 역사나 확인된 사망 장면으로 설명하지 않는다.
- 전용 그림: 기존 젊은 이루 그림과 비돌개 여관 배경을 참조해 63세 모습의 새 삽화를 만들었다. 첫 시안은 너무 젊어 보였고, 두 번째 시안에서 얼굴·머리카락·손의 나이를 보정했다. 최종 파일 `room7-final-moment.jpg`는 1536×1024, 272KB이며 기존 배경이나 다른 마지막 삽화와 별도다. 나무 인형 둘, 종이 모자, 조카, 비 오는 창을 눈으로 확인했다.
- 자동 검사: `final-moment:check` 3/120, 콘텐츠 37개, API E2E 2개, content/mobile/API 타입 검사를 통과했다.
- 실제 웹 여정: 인메모리 3.0 API에 여섯 답변을 제출해 20번째 시도에서 이루 결과(`ROOM7`)를 선택했다. 320px 결과에서 잠긴 저장·공유 → 두 번째 테스트 광고 → 마지막 순간 읽기 → API `finalMomentRead=true` → 저장·공유 해제를 확인했다. 768px에서도 마지막 순간의 삽화·본문·끝 버튼 도달성과 가로 넘침 없음(`document=viewport=768`)을 확인했다. 브라우저 오류는 두 크기 모두 없었다.

- 남은 한계: 광고는 테스트용이며 운영 광고가 아니다. 네이티브 PDF 저장·이미지 공유와 실제 운영 DB의 읽음 상태 영속화는 미검증이다. 다른 117편의 마지막 순간 원고·삽화도 남아 있어 전체 경험 완료 편수는 0/120이다.
- PDF 편집 재검사(2026-10-24): 문단 경계와 별도 `전생록의 기록` 끝 장을 적용한 뒤 실제 이루 결과의 앱 버튼으로 다시 다운로드했다. 이번 PDF는 10쪽 A4이며 마지막 쪽을 렌더링해 맺음말이 첫 문장부터 시작하는 것을 확인했다. 앞선 9쪽 수치는 편집 조정 전 파일의 검사 기록이다.
