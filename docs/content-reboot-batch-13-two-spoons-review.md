# 53번째 라이브 검수 — 숟가락 두 개

**고빈드 파틸 · 남성 · 1882~1959년 · 1912년 영국령 인도 봄베이 관구 봄베이.** [선행 설정 대장](story-setting-register.md)에 시대·정치권·생애와 출처를 원고 전에 확정했다. [뭄바이 시 정부 역사](https://mumbaicity.gov.in/en/history/)와 [UNESCO의 빅토리아 터미너스 기록](https://whc.unesco.org/en/list/945/)은 도시와 역의 실제 배경을 뒷받침한다. [도시락 배달 조합의 공식 연혁](https://www.mydabbawala.com/index2.html)은 1890년 시작과 집에서 만든 점심의 직장 배달을 설명한다. **2026-10-22 확인**. 조합 사이트는 검색 색인으로 확인했으며 직접 열람은 403으로 제한됐다. 고빈드 가족·하리 부부·두 숟가락 사건과 대사는 창작이다. 정확한 노선·요금·배달 규칙을 역사적 사실로 주장하지 않는다.

## 원고 자체 검수

- **01** 이름·생몰·시대·일·성격·취향·가까운 사람·바람·걱정을 세 쪽에 넣었다. 평생 한 줄은 시골에서 봄베이로 이주, 배달 일, 가족, 아내와 연 차 가게, 사별과 딸 곁의 노년을 잇는다. 한 고객의 비밀을 고빈드 평생의 정의로 만들지 않는다.
- **02** 전생록 도입·마무리 사이에 레카의 직접 배달 부탁, 사흘간 달라진 손님의 동선, 사라진 하리, 수색, 실직 고백, 두 숟가락과 레카의 등장, 늦은 다음 배달의 대가를 대화와 장면으로 썼다. `notice`는 물잔과 가게 주인의 손짓을 살피고, `speak`는 가게 주인에게 물으며, `explore`는 역 주변을 직접 돈다. 고빈드는 레카 앞에서 장소를 숨기지 않지만 부부의 대화는 대신하지 않는다. 하리의 새 일자리는 즉시 생기지 않는다.
- **03** 출생부터 사망까지 이주, 동료, 혼인, 두 자녀, 어머니의 합가와 사별, 무릎 통증, 부부 차 가게, 자녀의 독립, 아내의 죽음과 노년 이사 등 17개 사실형 사건으로 구성했다. 1912년 30세·1959년 77세가 일치한다.
- **04** 사비타의 어깨끈, 딸과 읽던 시간, 차 가게와 무릎 통증, 아내·동료·딸·아들의 서로 다른 기억을 넣었다. 하리의 도시락만 되풀이하지 않는다.
- 인과 점검: 레카가 하리의 실직을 직접 듣지는 못했지만 전날 역에서 그를 보았으므로 두 숟가락을 준비해 찾아온다. 고빈드가 왜 노선을 벗어났는지, 마지막 배달과 품삯에 어떤 결과가 났는지 명시했다. 레카와 하리가 그날 집에서 무슨 결론을 냈는지는 단정하지 않았다.
