# 74번째 원고·그림 검수 — 「붉은 끈을 묶은 가방」

- **선행 설정과 근거:** `docs/story-setting-register.md`에 1908년 오스만 제국 베이루트 항구, 남성 일리야스(1886~1919)의 출생부터 이른 죽음까지 기록한 뒤 원고를 집필했다. AUB 항구·전쟁기 자료, 미국 의회도서관 베이루트 사진, 옥스퍼드 오스만 시대 이주 연구와 1908년 여행 일기를 확인했다. 지명·정치권·항구·알렉산드리아로의 이동 가능성·전쟁기 어려움은 역사 근거이며 일리야스와 가족, 가방, 감독의 결정은 창작이다. 특정 선박·운항일·항구 고용 규칙은 재현하지 않는다.
- **01:** 어린 시절 나무배 놀이·아버지 사별·항구 일, 동생과 친구, 파라와 가정, 전쟁기와 33세 병사를 세 쪽에서 소개한다. 성격·취향·바람·걱정은 짧은 사실형 문장으로 제시한다. 1908년 가방을 숨긴 행동 하나로 평생을 정의하지 않는다.
- **02:** 동생이 알렉산드리아로 떠나려 함 → 일리야스가 가방을 차양 밑에 숨김 → 미리암은 가방 없이도 떠나겠다고 함 → 답변별 장면에서 숨긴 곳을 밝히고 가방을 되찾음 → 미리암은 배에 타지만 즉시 용서하지 않음 → 일리야스는 임금과 일을 잃음. 전생록 도입·마무리, 감각·행동·대화·선택의 대가가 있다. 소지품을 이용해 다른 사람의 앞날을 막으려던 잘못을 사과만으로 지우지 않는다.
- **03·04:** 출생~죽음의 13개 이정표에는 어린 시절 친구, 가족 일, 동생의 독립, 어깨 부상, 결혼, 전쟁기의 생활, 이른 죽음이 있다. 1908년 일리야스 22세·미리암 19세, 1913년 27세, 1919년 33세를 맞췄다. 미리암·나빌·파라의 기억은 서로 다른 관계를 보여 준다.
- **그림:** 고유 베이루트 항구 배경 **1254×1254**, 인물 **1024×1536** 실제 투명 WebP를 연결했다. 항구 차양·붉은 끈 가방·증기선과 일리야스의 밧줄·복식이 원고에 맞는다. 실제 항구 특정 건물의 정확한 사진 복제는 아니다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 74쌍 그림·투명도·매핑 검사, 다양성 4개, 전체 콘텐츠 37개·점수 13개, API E2E 2개 통과. Playwright `e2e/mobile-red-cord-trunk.spec.ts`에서 독립 서버의 320×720·768×1024 화면으로 01 세 쪽, 02~04 도달성, 이미지 실제 로드와 가로 넘침을 검사해 통과했다. 두 폭의 첫 결과 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않는다.
