# 전생록 C 시안 확정 디자인 기준

## 확정 방향

전생록의 기본 UI 방향은 `C. 영화형 역사 장면`으로 확정한다. 사용자는 짧은 테스트를 진행하지만, 결과는 한 편의 역사 영화와 장면 목록을 탐색하는 경험으로 느껴야 한다.

## 핵심 화면 원칙

- 시작 화면: 역사 장면을 배경으로 한 영화 포스터형 진입 화면
- 질문 화면: 장면 위에 질문과 선택지를 배치하고, 선택지는 장면의 일부처럼 표현
- 결과 화면: 인물·시대·직업을 영화 포스터와 기록 패널의 조합으로 표현
- 챕터 탐색: 원형 썸네일 대신 직사각형 시네마틱 카드와 금색 타임라인을 사용
- 챕터 상호작용: 카드 선택 시 해당 장면의 상세 이야기로 이동
- 모바일: 챕터 필름스트립 가로 스크롤
- 태블릿: 챕터 카드 4개를 한 화면에 표시

## 시각 언어

- 배경: 짙은 남색, 차콜, 역사 장면 이미지
- 강조: 앤티크 골드, 절제된 앰버
- 텍스트: 아이보리·양피지 톤, 영화 포스터형 제목 처리
- 카드: 얇은 금색 테두리, 낮은 투명도의 어두운 패널, 필요한 경우 양피지 패널
- 모션: 장면 전환, 천천히 나타나는 텍스트, 선택 챕터 확대

## 보존 규칙

- 기존 질문 의미, 선택지 연결, 채점 방식, 결과 데이터 구조는 변경하지 않는다.
- 기존 전생 결과 이미지 자산은 계속 사용하고, 새 UI가 이미지 분위기를 보조한다.
- 320px 모바일과 태블릿 가로·세로 화면을 모두 지원한다.
- 모든 UI 수정은 공통 레이어와 인접 화면까지 종합 점검한다.
