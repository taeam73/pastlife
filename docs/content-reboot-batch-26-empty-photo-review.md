# 66번째 「사진 속 멈춘 손」 원고·그림 검수

2026-10-23. 작업 시작 시 라이브 카드·원고·그림 매핑은 65쌍이었고 새 ID와 겹치는 작업은 없었다. 등록 뒤 실제 배열을 다시 세어 카드 66, 원고 66, 그림 매핑 66, ID 중복 0을 확인했다.

## 먼저 확정한 실제 배경과 창작 범위

- 1866년 자바 세마랑, 네덜란드령 동인도. 당시 세마랑의 바틱 작업장 사진과 세마랑 레지던시 관련 1860년대 자료를 확인했다. 바틱의 밀랍·염색 원리와 1860년대 유리판 사진의 느린 촬영 절차도 확인했다. 근거 링크와 확인일은 [설정 대장](story-setting-register.md)의 EMPTY_PHOTO_SEAT 항목에 있다.
- 사리·와르시·라티·다르소·미나, 사진가, 사진 촬영을 둘러싼 다툼·품삯·주문 천·사진 결과는 모두 창작이다. 실제 미술관 사진의 모델이나 촬영 순간을 재현한다는 표현은 피했다. 1863~69년으로 표시된 실물 사진이 반드시 1866년 촬영됐다고 주장하지 않는다.
- 원고보다 먼저 사리의 출생·혼인·출산·어머니와의 일·남편의 병·딸의 다른 진로·일터 이전·눈의 피로·노년 교육·사망을 설정했다. 02는 그 평생에서 단 하루의 사진 촬영만 고른다.

## 01~04 원고 점검

- 01 전생의 나: 3쪽에 이름·성별·생몰·정치권·일·생활, 성향·취향·잘하는 일, 아낀 물건·관계·바람·걱정을 짧게 배치했다. 사진 한 장의 교훈으로 사리의 삶을 규정하지 않는다.
- 02 에피소드: 바틱의 원리를 풀어 설명하고, 촬영 중 뜨거운 밀랍을 든 손을 멈추라는 요구가 왜 천을 망칠 수 있는지 장면에서 보여 준다. 첫 판의 문제 → 어머니를 뺀 재촬영 제안 → 사리가 추가 촬영을 청하고 자기 품삯을 냄 → 주문 천이 늦어져 값이 깎임 → 사진을 본 세 사람의 서로 다른 반응으로 이어진다. 세 답변 갈래에는 관찰·천 보호·설명이 각각 실제 행동으로 나타난다. 사진가의 동의와 와르시 본인의 의사를 거쳐 촬영하며 손해는 그대로 남긴다.
- 03 삶의 기록: 1835~1896년, 출생부터 죽음까지 16개의 짧은 사건을 시간순으로 담았다. 02 밖의 배우자·딸·친구·어머니·일터·건강·돌봄도 담았다. 나이 표기는 각 연도와 맞는다.
- 04 전생의 기억: 도구·좋아한 순간·걱정·남긴 말과 와르시·미나·라티·다르소의 서로 다른 기억을 둔다. 라티의 늦어진 작업과 미나의 진로는 02 장면만으로 환원하지 않았다.
- 중학생 독자가 바틱을 이해하도록 첫 문단에서 뜻을 풀었다. 01~04의 인명·시기·관계·선택과 대가를 대조했다.

## 그림·앱 검사

- 고유 배경은 1280×1280 JPEG로 세마랑의 작업장 베란다·천·밀랍 도구·19세기식 나무 사진기를 그렸다. 별도 인물은 1024×1536 WebP, 실제 알파 채널이다. 바틱 천과 구리 펜을 든 31세 자바 여성으로 만들었다. API 자산 공급자와 Expo 정적 이미지 목록에 두 파일을 연결했다. 복식·도구의 세부가 박물관 보존품과 완전히 일치한다고 주장하지 않는다.
- content·api·mobile 타입 검사, 66쌍 그림 검사, 다양성 검사, 관련 Vitest 27개, API E2E 2개 통과.
- Playwright 결과 화면을 320×720 및 768×1024에서 검사했다. 배경·인물 각각 자연 폭 1024px 이상, 01의 3쪽 이동·가로 넘침 없음·요약 패널과 상단 문구의 수직 분리, 02~04 후반 문구까지의 도달성을 확인했다. 저장된 첫 화면 스크린샷도 직접 검토했다. 휴대전화 폭에서는 인물과 상단 소개문 사이가 좁지만 본문을 가리는 수준은 아니었다.

실제 독자 이해도·흥미, 실기기 성능, 앱 배포 상태는 이번 검사에 포함되지 않았다. 기존 44편의 01·03 보강도 별도 미완료다.
