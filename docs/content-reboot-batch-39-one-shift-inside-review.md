# 79번째 원고·그림 검수 — 유리창 안의 동생

- ID: `ONE_SHIFT_INSIDE`; 엘사 뉘스트룀은 1888~1964년 스웨덴 왕국 스톡홀름에 산 창작 인물이다. 1922년 여성 전화 교환원 파업, 당시 수동 교환 업무와 자녀가 있는 조합원의 추가 지원 제도는 [스톡홀름시의 파업 기록](https://stockholmskallan.stockholm.se/post/32572), [지원 기록](https://stockholmskallan.stockholm.se/post/32574), [파업 뒤 기록](https://stockholmskallan.stockholm.se/post/32575), [스웨덴 기술박물관의 전화 역사](https://www.tekniskamuseet.se/lar-dig-mer/100-innovationer/telefonen/)를 2026-10-23 확인했다. 개별 자매·가족·교환실·하루 근무·대화·빌린 돈은 모두 창작이다. 생애와 근거는 원고 전에 [설정 대장](story-setting-register.md)에 확정했다.
- 01: 아버지에게 숫자를 배운 어린 시절, 오래 한 전화 교환 일, 올레·카린과의 가정, 새 교환원 교육, 수선 가게 장부와 손자 돌봄의 노년을 세 쪽으로 제시한다. 파업 하루의 판단으로 평생을 규정하지 않는다.
- 02: 파업 첫날 유리창 안의 동생을 보는 장면으로 시작한다. 수동 전화 연결과 파업 이유를 짧고 쉽게 설명한다. 엘사는 집세 독촉장을 보고 동생의 말을 들은 뒤 조합 지원을 함께 확인한다. 자기 집 돈을 빌려주면서 카린의 신발 수선을 미루고 올레·동료와 갈등이 남는다. 동생은 다음 날 파업에 다시 서지만 모두가 즉시 화해하지는 않는다. 전생록 화자의 도입과 이후 삶의 마무리가 있으며 `notice`·`speak`·`connect` 장면이 각각 다른 행동으로 이어진다.
- 03: 출생부터 죽음까지 18개 사건으로 부모·배움·직업·결혼·자녀·자매·실직·파업·직무 변경·손자·사별·노년을 다룬다. 04에는 마르타·카린·올레·동료 안나의 서로 다른 시선이 있다. 생몰·나이·가족관계·대가의 전후와 문장을 대조했다. 원고의 올레 실직 기간 표현을 연대기와 맞도록 수정했다.
- 그림: `apps/mobile/assets/stories/v3/one-shift-inside-stockholm-bg.jpg`(1254×1254, 배경 단독)와 `one-shift-inside-elsa.webp`(1024×1536, 알파 0~254). 배경은 스톡홀름 거리의 교환소와 창 안 교환판, 인물은 1922년 노동자 복식의 34세 엘사로 그렸다. 앞선 폼페이 식당·캘커타 세탁터와 건축·도구·복식이 다르다. 특정 실존 건물의 재현이 아니라 역사 조건을 따른 창작 삽화다.
- 검증: `corepack pnpm typecheck`, `corepack pnpm content:check`, API E2E 통과. `e2e/mobile-one-shift-inside.spec.ts`에서 320×720·768×1024의 그림 로드, 01 세 쪽, 02~04 도달성, 가로 넘침과 카드 간격을 검사했고 실제 합성 화면을 확인했다. 처음 브라우저 검사는 80자 소개 제한과 임시 개발 서버의 HTTP 501로 실패했으나, 소개를 줄이고 서버를 다시 띄워 동일 E2E를 통과했다. 79개 원고·그림 매핑과 ID 중복 여부를 재확인했다.
- 한계: 실제 독자 반응과 실기기 검증은 아직 없다. 기존 44편의 01·03 전수 점검도 남았다. 커밋·푸시·배포하지 않았다.
