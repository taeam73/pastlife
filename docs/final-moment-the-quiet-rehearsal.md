# 쩐반호아 — 「소리 없는 밤의 박자」 마지막 순간 검수

확인일: 2026-10-24. 이야기 ID `THE_QUIET_REHEARSAL`.

## 작품 정합성

- 1819년 후에 출생~1887년 후에 사망, 68세. 1850년 대표 사건은 31세 때이며 마지막 장면은 37년 뒤다.
- 01의 친척에게 물려받은 나무채, 아내와 두 아이, 03의 후배 지도·빠른 곡 자리 양보·손자들과의 손뼉 놀이, 04의 서로 다른 평가를 대조했다.
- 02의 이웃집 아기를 깨운 밤 연습은 반복하지 않았다. 마지막 장면은 집 안뜰에서 손자가 건너뛴 박자를 호아가 들으며 아내에게 기대는 별도 장면이다. 아이·아내·후배의 반응은 확인된 개인 기록이 아닌 창작이다.

## 역사와 창작의 경계

- [UNESCO 나냐크 궁중음악 자료](https://ich.unesco.org/en/RL/nha-nhac-vietnamese-court-music-00074)는 응우옌 군주 아래 궁중 음악의 제도화와 타악기 역할을 설명한다. [미국 의회도서관의 베트남 연표](https://tile.loc.gov/storage-services/master/frd/frdcstdy/vi/vietnamcountryst00cima_0/vietnamcountryst00cima_0.pdf)는 1883·1884년 조약 뒤 안남이 프랑스 보호국이 됐고 1887년 인도차이나 연합이 성립했음을 설명한다. 1850년의 응우옌 왕조 후에와 1887년의 프랑스 보호국 안남을 구분했다.
- 호아·가족·동료·집·대사·마지막 날은 창작이다. 삽화는 후에의 특정 주택이나 실제 음악가를 복원한 자료가 아니다.

## 제작·검증

- 기존 호아의 투명 인물과 후에 안뜰 배경을 참조해 내장 imagegen으로 노년 가족 장면을 제작했다. 최종 프롬프트 핵심은 ‘같은 남성을 68세로 자연스럽게 늙힌 얼굴과 남색 일상복, 아내와 손자, 낮은 상의 낡은 나무채, 후에의 소박한 마당, 무대·유럽 가구·현대 설비 제외’였다. 최종 파일 `apps/mobile/assets/stories/v3/the-quiet-rehearsal-final-moment.jpg`는 1536×1024이며 화면에서 얼굴·복식·가족 구성을 확인했다.
- `final-moment:check` 20/120, `content:check`, 모바일 타입, API E2E 2건 통과.
- 인메모리 3.0 API와 웹에서 여섯 답변→첫 테스트 광고→결과→두 번째 테스트 광고→마지막 순간→PDF·공유 해제를 검사했다. 320px·768px 삽화 로딩과 가로 넘침 검사를 통과했다.
- 실제 버튼으로 받은 A4 PDF는 10쪽·1,966,631바이트다. 전 페이지를 렌더링해 확인했다. 공유 이미지는 1080×1800 RGBA PNG로 열었다.
- 공유 인물의 발끝이 배경 위에 떠 보이는 문제를 발견해 공통 네이티브 카드 위치와 웹 이미지 합성 위치를 낮췄다. 호아와 키야 웹 공유 이미지를 다시 받아 확인했다. 나머지 118편의 개별 합성 크롭은 여전히 전수 확인 대상이다.
