# 73번째 원고·그림 검수 — 「두 사람 몫의 목소리」

- **결과:** `TWO_MARKET_VOICES`를 73번째 라이브로 등록했다. 총 73/120편, 남은 47편.
- **선행 설정과 근거:** `docs/story-setting-register.md`에 1906년 브라질 공화국 페르남부쿠주 헤시피, 여성 벤타(1870~1937)의 독립 매대·동생·조카·제카와 리아·노년까지의 생애를 집필 전에 기록했다. 헤시피 시청·브라질 국립역사문화유산연구소·국립도서관의 상 주제 시장 건축과 1906년 수리 기록, 국립기록원의 당시 공화국 기록을 확인했다. 시장의 실제 임시 매대 배치와 벤타의 과일값 사건은 창작이다.
- **01:** 어머니의 일 배우기, 독립 매대, 마리아나·토마스와의 생활, 후배 리아에게 일을 넘긴 노년을 세 쪽에 소개했다. 성격·취향·가까운 사람·바람·걱정을 짧게 담았다. 목이 쉰 하루로 평생을 규정하지 않았다.
- **02:** 벤타가 값을 두 줄로 적음 → 제카가 망고의 수와 바나나의 값을 섞어 외침 → 손님이 몰려 판이 가려짐 → 벤타가 답변별로 판을 옮기거나 양철컵을 치거나 제카와 함께 값을 확인함 → 제카가 이미 판 차액을 보전하고 벤타는 눌린 과일을 낮은 값에 판매함으로 이어진다. 전생록 화자 도입·마무리, 장면·대화·선택·대가가 있다. 사과 뒤에도 두 사람의 손해가 남는다.
- **03·04:** 출생~사망 14개 사건에 학교 중단, 독립 매대, 모친 사별, 동생·조카와의 집, 동료 우정, 돌봄, 일의 전수와 신체 변화가 들어 있다. 마리아나·제카·토마스·리아의 평가는 서로 다르다. 1906년 벤타 36세, 1912년 토마스 12세, 1918년 토마스 18세 등 연도를 맞췄다.
- **그림:** 별도 **1254×1254** 시장 배경과 **1024×1536** 실제 투명 인물 WebP를 API·모바일에 연결했다. 철골 지붕·과일·생선·석판과 벤타의 옷차림·분필이 원고와 맞는다. 최초 배경의 항구가 시장 바로 옆에 보이는 구도를 보류하고 도시 거리로 고친 두 번째 배경을 사용했다. 실제 1906년 시장 내부의 사진 재현을 주장하지 않는다. 직전 하를럼 겨울 여관과 계절·색·건축·인물 실루엣이 구별된다.
- **검사:** 콘텐츠·API·모바일 타입 검사, 73쌍 그림·투명도·매핑 검사, 다양성 4개, 전체 콘텐츠 37개와 점수 13개, 집중 콘텐츠·결과 단위 검사 56개, API E2E 2개 통과. 확장 전 44편에 고정된 기존 테스트 두 곳을 최소 44편 기준으로 고치고, 이름·당시 지역 표기가 줄어 있던 기존 세 카드의 소개문을 명확히 한 뒤 전체 콘텐츠 테스트를 재실행했다. Playwright `e2e/mobile-two-market-voices.spec.ts`가 독립 서버에서 320×720·768×1024의 01 세 쪽·02~04 도달성·이미지 실제 로드·가로 넘침을 검사해 통과했다. 두 폭의 첫 결과 스크린샷을 직접 확인했다.
- **한계:** 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 점검은 남았다. 커밋·푸시·배포는 하지 않았다.
