# 109번째 원고 검수 — 상자 둘이 바뀐 아침

2026-10-23. `THE_TWO_TRUNKS_AT_LEVUKA`는 1882년 영국령 피지 식민지 레부카를 배경으로 한 창작 인물 루이사의 이야기다. 집필 전에 [설정 대장](story-setting-register.md)에 시대·장소·정치권·생몰·평생·역사 근거를 확정했다.

## 역사 조건과 창작

- [유네스코 레부카 역사 항구](https://whc.unesco.org/en/list/1399), [피지 정부의 레부카 연설](https://www.fiji.gov.fj/Media-Center/Speeches/FIJIAN-PRESIDENT-H-E-RT-EPELI-NAILATIKAU-AT-STATE-), [ANU Press 수도 이전 연대기](https://press-files.anu.edu.au/downloads/press/n10434/html/chronology.xhtml?page=5&referer=)로 1882년의 식민 정치권과 레부카·수바 관계, 항구·목조 건물·부두를 확인했다. [케임브리지 고고인류학 박물관](https://maa.cam.ac.uk/fiji-duftys-studio)과 [테파파 1884년 나소바 사진](https://collections.tepapa.govt.nz/object/21094)은 당시 외양·거리 참고 자료다. 확인일은 2026-10-23이다.
- 루이사와 가족·숙박집·손님·매듭·상자 소동은 모두 창작이다. 특정 1882년 정부 이삿날이나 사진 속 실존 인물의 생애를 재현하지 않는다. 그림의 복식·건물은 자료를 참고한 상상이며 정확한 유물 복원으로 주장하지 않는다.

## 원고와 그림

- 01은 어머니의 항구 장사에서 동생과 숙박집을 연 중년, 수도 이전 뒤 축소 운영, 조카에게 일을 넘긴 노년까지 요약한다. 02의 하루를 평생의 교훈으로 쓰지 않았다.
- 02는 상자가 바뀐 원인, 매듭을 알아보는 행동, 부두까지의 추격, 손님 둘의 안도와 빈방 값의 손실을 대화와 장면으로 썼다. `notice`·`speak`·`connect`의 서로 다른 행동을 반영했다. 03은 1841~1913년 생애 13지점, 04는 리티아·아나·타베가 각자 기억한 루이사를 담았다.
- 1254×1254px 고유 레부카 항구 배경과 알파 채널이 있는 투명 인물 그림을 API·모바일 결과에 연결했다. 나무 상자 두 개와 끈 매듭이 배경·인물에 이어진다.

## 확인 범위

타입, 콘텐츠·그림·다양성, 단위, API E2E 검사와 질문의 여섯째·다섯째 보기를 택하는 320px·768px 브라우저 결과 검사가 통과했다. 세 소개 페이지와 태블릿 결과 화면을 직접 확인했다. 실제 독자 반응과 물리적 기기, 복식·건축의 정밀 고증은 미검증이다. 기존 44편의 01·03 전수 점검도 남았다.
