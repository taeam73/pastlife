# 기존 3.0 원고 33편 개편 검수 기록

범위: 현재 `storyCards`에서 선택 가능한 33편. [작성·검수 기준](story-authoring-standard.md)의 01 전생의 나, 02 에피소드, 03 삶의 기록, 04 전생의 기억을 `story-manuscripts-batch-01.ts`~`03.ts`에 모두 적용했다. 02는 답변 신호별 문장이 장면에 들어가고, 전생록의 도입·사후 마무리를 갖는다. 03은 사건 한 장면 외에 어린 시절부터 생의 끝까지 기록한다.

## 발견·수정한 공통 문제

- 4장의 기존 짧은 사건 분할을 교체했다. 01은 시대·지역·성별·생몰·삶 요약, 02는 독립적인 사건, 03은 평생의 사건, 04는 인물의 결을 담는다.
- 3묶음 원고의 사건 당시 나이가 선행 설정과 다른 여러 편을 발견해 신원·연대기를 수정했다. 생몰 차이와 설정 연령 범위는 콘텐츠 검사로 고정했다.
- 경성 전당포 이야기에서 하루 늦으면 무조건 한 달 이자가 붙는다는 일반화 대신, 이야기 속 점포 전당표의 늦은 날 이자로 좁혔다.
- 첫 비행 원고의 실제 인물 생몰·결혼·직업 전환을 자료와 맞추고 창작 대사를 표시했다. 달 착륙 원고는 첫 화면 신호의 실제 출처와 허구 수리공을 분리했다.
- 모바일 본문 페이지 나누기가 문단·연대기 줄을 지우던 문제를 고쳤다. 긴 오르 원고에서는 페이지 번호와 실제 가로 스크롤 위치가 어긋나 마지막 문장이 잘리는 문제도 발견해, 본문을 한 페이지씩 직접 표시하도록 고쳤다. 04의 항목 제목과 내용이 서로 다른 페이지로 갈라지거나 하단 버튼과 겹치는 문제는 항목별 페이지 묶음으로 해결했다. 320px·768px 브라우저에서 01~04와 가장 긴 02의 첫·마지막 페이지를 확인했다.

## 검수 범위의 한계

원고 검토와 자동 검사, 브라우저 확인은 제작자의 자체 검수다. 실제 독자의 이해도·재미·공감과 실기기 가독성 평가는 아직 수집하지 않았다. 이를 완료된 독자 검증으로 표기하지 않는다.
