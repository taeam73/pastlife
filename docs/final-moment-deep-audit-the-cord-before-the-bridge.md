# `THE_CORD_BEFORE_THE_BRIDGE` 마지막 순간 심화 감사

2026-10-25 기준. 01~04, 02의 세 답변 신호, 결과 카드, 설정 대장, 등록 마지막 원고와 삽화를 대조했다. 이 문서는 재작업 범위 판정이며 서사 승인이 아니다.

## 확정된 삶과 미설정

- 키야는 창작 인물이다. 1451년 타완틴수유의 쿠스코 고원 마을에서 태어나 1514년 같은 고원에서 63세에 죽는다. 1490년 무렵 39세 때 조카와 꼰 풀줄의 약한 곳을 사람들 앞에 보여 주고 다시 만들었다. 기다리던 공동 작업과 식사가 늦었고 조카는 창피함과 서운함을 오래 기억했다. 키야를 무조건 옳은 스승으로 마무리할 수 없다.
- 어머니가 아픈 시기에는 언니와 돌봄을 나누면서 먼 공동 작업을 줄였다. 1498년 젊은 일꾼과 방법을 두고 다퉜고, 1504년 딸이 따로 살게 된 뒤에도 곡식과 풀을 주고받았다. 1509년 손가락이 뻣뻣해져 재료 고르기와 어린 친척 교육으로 일이 바뀌었다. 루미는 바깥일을 그리워한 키야를, 딸은 다정하면서도 간섭하는 어머니를 기억한다. 언니는 키야가 먼저 자기 말을 했다고 평가한다.
- 1514년의 직접 사망 경위, 마지막 날에 딸·루미가 곁에 있었는지, 손가락의 변화와 죽음의 관계는 원래 01~04에서 **미설정**이다. 등록된 문가의 마지막 대화와 동석은 창작 장면이다. 손가락 통증이나 가슴의 불편을 확정된 병명·사인으로 올리지 않는다.

## 판정과 작업 순서

**등록 마지막 원고·삽화 재작업.** 현재 원고는 첫 줄을 딸에게 주고, 풀을 골라 주라는 말을 루미에게 남기고, 내일 들어올 재료를 생각하다 눈감는다. 1490년 02와 직업의 안전 판단을 다시 삶의 결론으로 삼는다. 숨이 어떻게 끊기는지는 인물 시점에서 보이지 않고 전생록 화자가 뒤늦게 사망을 선언한다. 화자의 첫 줄 보관·다음 삶 첫 장 문형도 다른 편과 겹친다.

63세 생몰과 1490년 사건은 지금 유지한다. 20~50대 결과를 늘리려고 1498년의 다툼, 1504년 딸 독립, 1509년 이후의 생활을 자동으로 지우지 않는다. 먼저 어머니 돌봄의 기억, 바깥일을 그리워한 마음, 딸의 독립을 존중하거나 간섭했던 후반 생활을 설정·01·03·04에서 구체화한다. 조카의 서운함을 마지막 한마디로 화해시키지 않는다. 그다음 인물의 실제 생활에서 새 마지막 하루와 사망 경위를 고르고, 새 경위는 창작 설정이라고 표시한다.

**2026-10-25 재작업 초안:** 1485년 언니에게 남은 밤 돌봄과 1504~1506년 딸의 독립·방문 경계선을 01·03·04·결과 카드·설정 대장에 반영했다. 마지막은 1514년 집에서 루미가 물을 건네는 아침으로 다시 썼다. 키야는 며칠째 열이 나고 호흡이 어려워졌으며, 딸과 언니는 사후에 온다. 병명·직접 사인은 미설정이다. 39세 인물 참조로 63세 얼굴을 만든 새 고유 그림 `the-cord-before-the-bridge-final-moment-v2.jpg`를 연결하고 원본 그림은 보존했다. 새 장면은 02의 풀줄과 마지막 기술 인계를 쓰지 않지만, 다른 병상 장면과의 유사성 및 낭독·고증·실제 화면을 다시 확인하기 전이므로 서사 승인으로 세지 않는다.
