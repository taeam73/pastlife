# 115번째 「케이크가 없던 생일」 검수

- **완료:** 2026-10-23. 착수 때 실제 `storyCards`·원고·그림 매핑 114쌍을 다시 세었다. 앞선 아보메 장터 수리 일꾼과 시기·지역·일·가족 중심의 소동이 겹치지 않는다. 신규 등록 뒤 115편과 고유 배경/인물 115쌍을 확인했다.
- **선행 설정:** [설정 대장](story-setting-register.md)에 1948년 연합국 분할 점령 베를린의 미국 관할 구역, 로테 노이만의 창작한 1888~1962년 생애, 가족·빵집·전쟁·노년의 변화와 생일 사건을 집필 전에 확정했다.
- **역사와 창작:** [독일 연방기록원](https://www.bundesarchiv.de/themen-entdecken/online-entdecken/dokumente-zur-zeitgeschichte/waehrungsreform-und-berlin-blockade/), [연합군 박물관](https://www.alliiertenmuseum.de/wp-content/uploads/2021/06/03-Lecture-Text.pdf), [베를린시 역사 자료](https://www.berlin.de/ba-tempelhof-schoeneberg/ueber-den-bezirk/historisches/artikel.1330468.php)를 2026-10-23 확인했다. 봉쇄·배급 부족·공수 보급과 정치적 지위는 역사 배경이다. 로테와 가족, 빵집, 생일, 케이크 대신 쓴 초·종이 왕관, 대화는 창작이다. 실제 배급 규정의 우회나 실존 가게의 기록으로 주장하지 않는다.
- **원고 검수:** 01 세 쪽은 생몰·일·생활, 성격·취향·관계·바람·걱정을 읽기 쉬운 프로필로 담았다. 삶 한 줄은 아버지 가게에서 배운 어린 시절, 결혼·딸·빵집, 전후 재개, 노년의 장부와 화분까지 이어지며 02 결말을 미리 말하지 않는다. 02는 전생록 화자의 도입·마무리 사이에 빈 재료 자루·문 앞 친구·아이의 실망·늦은 사과·초와 이야기·딸과의 대화를 장면으로 썼다. 03은 사건 밖의 출생부터 사망까지, 04는 오래 한 일·남긴 말과 딸·손녀·단골의 다른 평가를 담았다. 1948년 60세와 손녀 7세, 1962년 74세, 딸 1918년 출생과의 관계를 대조했다.
- **그림:** 사람 없는 1254×1254px 창작한 서베를린 빵집과 별도 1024×1536px 투명 인물을 제작했다. 장부·소박한 빵·초·창밖 비행기와 로테의 1940년대 원피스·제빵 앞치마가 원고에 맞는다. 인물은 만화 외곽선 없는 사실적 화풍이며 원본 알파 범위 0~254를 확인했다. API·모바일에 고유 경로를 연결했다. 특정 역사 건물·군 소속 비행기·실제 당시 가게의 정밀 복제는 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e` 통과. 콘텐츠 검사에서 다른 115개 1024px 이상 배경/투명 인물 쌍과 모바일 경로 231개(115쌍+오류 시 1개)를 확인했다. API 그림 단위 검사 통과. 전용 브라우저 E2E에서 질문당 보기 6개, 첫 질문 여섯째·둘째 질문 다섯째 선택, 01 세 쪽과 02~04 도달성, 320×720px·768×1024px 그림 로드·가로 넘침을 확인했다. 두 폭의 실제 첫 화면을 육안 확인했다.
- **한계:** 320px 첫 화면에서는 프로필 카드가 인물 몸 대부분을 가린다. 내용과 페이지 이동은 가능하다. 실제 독자 반응·실기기, 당시 개인 빵집의 정확한 내부·복식 재현, 기존 44편 01·03 전수 보강은 미검증이다. 커밋·푸시·배포 없음.
