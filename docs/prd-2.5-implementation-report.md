# 전생록 PRD 2.5 구현 보고서

## 반영 결과

PRD 2.0의 질문 데이터, 점수 계산, 광고 해금, 로그인, 아카이브를 유지하면서 2.5 변경을 기존 수직 흐름에 통합했다. 데이터베이스 변경은 추가형 마이그레이션으로 구성했으며 기존 결과를 재계산하거나 삭제하지 않는다.

| 변경 | 반영 내용 | 주요 검증 |
|---|---|---|
| CHG 01 | 설치 식별자별 최근 10개 세션의 질문을 우선 제외하고 세션·단계별 선택을 즉시 고정 | 같은 단계 재호출 동일성, 다음 세션 단계별 질문 비중복 E2E |
| CHG 02 | 새 세션의 `viewMode` 기본값을 `VIDEO`로 설정 | 생성 응답과 결과 상태 검사 |
| CHG 03 | 기본·심화·현생 가이드가 공통 `ResultExperience`에서 영상형과 텍스트형을 제공 | 타임라인 단위 테스트, 모바일 타입 검사 |
| CHG 04 | `VIDEO`와 `IMAGE` 공유 자산 API, 별도 공개 `shareId`, 딥링크와 Play 폴백 메타데이터 제공 | 두 포맷이 기본 결과와 같은 원본 URI를 쓰는 E2E |
| CHG 05 | 결과 이미지 최초 조회 시 결과 ID별 단일 작업으로 생성하고 저장 후 모든 결과·공유에서 재사용 | 동시 작업 캐시와 저장소 멱등성, 공유 URI 검사 |
| CHG 06 | BGM·효과음·동작 줄이기 기기 설정과 영상형 음소거 제어 제공 | 모바일 타입 검사 |
| CHG 07 | 2.5 메인 카피, 직감 안내, `전생 기록 No.XX 발견` 표현 적용 | 브라우저 여정 검사 |
| CHG 08 | 기본·심화·가이드 종료 지점에서 새 세션을 만드는 재탐색 CTA 제공 | 설치 식별자를 유지하면서 새 세션 생성 |
| CHG 09 | 메인·나의 전생·설정 내비게이션을 일반 화면에만 표시하고 질문·분석·결과에는 표시하지 않음 | 라우트 구조와 브라우저 여정 검사 |
| CHG 10 | Android 링크 호스트·패키지·Play URL을 환경 설정으로 분리하고 공유 소스·포맷을 링크에 포함 | API E2E 및 Expo 설정 검사 |

## 출시 후보 사용자 화면 마감

- 아카이브 목록에서 소유권이 검증된 저장 기록 상세로 이동
- 영상·이미지 공유의 독립적인 생성·완료·실패·재시도 상태 표시
- 광고 해제 중복 탭 차단과 실패 시 현재 기록 보존·재시도 안내
- 설정에서 계정 상태 확인, 로그인 이동, 확인형 로컬 로그아웃 제공
- 로그아웃 뒤에도 현재 세션과 결과가 유지되는 브라우저 여정 검증

## 이미지와 공유 상태

결과 상태를 최초 조회할 때 저장 이미지가 없으면 AI 이미지 API에 같은 `answerHash`를 멱등 키로 보내며 생성 장수 `n: 1`과 품질 `quality: low`를 고정한다. 결과 ID별 동시 작업을 하나로 합치고, 실패 시 한 번만 재시도하며 두 요청이 모두 실패하면 라이브러리 이미지를 `FALLBACK` 상태로 저장한다. 저장된 한 장은 기본 결과, 심화 결과, 현생 가이드, 이미지 공유, 영상 공유 템플릿에서 재사용되며 별도 사용자 선택이나 재생성을 요구하지 않는다.

이미지 공유와 영상 공유는 포맷을 명시적으로 분리한다. 현재 저장소에는 운영용 H.264/AAC 인코더가 없으므로 영상 자산은 `TEMPLATE_READY`로 반환한다. 이는 MP4 파일이 생성됐다는 의미가 아니며, 렌더 워커가 연결되기 전 클라이언트는 딥링크 공유를 제공한다.

## 출시 전 필요한 운영값

- 실제 AI 이미지 모델, 비용 상한, 프롬프트 및 안전 정책
- 결과 분류별 대체 이미지 수량과 저작권 정보
- 상업 이용 및 영상 재배포가 허용된 BGM·효과음 파일과 라이선스 증빙
- Android 패키지명, 검증된 App Links 도메인, Google Play 상세 URL
- 공개 공유 미리보기 서비스와 MP4 렌더 워커
- 지원 locale 우선순위와 번역 검수 책임자

## 검증 결과

- 전체 workspace TypeScript 타입 검사 통과
- 전체 단위 테스트 통과: content 3건, scoring 7건, API 17건, mobile 1건
- API 수직 흐름 E2E 통과: 질문 고정, 이전 세션 질문 제외, 이미지 폴백, 광고 해금, 공유 자산, 로그인과 아카이브
- Playwright 브라우저 E2E 2건 통과: 모바일 전체 결과 여정과 관리자 게시·롤백
- Expo web 정적 export 12개 라우트 생성 성공
- Prisma schema validation과 `git diff --check` 통과

## 후속 구현 범위

다음 항목은 운영 자산이나 별도 실행 인프라가 있어야 실제 완료 상태가 된다.

- `TEMPLATE_READY` 영상 공유 자산을 실제 H.264/AAC MP4로 인코딩하는 렌더 워커
- 라이선스가 확정된 BGM·효과음 바이너리의 실제 재생과 오디오 포커스·덕킹
- 검증된 App Links 도메인의 `assetlinks.json` 배포와 공개 공유 미리보기
- 질문별 `next_bias`, 조건 태그, 가중치를 운영 콘텐츠에 입력한 뒤 선택 가중치 계산 연결
- 분석 이벤트의 운영 보존 기간·삭제 정책과 대시보드 또는 외부 분석 싱크
