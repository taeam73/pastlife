# 유수프 마지막 순간 검수 기록

2026-10-24 기준. `CRACKED_PIGEON_TOWER`의 유수프·시마·랄레·파르하드, 가족의 마지막 대화와 사후 반응은 **모두 창작**이다. 실제 배경은 **1653년 사파비 왕조 이란 이스파한 외곽**이다. 2026-10-24 다시 확인한 [Antiquity 현장 연구](https://www.antiquity.ac.uk/projgall/pourjafar327/)는 이스파한 주변의 흙·어도비 비둘기탑, 다수의 둥지 구멍, 농지 거름용 비둘기 배설물과 사파비 시대 건립 추정을 뒷받침한다. [Encyclopaedia Iranica](https://www.iranicaonline.org/articles/isfahan-vii-safavid-period/)는 이스파한의 사파비 통치를 확인한다. 어느 자료도 유수프 개인이나 1653년의 구체적 마지막 날을 기록하지 않는다.

## 01~04와의 연결

- 1576~1653년·77세 남성, 다친 발목과 말년의 약한 어깨, 농지·비둘기탑 관리, 아내 시마와 딸 랄레가 곁에 있는 기존 생애 기록을 유지했다. 랄레는 1603년생이므로 이때 50세다. 시마의 사망 연도는 원고에 없으므로 1648년 함께 지냈다는 기록과 모순되지 않는 범위에서 마지막 곁에 둔 **창작 선택**이다.
- 04의 오래 쓴 **나무 흙손**, 돌아오는 날갯소리, 랄레가 기억한 첫 멜론, 시마가 기억한 발목 통증을 장면의 소품과 대화로 바꿨다. 02의 뱀·깨진 벽·조수 오판 사건을 마지막 장면의 갈등으로 반복하지 않았다. 파르하드가 훗날 제 밭을 얻은 기록을 유지해 마지막 장면에는 등장시키지 않고 화자의 짧은 사후 반응에만 넣었다.
- 유수프는 내일 다시 탑을 보고 싶어 하는 아쉬움과, 딸·젊은 일꾼이 일을 이어가는 안도감을 함께 느낀다. 마지막은 인물 시점의 소리와 감각으로 닫고, 전생록 화자가 남은 사람들의 짧은 행동과 다음 삶으로 넘어가는 여운을 받아 마무리한다.

## 그림·앱 검사

- 내장 **imagegen**으로 기존 유수프의 얼굴·옷, 기존 비둘기탑 배경을 참고해 새 그림을 만들었다. 최종 편집 지시는 무릎의 금속날 도구를 **온전히 나무로 된 흙손**으로 바꾸고 인물·탑·멜론·시대 구도를 보존하는 것이었다. 최종 프로젝트 자산은 `apps/mobile/assets/stories/v3/cracked-pigeon-final-moment.jpg`, **1536×1024, 375,104바이트**다. 아내·딸의 외형, 집·옷의 세부, 날씨는 자료를 바탕으로 한 창작 시각화다.
- `final-moment:check` **12/120**, `content:check`(기본 120 그림쌍 포함), 모바일 타입, API E2E **2건** 통과. 실제 여섯 답변으로 유수프를 선택하는 `e2e/mobile-final-moment-historical.spec.ts`가 320px 결과 잠금 → 두 번째 테스트 광고 → 마지막 순간과 그림 → 읽음 기록 → 결과 PDF·공유 해제 흐름에서 통과했다. 320px·768px의 가로 넘침과 본문 끝 도달도 확인했다. 지명이 320px에서 한 글자만 다음 줄로 밀려 장소 문구를 줄인 뒤 **같은 검사 1건을 재통과**했다.
- 웹에서 받은 PDF를 다시 열어 **A4 10쪽, 약 2.1MB**임을 확인하고 10쪽 모두 렌더링해 표지·01~04·마지막 삽화/장면·화자 맺음말을 직접 확인했다. 공유 PNG는 **1080×1800 RGBA**로 열어 배경·인물·91번째 표기·생몰·관계·삶 한 줄이 읽히는지 확인했다. PDF는 이미지형이므로 검색·복사가 되지 않는다. 검사 산출물은 `output/playwright/yusuf-record.pdf`, `yusuf-pdf-contact.jpg`, `yusuf-share.png`다.
- 실제 Android/iOS 시스템 공유창·파일 저장, 운영 광고, 영속 DB, 다른 108편의 마지막 순간과 전편 UI 검사는 남아 있다. 따라서 전체 출시 경험 완료로 세지 않는다.
