# 91번째 원고·그림 검수 — 이야기의 남은 반

## 선행 설정과 역사 경계

- `docs/story-setting-register.md`에 집필 전 **1655년 이스파한, 사파비 왕조**, 카림(남성, 1614~1678)의 가족·직업·후배·노년과 대표 사건을 확정했다.
- [유네스코 메이단 에맘](https://whc.unesco.org/en/list/115), [메트로폴리탄 미술관 이스파한](https://www.metmuseum.org/fr/essays/shah-cabbas-and-the-arts-of-isfahan), [이란학 백과사전 사파비 이스파한](https://www.iranicaonline.org/articles/isfahan-vii-safavid-period/), [커피하우스 문화](https://www.iranicaonline.org/articles/coffeehouse-qahva-kana/)를 2026-10-23에 확인했다. 도시·정치권·광장·커피하우스의 이야기 문화는 역사 근거이고, 인물·가족·공연과 대사는 창작이다.

## 편집 검수

- 01은 천 가게, 누이와 조카, 이야기꾼이 된 일, 견습을 가르친 뒤 목소리와 생활이 변한 노년까지 3쪽 프로필로 담았다. 한 번 무대를 양보한 일을 인생 전체의 정의로 쓰지 않았다.
- 02는 이야기 속 이야기와 실제 커피하우스 장면을 분리해 보여 준다. 견습 네마트의 질문, 손님들의 요구, 주인의 압박, 카림의 선택, 갈린 관객 반응과 줄어든 품삯이 장면·대화로 이어진다. 세 답변의 첫 행동은 달라도 공통 장면에서 막대를 건네는 동작이 모순 없이 이어지도록 고쳤다. 전생록 화자의 도입과 평생으로 돌아가는 끝맺음을 확인했다.
- 03은 출생부터 사망까지 14줄로 가족·일·상실·돌봄·독립·노년을 담았다. 04는 누이·견습·커피하우스 주인·조카·손님의 다른 시선을 둔다. 연도와 나이, 인물 관계를 대조했고 짧고 쉬운 문장으로 다듬었다.

## 그림·도달성·화면

- 고유 배경 `safavid-story-house-bg.jpg` **1254×1254**, 인물 `safavid-karim.webp` **1024×1536**, 실제 알파 범위 **0~254**. 둘을 별도 생성해 커피하우스와 간결한 사파비 시대 옷·나무 막대에 맞췄다.
- API·모바일 자산 경로를 연결했고 콘텐츠 검사에서 **91개 별도 1024px급 그림 쌍**을 확인했다.
- 타입·단위·콘텐츠·다양성·API E2E 통과. 전용 브라우저 E2E에서 **320×720, 768×1024**의 배경·인물 로드, 3쪽 프로필과 02~04 도달, 가로 넘침과 패널 겹침을 검사했다. `output/playwright/story-second-storyteller-*` 실제 화면을 열어 검토했다.
