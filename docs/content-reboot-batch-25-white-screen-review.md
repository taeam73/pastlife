# 65번째 라이브 검수 — 하얀 화면의 추격곡

**비말 샤 · 남성 · 1896~1970년 · 대표 에피소드 1932년 영국령 인도 봄베이 관구 봄베이.** [선행 설정 대장](story-setting-register.md)에 실제 시기·장소·정치권과 창작 인물의 성별·생몰·평생의 흐름을 원고보다 먼저 확정했다. [인도 국립영화기록보관소의 J. B. H. 와디아 구술](https://nfai.nfdcindia.com/upload/inter_pdf_image/J%20B%20H%20Wadia.pdf)은 무성영화 현장 반주에 하모니움·타블라 등이 쓰였다고 증언한다. [영화유산재단의 《알람 아라》 자료](https://filmheritagefoundation.co.in/alam-ara-1931-hindi-urdu-124-mins/)와 [인도 영화인 구술](https://nfai.nfdcindia.com/upload/inter_pdf_image/1604643900_Dada%20Salvi.pdf)은 유성영화가 등장한 뒤에도 무성영화가 이어진 시기임을 보여 준다. [영국 도서관의 봄베이 관구 1932~33년 행정기록](https://searcharchives.bl.uk/catalog/041-004061317)으로 당시 정치권을 확인했다(모두 2026-10-23 확인). 비말·영화관·상영 고장·즉흥극과 품삯은 창작이다.

## 원고 자체 검수

- **01** 세 쪽에 신원·생몰·그림과 음악 일, 평소 성격·취향·솜씨, 하모니움·누이·조카·동료와 바람·걱정을 배치했다. 삶 한 줄은 간판 그림을 배운 어린 시절부터 무성영화관, 다른 공연과 간판 작업, 노년의 가르침까지 이어진다. 영화가 멈춘 한밤의 교훈으로 평생을 규정하지 않는다.
- **02** 전생록이 무성영화에도 현장 음악이 있었음을 짧게 알려 준 뒤 추격 장면과 두 연주자를 소개한다. 필름이 끊기자 주인이 고장을 숨기라 하고, 비말은 어두운 화면에 빠른 곡을 계속 붙여 보다가 관객의 질문에 멈춘다. `notice`는 빈 화면과 자기 손을 보고, `connect`는 디네시에게 즉흥 연주를 청하고, `speak`는 고장을 알린다. 세 경로 모두 상영 중단을 밝히고 관객과 다음 장면을 상상한다. 실제 영화가 다시 시작되자 비말의 짐작과 다른 우스운 장면이 나오지만 이미 나간 관객은 표값을 돌려받았고 두 연주자의 품삯 일부가 깎인다. 디네시가 함께 감당한 손실을 지적해 즉각적인 화해나 일자리 기적을 피했다. 낯선 악기 이름은 처음 나올 때 짧게 설명했다.
- **03** 1896년 출생부터 1970년 사망까지 19개 사건에 부모·누이의 혼인과 사별, 조카·동료와의 관계, 그림·음악 일의 변화, 말년의 가르침과 디네시의 죽음을 담았다. 1932년 36세, 1970년 74세가 맞다. 1948년 사별한 누이를 위해 1921년 혼인 사건을 선행 배치했다.
- **04** 하모니움·간판 글자·지킨 자리·남긴 말과 리나·타라·디네시·영화관 직원의 다른 평가로 평생을 되돌아본다. 영화의 고장을 고친 사람은 영사실 직원이며 비말의 공연은 기다리는 시간을 채웠을 뿐이라는 인과도 카드와 본문에서 유지했다.

## 그림과 검증

- 고유 배경 `white-screen-bombay-bg.jpg` **1254×1254, 139KB**, 실제 알파 인물 `white-screen-vimal.webp` **1024×1536, 107KB**를 API·모바일에 연결했다. 첫 배경은 영사기가 스크린 바로 옆에 놓인 듯해 버리고, 뒤쪽 관람석에서 스크린을 바라보는 두 번째 배경을 채택했다. 인물의 휴대용 하모니움·악보와 관람석의 빈 화면이 원고와 맞는다. 직전 에도 화재의 야외·짙은 남색 소방복과 달리 실내 관람석·갈색 조끼·크림색 옷이다.
- 카드·원고·API 그림 매핑 **65/65**, 중복 ID 없음, 고유 그림 **65쌍** 검사 통과. 콘텐츠·API·모바일 타입, 집중 단위·콘텐츠 도달성 **27개**, 다양성 **4개**, API E2E **2개** 통과. 첫 브라우저 실행에서 인물 요약이 결과 데이터의 80자 제한보다 1자 길어 실패했고 78자로 줄여 재검사했다.
- `e2e/mobile-white-screen-tune.spec.ts` 통과. 320px·768px 실제 결과 화면에서 그림 원본 로드, 01 세 쪽, 02~04 본문 도달, 가로 넘침과 제목/양피지 비겹침을 확인했다. `output/playwright/story-white-screen-tune-320-1.png`와 `story-white-screen-tune-768-1.png`를 육안 점검했다. 320px에서는 인물 일부가 글과 패널에 가려지지만 얼굴과 글자는 읽히고, 768px에서는 인물·영화관이 함께 보인다.
- 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 보강은 남아 있다. 커밋·푸시·배포는 하지 않았다.
