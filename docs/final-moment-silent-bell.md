# `SILENT_BELL` 다온 마지막 순간 검수 기록

**2026-10-24 재작업 판정:** 아래는 생애 재설계 전의 기술·웹 화면 검사 기록이다. 새 01·03·04에서는 다온이 46세 비란을 잘못 지목해 그의 일자리를 잃게 하고, 소미와의 동거가 끝난 뒤 51세부터 나루 짐배에서 일한다. 아래의 64세 소미·젊은 조사자·질문 장부 곁 임종과 삽화는 새 생애와 충돌한다. 원고·삽화 교체와 가독성·정합성 재검수 전까지 **새 편집 기준 승인에 포함하지 않는다**. 37세의 종탑 사건·답변 신호는 유지한다.

검수일: 2026-10-24 (KST)

- 기존 01·03·04 기준: 다린 세계 강력 74~138년, 여성 다온, 갈대강 중류 나루 출생·마을에서 사망. 분실물 기록자로 일하다 29세부터 탐정이 됐다. 16세에 가까워진 친구 소미와 그물을 엮었고, 53세부터 눈이 쉽게 피로해져 듣고 정리하는 일로 무게를 옮겼다. 58세에 젊은 조사자에게 질문 장부를 넘겼고 64세에 삶을 마쳤다.
- 새 장면: 강력 138년, 강가에서 소미의 그물 매듭을 만지고 후배 조사자의 이야기를 듣는다. 확인하지 못한 답과 소미와 걷고 싶은 강 아래쪽 길을 남긴다. 사망 원인을 새로 단정하지 않는다.
- 02와 구분: 종탑의 젖은 천과 아기·뱃사공 사건을 다시 다루지 않는다. 평생의 질문 장부, 소미와의 그물, 후배에게 넘긴 역할을 마지막 장면에 사용했다. 두 집의 물건 소유 다툼과 남겨진 사람들의 반응은 이번에 창작했다.
- 창작·사실 구분: 다린 세계, 강력, 갈대강 마을, 인물과 사건은 기존 작품의 허구 설정이다. 실존 역사나 실제 사망 기록으로 설명하지 않는다.
- 전용 그림: 기존 갈대강 배경과 다온의 어두운 겹옷·묶은 머리를 참조한 1536×1024 JPEG(353,258바이트)다. 첫 시안의 다온이 64세보다 젊어 보여 희끗한 머리·얼굴선·손을 보정한 두 번째 그림을 채택했다. 소미와 그물, 질문 장부를 든 젊은 조사자, 강가 나루를 눈으로 확인했다. 읽을 수 있는 문구와 현대 물건은 보이지 않는다.
