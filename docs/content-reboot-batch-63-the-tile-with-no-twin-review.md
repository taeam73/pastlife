# 103번째 이야기 검수: 짝이 없는 타일

- **설정과 구분:** 1432년 티무르 왕조의 사마르칸트. [유네스코의 사마르칸트 자료](https://whc.unesco.org/en/list/603/)와 [메트로폴리탄 미술관의 티무르 시대 자료](https://www.metmuseum.org/ja/essays/the-art-of-the-timurid-period-ca-1370-1507), [타일 제작 연구](https://resources.metmuseum.org/resources/metpublications/pdf/Persian_Tiles.pdf)를 2026-10-23 확인했다. 도시·시기·타일 공예는 역사적 배경이고 유수프와 가족·주문·꽃잎이 다른 타일은 창작이다. 현존 건물의 실제 수리 기록으로 소개하지 않는다.
- **한 사람의 삶:** 1392~1464년, 사마르칸트의 도자기 장인 집에서 자라 친구와 공방을 열었다. 라일라와 두 아이를 키우고 친구가 떠난 뒤 제자와 일했다. 손이 떨리는 노년에는 딸과 제자에게 일의 몫을 넘겼다. 01의 삶 한 줄은 이 변화를 요약하며, 02의 실수로 생애를 정의하지 않는다.
- **02의 독립성:** 남의 실수로 잘못 짚은 타일을 확인하고 나짐에게 사과한다. 주문한 사람에게 다른 무늬를 보여 주어 한 장만 허락받고 나머지는 새로 구워 늦어진 품삯을 낸다. 바흐람의 흔적은 남지만 나짐의 서운함은 즉시 풀리지 않는다. 화자의 도입과 마무리, 대화, 선택과 비용이 들어 있다.
- **질문·결과 연결:** 3.0 질문의 각 여섯 보기에서 나오는 신호 중 `notice`, `speak`, `connect`가 이 편의 장면에 연결된다. 이상한 타일과 견본 확인, 나짐에게 잘못을 말함, 주문자·벽 장인과 함께 결정함으로 이어진다. 기존 2.5 질문과 초기 44편의 보기는 소급 변경하지 않았다.
- **연대·관계:** 사건 때 40세, 사망 때 72세. 바흐람이 1431년에 떠난 뒤 1432년의 견본이 남는다. 라일라·사미라·다니알·나짐은 01~04에서 같은 관계를 유지한다. 03은 사건 밖의 혼인·자녀·일의 변화·노년까지 기록하고 04는 라일라·딸·제자가 서로 다르게 기억한다.
- **그림:** `samarkand-tile-workshop-bg.jpg`는 1254×1254, `samarkand-yusuf-tile-maker.webp`는 1024×1536의 실제 알파 채널을 가진 인물이다. API와 모바일에 각각 정확히 매핑했다. 생성 그림의 복식·세부 건축이 학술적 복원이라고 주장하지 않는다.
- **검증:** `pnpm typecheck`, `pnpm content:check`(103개의 고유 그림쌍 및 레지스트리), `pnpm test`(API 109개 포함), `pnpm test:e2e`(2개), Edge Playwright 320×720·768×1024의 01 세 쪽 및 02~04 도달 검사가 통과했다. 실제 독자 이해도, 실기기 화면과 고고학적 세부 복원은 별도 검증 전이다.

이 검수는 사용자에게 3.0으로 보일 수 있는 원고·그림 연결을 대상으로 한다. 그림을 포함한 원고는 커밋·푸시·배포하지 않은 로컬 상태다.
