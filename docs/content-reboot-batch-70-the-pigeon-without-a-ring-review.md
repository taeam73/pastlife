# 110번째 원고 검수 — 발찌가 없어진 비둘기

2026-10-23. `THE_PIGEON_WITHOUT_A_RING`은 1650년 무굴 제국 샤자하나바드의 창작 인물 라피크 이야기다. 집필 전 [설정 대장](story-setting-register.md)에 당시 정치권·장소·생몰·평생·자료와 창작 범위를 기록했다.

## 역사 조건과 창작

- [유네스코 붉은 요새](https://whc.unesco.org/en/list/231)와 [건설 보고서](https://whc.unesco.org/document/8815)로 샤 자한의 새 수도와 1648년 요새 완공을 확인했다. [메트로폴리탄 미술관의 1650년경 비둘기 그림](https://www.metmuseum.org/art/collection/search/825596)은 금색 발찌가 있는 궁정 비둘기의 시각 자료다. [아크바르 궁정 기록](https://persian.packhum.org/text/000702051/6)은 이전 시기 궁정의 비둘기 돌봄을 전한다. 2026-10-23 확인했다.
- 라피크·가족·동료·화가·새장 마당·빠진 발찌와 대화는 창작이다. 16세기 말의 세부 관행을 1650년 궁정의 정확한 절차라고 주장하지 않는다. 배경도 실제 요새의 특정 마당 복원이 아니다.

## 원고와 그림

- 01은 아그라의 어린 시절, 궁정에서 일하고 가족과 이주한 중년, 일을 줄이고 이웃과 지낸 노년까지 담았다. 한 번의 발찌 소동으로 평생을 규정하지 않았다.
- 02는 화가가 새 두 마리를 그리려는 동안 발찌가 없어지는 장면, 라피크가 동료·화가와 다시 확인하는 선택, 하루 미뤄진 그림과 가족과의 놓친 저녁을 대화로 담았다. `notice`·`speak`·`connect`의 행동을 구별했다. 03은 1610~1682년의 생애 13지점, 04는 아리파·아미나·나딤의 서로 다른 기억을 담았다.
- 1254×1254px 고유 새장 마당 배경과 알파 채널이 있는 1254×1254px 전신 인물을 API·모바일에 연결했다. 사용자가 지적한 초기 만화풍 시안을 사용하지 않고, 기존 인물의 사실적인 질감과 전신 비율을 참조해 다시 제작했다.

## 확인 범위

타입, 콘텐츠·그림·다양성, 단위, API E2E와 질문 여섯째·다섯째 보기에서 320px·768px 결과에 도달하는 브라우저 검사가 통과했다. 휴대전화와 태블릿의 실제 결과 스크린샷을 확인했다. 실독자 반응, 물리적 기기, 정확한 복식·건축 재현은 검증하지 않았다. 기존 44편의 01·03 전수 점검도 남아 있다.
