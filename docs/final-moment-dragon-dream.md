# 오르 마지막 순간 검수 기록

> **2026-10-24 생애 재설계 후 재작업 필요:** 아래는 당시 원고·삽화·웹 여정의 과거 검사 기록이다. 현재 01·03·04에서는 오르가 49세 도서관을 떠나 라엔과 여행하다 54세 혼자 은등으로 돌아와 도서관 밖 집에서 지낸다. 아래 마지막 장면의 도서관·라엔·후배 곁 임종과 삽화는 새 설정과 충돌한다. 기술 등록 1건은 남지만, 새 서사 승인과 전체 출시 완료에는 포함하지 않는다. 63세 사망 경위·새 마지막 장면·삽화와 최종 일괄 PDF/공유 검수는 미완료다.

2026-10-24 기준. `DRAGON_DREAM`은 **허구의 리오른 세계** 이야기이며, 잠든 용과 베룬 왕국은 실제 역사 근거가 아니다. 오르·라엔·후배의 마지막 저녁, 대사와 사후 반응은 기존 인물 설정에 기대어 새로 쓴 창작이다.

## 원고·그림 정합성

- 01·03의 여성 오르, 도서력 218~281년·63세, 은등 강변 마을, 15세에 라엔을 만나 28세에 함께 책을 묶고 49세에 도서관을 넘긴 관계를 유지했다. 후반기에도 라엔과 책을 고쳤다는 55세 기록을 마지막 장면의 공책에 연결했다.
- 04의 ‘들은 말과 짐작한 말 구분’, 말 걸면 펜을 내려놓는 버릇, 자기 이야기는 좀처럼 하지 않았다는 주변인 평가를 바탕으로, 마지막에 자기 이야기를 말로 들려주되 라엔에게 받아 적지는 말라고 하는 장면을 만들었다.
- 02의 지워진 이름·니아·홍수와 수문 사건을 반복하지 않았다. 도서관을 넘긴 후의 강변 저녁으로 시간과 사건을 분리했다.
- 삽화는 기존 오르의 남색 복식과 같은 도서관의 청금색 공간을 참고했다. 첫 시안의 오르가 63세보다 젊어 보여 흰머리·얼굴·손의 말년 표현을 보정했다. 1536×1024 JPEG, 387,525바이트.

## 실행 검사

- `final-moment:check` **10/120**, `content:check`의 기본 그림 120쌍과 마지막 삽화 10개, 모바일 타입, API E2E 2건 통과.
- 인메모리 3.0 API에 실제 여섯 답변을 제출해 56번째 시도에 오르 결과를 선택했다. 320px 결과의 잠금 → 두 번째 **테스트 광고** → 마지막 순간 → 읽음 표시 → 웹 PDF·PNG 해제를 확인했다.
- 320px·768px 마지막 화면의 본문·삽화·맺음말과 끝 버튼을 확인했다. 가로 넘침과 브라우저 페이지 오류가 없었다. 320px 상단·하단 캡처와 1080×1800 공유 PNG를 직접 열어 인물·배경·소개 문구를 확인했다.
- 앱에서 내려받은 A4 **11쪽 PDF** 전체를 렌더링해 표지, 01~04, 삽화가 들어간 마지막 순간과 전생록 맺음말을 확인했다. 접촉 시트는 `output/pdf/dragon-dream-final-contact.jpg`에 있다. PDF는 이미지형으로 텍스트 선택은 되지 않는다.

## 검증 한계

운영 광고·실제 DB 지속성·휴대폰 파일 저장 및 이미지 공유는 아직 검증하지 못했다. 120편 전체의 카드별 크롭과 기기별 화면 검증도 진행 중이다. 이 편은 **원고·그림과 인메모리 웹 시범 여정**이 검증된 상태이며 전체 출시 경험 완료로 세지 않는다.
