# 112번째 「간판 속 다른 얼굴」 검수

- **완료:** 2026-10-23. 실제 `storyCards` 112편, 112개 원고와 각각 다른 112쌍의 배경·인물 매핑을 다시 확인했다. 직전 1518년 소치밀코 꽃 재배자·1650년 샤자하나바드 비둘기 돌봄 일꾼, 기존 아크라 두 편과 시기·지역·역할을 달리했다.
- **선행 설정:** 원고보다 먼저 [설정 대장](story-setting-register.md)에 1981년 나이지리아 제2공화국의 라고스, 여성 비시의 1952~2018년 생애(66세), 가게·가족·견습생·노년, 02의 간판 사건, 사료와 창작의 경계를 확정했다.
- **역사 확인:** 미국 의회도서관의 [나이지리아 국가 연구](https://tile.loc.gov/storage-services/master/frd/copr/Nigeria.pdf) 및 [의회사](https://wwws.loc.gov/law/help/national-parliaments/nigeria.php), 스미스소니언의 [라고스 1980년대 거리 사진](https://africa.si.edu/archives?edan_fq%5B%5D=date%3A%221980s%22&edan_fq%5B%5D=set_name%3A%22Barbara+Blackmun+Collection+%2F+Series+4%3A+Landscape+and+Street+Scenes%2C+Nigeria+%2F+Lagos%2C+Nigeria%22)과 [미용실 간판·머리모양 사진 자료](https://sova.si.edu/record/eepa.2005-002/contents?i=0&n=100&q=ibeji+--+Photographs&s=0&t=W)를 2026-10-23 확인했다. 도시·정치권·간판의 시대 맥락은 역사 조건이고 비시, 가족, 화가, 간판의 얼굴·대화는 창작이다. 생성 그림은 특정 사진이나 실제 간판의 재현이 아니다.
- **원고 검수:** 01의 삶 한 줄은 이바단 출생에서 라고스 미용실·가족·가게 축소·일의 이양과 노년까지 이어지며 02의 결론을 미리 말하지 않는다. 성격·취향·사람·바람·걱정을 3쪽에 실었다. 02는 가게 개점 준비, 달라진 얼굴의 발견, 화가·톨라와의 대화, 다시 그리는 선택, 추가 물감값·놓친 손님과 늦은 간판까지 장면으로 진행한다. 03은 1952~2018년을 사건 밖의 삶과 함께 적었다. 04는 오래 한 일·좋아한 시간·남긴 말과 톨라·아들·조카의 서로 다른 평가를 담았다. 1981년 사건 29세, 2018년 사망 66세, 관계와 인과를 대조했다.
- **그림:** 사람 없는 1254×1254px 라고스 미용실 배경과 1254×1254px 비시 인물 레이어를 생성해 API와 모바일에 각각 연결했다. 인물은 기존 회화적 사실주의와 맞춘 전신 컷아웃이며 이미지 가장자리 투명도를 확인했다. 초반 세 시도는 갈색 후광이 남아 폐기하고, 기존 투명 캐릭터의 알파 실루엣을 참조한 네 번째 결과를 채택했다. 회화풍의 일반적 복식 묘사이며 1981년 라고스의 특정 인물 복장을 정밀 복원한 자료는 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e` 통과. 112쌍 1024px 이상 고유 그림·투명 인물·모바일 레지스트리, API 이미지 매핑 검사 통과. 전용 브라우저 E2E에서 질문 다섯째·여섯째 보기로 결과 도달, 01의 세 쪽과 02~04 콘텐츠, 320×720px·768×1024px 레이아웃과 1024px 이상 실제 이미지 로드를 확인했다. 두 너비의 첫 결과 화면을 육안으로 확인했다. 320px에서는 긴 01 카드가 인물 하단을 가리지만 글을 읽고 페이지를 넘길 수 있다.
- **한계:** 실제 이용자의 이해도·재미, 실기기 화면, 정확한 1981년 라고스 개별 상가·복식 복원은 검증하지 않았다. 기존 44편의 01·03 전수 점검은 별도 작업으로 남는다. 커밋·푸시·배포 없음.
