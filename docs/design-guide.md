# 전생록 디자인 가이드

## 승인 절차

판타지형, 경쾌한 엔터테인먼트형, 혼합형의 서로 다른 3개 시안을 비교한다. 색상만 바꾸지 않고 제목 처리, 구도, 그래픽, 속도감, 사용자 경험을 다르게 만든다. 사람 승인 전에는 하나를 확정 디자인으로 간주하지 않는다.

## 시안 3종

### 시안 A 판타지 기록 보관소

- 방향: 어두운 남청 배경, 금빛 포인트, 기록 카드와 봉인·문양 그래픽
- 경험: 질문은 의식처럼 차분하게 진행하고 결과는 오래된 기록을 펼치는 느낌으로 공개
- 강점: 현재 앱의 신비로운 분위기와 역사 기록 콘셉트를 가장 일관되게 확장
- 위험: 정적이고 무거워질 수 있어 짧은 전환과 명확한 진행 표시가 필요

### 시안 B 경쾌한 발견 카드

- 방향: 밝은 종이색 배경, 선명한 보조색, 카드 넘김과 수집 피드백
- 경험: 질문마다 빠른 선택 피드백을 주고 결과를 친구에게 공유할 수 있는 카드로 구성
- 강점: 짧은 테스트와 공유에 유리하고 첫 사용 진입이 쉽다.
- 위험: 역사적 깊이와 신비감이 약해질 수 있다.

### 시안 C 영화형 역사 장면

- 방향: 전면 이미지, 큰 타이포그래피, 장면 전환과 인물 레이어
- 경험: 질문은 장면의 단서로, 결과는 한 편의 짧은 역사 영화처럼 공개
- 강점: 이미지와 챕터형 서사의 몰입도가 높다.
- 위험: 이미지 용량·저작권·로딩 비용과 저사양 화면 대응 부담이 크다.

## 추천 방향

시안 A를 기본 구조로 채택하고, 시안 B의 빠른 카드 피드백과 시안 C의 결과 이미지 레이어를 제한적으로 결합한다. 이 추천은 시장 조사와 현재 구현 구조에 기반한 제안이며, 구현 전에 핵심 화면 3종의 시각 시안을 비교한다.

## 핵심 화면 시안 범위

1. 시작 화면: 콘셉트와 오락성 고지
2. 질문 화면: 진행률·선택 피드백·재시작 방지
3. 결과 화면: 역사 장면·인물 카드·챕터·공유

## 승인 체크리스트

- 세 시안이 색상만이 아니라 정보 구조와 사용자 경험도 다른가
- 질문과 결과의 가독성이 유지되는가
- 이미지 없이도 제목과 핵심 행동이 이해되는가
- 모바일 저사양·느린 네트워크에서 로딩 상태가 설명되는가
- 실제 UI 요소와 대체 텍스트가 유지되는가

## 구현 원칙

- 버튼·입력·상태 표시·접근성 요소는 실제 UI 컴포넌트로 만든다.
- 배경 이미지에 제목·버튼을 통째로 합치지 않는다.
- AI 생성 이미지는 필요할 때만 사용하고 권한, 해상도, 용량, 대비, 대체 텍스트를 확인한다.
- 텍스트 제목은 검색·접근성을 위해 유지한다.

## 검증 항목

첫인상, 흥미, 사용성, 콘텐츠 감정 전달, 반응형 레이아웃, 로딩·오류·재시도 상태, 저사양 화면을 확인한다.

현재 시안과 최종 토큰은 아직 승인되지 않았다.
