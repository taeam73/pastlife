# 113번째 「지운 이름 옆의 빈칸」 검수

- **완료:** 2026-10-23. 집필 전 실제 `storyCards`·원고·고유 배경/인물 매핑 112쌍을 확인하고, 직전 1981년 라고스 미용사와 다른 시대·지역·일을 골랐다. 등록 후 113편과 고유 그림 113쌍을 검사했다.
- **선행 설정:** [설정 대장](story-setting-register.md)에 1905년 크리스티아니아, 동군연합 해체를 선언한 노르웨이의 정치 상황, 창작 여성 잉가 라르센의 1871~1948년 생애, 02 밖의 직물 일·가족·동료·노년, 한 점심의 서명 사건을 원고보다 먼저 확정했다.
- **역사와 창작:** [노르웨이 의회의 1905년 서명 운동](https://www.stortinget.no/no/Stortinget-og-demokratiet/Historikk/kvinnestemmerett/underskriftsaksjonen1905/) 및 [참정권 역사](https://www.stortinget.no/no/Stortinget-og-demokratiet/Historikk/kvinnestemmerett/stemmerettskampen-18901913/), [의회 전시 자료](https://www.stortinget.no/globalassets/pdf/english/utstillingshefte_engelsk.pdf), [오슬로 박물관의 1904년 노동자 사진](https://www.oslomuseum.no/arkiv/tidligere-arrangementer/maries-tur-arbeidere-fabrikkeiere-pa-sagene/)과 [국립도서관의 도시 노동사 자료](https://www.nb.no/content/uploads/2018/08/NOTA-BENE-12_Layout_digital_30ab.pdf)를 2026-10-23 확인했다. 해체 선언 뒤 남성 투표와 여성 서명 운동, 여성 직물 노동, 1913년 여성 참정권은 역사 배경이다. 잉가·리브·마르타, 특정 작업장, 서명 취소와 품삯 소동 및 모든 대화는 창작이며 보존된 실제 서명지를 재현하지 않는다.
- **원고 검수:** 01의 세 쪽은 이름·시대·장소·생몰·일, 생활·성격·취향·가까운 사람·바람·걱정을 담고, 삶 한 줄은 어머니의 바느질에서 여러 일터와 동료·조카 곁 노년까지 이어진다. 02의 선택이나 결말을 먼저 말하지 않는다. 02는 전생록 화자 도입, 점심 탁자의 서명·리브의 번복·동료 간 대화·다시 쓰는 선택, 잃은 품삯과 남은 어색함, 화자 마무리로 독립된 사건을 이룬다. 03은 1871년 출생부터 1948년 사망까지 일과 가까운 사람의 변화를 짚고, 04는 일·식탁·가위·남긴 말과 리브·마르타·조카의 서로 다른 평가를 남긴다. 1905년 34세, 1913년 42세, 사망 77세와 친족·동료 관계를 대조했다. 문장을 중학생이 이해할 수 있는 말로 자체 검토했다.
- **그림·연결:** 사람 없는 1254×1254px 창작 직물 작업장 배경과 별도 1254×1254px 잉가 전신 인물을 제작했다. 사실적 회화풍의 실용적인 블라우스·치마·앞치마, 종이와 연필을 사용했고 투명 영역을 확인했다. API 이미지 공급자와 모바일 정적 레지스트리에 고유 경로를 연결했다. 그림은 특정 작업장이나 1905년의 개별 복식에 대한 정밀 복원은 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e` 통과. 콘텐츠 검사는 113편의 서로 다른 1024px 이상 배경/투명 인물 쌍과 모바일 도달성을 확인했다. 전용 브라우저 E2E는 3.0 질문당 6개 보기, 첫 질문 여섯째·둘째 질문 다섯째 보기 선택, 01 세 쪽과 02~04 도달, 320×720px·768×1024px 실제 결과 이미지 로드와 가로 넘침을 확인했다. 첫 결과 화면을 두 너비에서 육안 확인했다.
- **한계:** 320px에서 긴 01 프로필 카드가 인물 하단을 가리고 상단의 일부만 보인다. 글과 페이지 이동은 가능하다. 실제 독자 반응, 실기기, 개별 작업장·복식의 역사적 정밀 복원, 기존 44편의 01·03 전수 점검은 완료되지 않았다. 커밋·푸시·배포 없음.
