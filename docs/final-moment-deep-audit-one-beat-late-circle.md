# 100번 나피사 마지막 순간 재작업 감사 — 초안

2026-10-25, ID `ONE_BEAT_LATE_CIRCLE`. 새 편집 기준의 최종 승인은 아니다. [생애 감사](life-deep-audit-one-beat-late-circle.md)와 함께 읽는다.

## 기존과 변경

- 1867~1942년·75세, 1905년 춤 사건 38세, 1913년 언니 마리암의 노동값을 미룬 일, 1919년 마리암 사망, 1942년 살마 52세를 유지한다. 주후라는 살아 있으나 마지막 현장에는 없다.
- 기존 원고는 나피사·살마·주후라가 과일을 나누며 내일 맛을 기대하고, 소리가 멀어지다 눈을 감는다. 직접 사망 경위가 없어 독자가 왜 그 자리에서 죽었는지 따라갈 수 없었다. 유수프(`THE_TILE_WITH_NO_TWIN`) 편과 과일·내일·웃음·수동적 눈감음까지 겹쳤다.
- 새로 설정한 **창작 개인사**: 1942년 며칠째 기침하던 나피사가 밤에 혼자 물을 마시려다 숨이 가빠진다. 바깥 공기를 마시려고 문으로 가지만 목소리가 끊기고 빗장을 들다 주저앉는다. 밖에서 온 조카 살마가 들어와 어깨를 받치고, 나피사는 몇 번 숨을 쉬다 그날 밤 죽는다. 정확한 병명과 의학적 원인은 **미상**이다. 1913년 병의 재발이라고 단정하지 않는다.
- 사후 화자는 살마가 독립하겠다는 이모의 말을 떠올리고, 주후라가 마리암과 천을 접던 조용한 시간을 기억한다고 전한다. 마리암의 노동값 문제를 사망 장면에서 속죄하거나 용서받게 만들지 않는다.
