# 99번째 원고·그림 검수 — 첫 밭에 물을 보낸 날

- **집계:** 99개 고유 storyCards, 99개 고유 원고, 99쌍의 별도 그림과 API·모바일 매핑. 120편까지 21편 남음. 작업 전에는 각 98개였다.
- **선행 설정:** [설정 대장](story-setting-register.md)에 집필·그림 제작 전에 1442년 비자야나가라 제국 수도와 상가마 왕조, 남성 라마나(1404~1476), 가족·직업·돌봄·노년을 확정했다.
- **역사 근거:** [유네스코 함피](https://whc.unesco.org/en/list/241)의 수도·강·바위·물 시설, [펜 박물관 생활 공간 조사](https://www.penn.museum/sites/expedition/the-multiple-landscapes-of-vijayanagara/) 및 [시카고대 수로·농업 조사](https://paleoecology.uchicago.edu/vijayanagara-metropolitan-surv/)를 2026-10-23 확인했다. 라마나와 가족, 금 간 수로, 밭의 피해는 모두 창작이며 역사 기록의 특정 사고로 제시하지 않는다. 16세기 이후 특정 기념물이나 확인하지 못한 물 배분 법률은 원고에서 단정하지 않는다.
- **원고:** 01은 강가 밭에서 석공, 타라와 아이들, 어머니 돌봄과 손목 변화까지 평생을 보여 준다. 02는 금 간 벽 앞 선택과 실제 개방 행동, 지킨 집·잃은 모종, 가우리의 항의와 남은 거리까지 장면으로 썼다. 세 답변은 관찰·바수에게 묻기·타라에게 알리기로 서로 다른 첫 행동이다. 03의 출생~사망 16개 사건은 02 밖의 혼인, 아이들의 일, 간병과 노년을 포함한다. 04는 타라·가우리·나빈·바수가 각각 다른 라마나를 기억한다. 연도·나이·관계·인과·물길 방향을 대조했다.
- **그림:** `vijayanagara-first-garden-flood-bg.jpg` 1254×1254, 사람 없는 돌 수로·잠긴 밭; `vijayanagara-ramana.webp` 1024×1536, 투명도가 있는 남성 석공. 인물 생성 시 가장자리 갈색 잔상이 남아 재생성을 시도했고, 합성 화면에서 두드러지지 않음을 확인했다. 복식·건축의 정확한 고증은 별도 전문가 확인 전이다.
- **검사 통과:** `corepack pnpm typecheck`, `corepack pnpm content:check`(99개 그림쌍과 다양성 포함), `corepack pnpm test`, `corepack pnpm test:e2e`. 전용 `e2e/mobile-first-garden-flood.spec.ts`를 API+모바일 브라우저에서 320×720 및 768×1024로 실행해 01 세 쪽, 02~04 접근, 그림 로드와 가로 넘침을 확인했다. `output/playwright/story-first-garden-flood-320-{1,2,3}.png`와 `-768-3.png`를 시각 검사했다.
- **한계:** 실사용자 이해·흥미, 물리적 기기, 정확한 15세기 복식·수로 형태는 검증하지 않았다. 기존 첫 44편의 01·03 전수 보강도 남았다. 커밋·푸시·배포 없음.
