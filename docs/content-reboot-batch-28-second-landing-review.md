# 68번째 「밭의 반쪽」 원고·그림 검수

2026-10-23. 집필 전 실제 카드·원고·그림 매핑은 67쌍, 마지막 ID는 `MASKED_FARE`였다. 소치밀코의 배경·정치권·주인공 생몰과 평생을 [선행 설정 대장](story-setting-register.md)에 먼저 확정한 다음 원고와 그림을 만들었다.

## 역사 배경과 창작의 경계

- 대표 장면은 **1490년 메히카 지배 아래 소치밀코**이다. 멕시코 국립인류학역사연구소(INAH)의 소치밀코 역사와 발굴 자료, FAO의 치남파 농법 자료로 호수 흙으로 만든 긴 농경지·좁은 수로·말뚝·옥수수·나무 심는 막대와 당시 정치권을 확인했다. 세부 출처와 확인일은 설정 대장에 남겼다.
- 토치틀의 가족·친구·밭을 나누는 방식·그날 뽑은 옥수수는 창작이다. 공식 토지 상속 관습이나 특정 실존 농가를 설명하는 사건으로 쓰지 않았다. 그림에는 식민지 건축, 말, 쇠 도구를 넣지 않았다.

## 01~04 점검

- **01:** 부모에게 배운 농사, 이츠엘과 아이들, 동생·친구, 노년의 무릎과 가르침을 세 쪽으로 소개했다. 한 번의 밭 나누기에서 얻은 교훈으로 평생을 규정하지 않았다.
- **02:** 뒤쪽 밭에서 배까지 수확 자루를 옮기기 어려운 문제를 실제 동선으로 보여 준다. 형과 남동생이 각자 심은 옥수수를 일부 걷어 길을 만들고 그해 수확을 덜 얻는다. 전생록의 도입·마무리와 세 답변 신호별 관찰·협의·직접 말하기 행동을 구분했다. 곧바로 완전한 화해로 끝내지 않았다.
- **03:** 1452~1510년 출생·부모·친구·함께 산 사람·자녀·병 돌봄·동생의 일·노년을 16개 짧은 사건으로 기록했다. 연도와 나이를 대조했다.
- **04:** 아버지의 나무 막대, 좋아한 저녁, 걱정, 남긴 말, 동생·이츠엘·딸·친구의 서로 다른 기억을 담았다.
- 문장은 밭·자루·배·옥수수처럼 눈에 보이는 소재를 중심으로 썼다. 생몰, 나이, 관계, 선택의 대가, 01~04 사이의 표현을 자체 대조했다. 독자 흥미·이해도는 실제 독자로 아직 확인하지 않았다.

## 그림·기술 검증

- 고유 배경 **1280×1280 JPEG**, 고유 인물 **1024×1536 WebP(실제 알파 채널)**를 분리해 API 및 모바일 정적 매핑에 연결했다. 배경 그림은 치남파와 수로의 분위기 묘사이며 실제 1490년 소치밀코의 특정 지형을 정밀 재현한 지도는 아니다.
- content·api·mobile 타입 검사, 68쌍 그림 검사, 다양성 검사, 관련 단위/도달성 27개, API E2E 2개가 통과했다.
- Playwright 결과 화면은 **320×720** 및 **768×1024**에서 배경·인물 이미지 폭, 01 세 쪽 이동, 02~04 후반 문구 도달성, 가로 넘침, 상단 소개문과 양피지 분리를 검사해 통과했다. 두 크기의 첫 화면 이미지를 직접 보았고 글과 얼굴을 알아볼 수 있다.

실제 이용자 평가, 물리 기기 성능·크롭과 배포 환경은 미검증이다. 기존 44편의 01·03 전수 보강은 별도 남은 작업이다.
