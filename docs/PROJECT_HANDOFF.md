# 전생록 프로젝트 인수인계

**갱신일:** 2026-10-30
**용도:** 다른 PC에서 저장소와 새 대화를 열어 작업을 이어가기 위한 요약. Codex/ChatGPT의 원래 대화 기록을 복제하는 파일은 아니다.

## 프로젝트

- 앱 이름은 **전생록**이다.
- 실제 전생을 판정하거나 심리·과학적 진단을 하는 서비스가 아니라, 선택에 따라 한 사람의 삶을 읽는 이야기형 엔터테인먼트 앱이다.
- 제품의 우선 기준은 흥미·재미·공감이다. 실제 전생을 사실로 단정하는 홍보 문구는 피한다.
- 프로젝트 문서와 코드 기준으로 6단계 질문 경험과 총 120편의 3.0 이야기를 목표로 한다. 현재 출시 경험 검수 현황은 `PROJECT_STATUS.md`를 기준으로 다시 확인한다.
- 앱은 모바일·API·관리자·워커로 나뉜 모노레포다. 질문·콘텐츠는 `packages/content`, 결과 채점은 `packages/scoring`, 화면은 `apps/mobile`에 있다.
- 앱의 상세 현황과 개발 규칙은 `PROJECT_STATUS.md`, `README.md`, `AGENTS.md`, `docs/concept.md`를 우선 참고한다. 오래된 설명과 최신 구현이 다르면 실제 코드와 최신 현황 문서를 확인한다.

## 이번 대화에서 정한 홍보 방향

- 목표는 설치 수만 늘리는 영상보다 **“궁금해서 한 번 해보고 싶다”**는 마음을 만드는 것이다.
- 텍스트 자막만 얹은 클립 나열보다, 짧은 서사와 장면 전환으로 분위기를 만드는 방향을 선호한다.
- 전생록의 화자는 수만 년 동안 전생의 기록을 지켜본 듯한 **인자하고 따뜻한 할머니**다. 목소리는 나이 들고 온화하며, 느리고 친밀하게 말해야 한다. 젊거나 딱딱한 합성음처럼 들리는 건 피한다.
- 로고는 실제 전생록 로고 자산만 사용한다. 예시 화면에서 가져온 로고 이미지는 쓰지 않는다.
- 한국어·영어·태국어·일본어 버전은 영상 장면을 공유하고, 각 언어에 맞춰 음성과 자막을 별도로 현지화하는 방향이다. 직역보다 자연스러운 표현을 쓴다.
- 현재 검토된 한국어 화자 문구는 “당신의 전생이 궁금하십니까?”와 “당신이 지나온 삶의 이야기를 들려드릴게요.”다. 아직 최종 광고 카피로 확정되지는 않았다.
- 전체 영상은 약 15초를 목표로 한다. Flow의 한 번 생성은 선택 모델에 따라 최대 10초이므로, 장면을 나눠 만들고 Flow의 장면 편집 기능에서 조립한다.

| 자산 | 내용 | 검토 상태 |

| `Hands opening book on table` | 노인의 손이 책을 열고 경성 전당포의 여성 인물로 이어지는 8초 세로 영상 | 분위기는 좋지만 간판에 가짜 한자처럼 보이는 문자가 생겨, 주요 연결 컷으로는 보류 |
| `Woman opening book on table` | 책과 손에서 잉크·종이 질감이 비 내리는 창으로 변하는 8초 세로 연결 컷 | 현재 추천 후보. 끝이 빗방울 클로즈업이라 다음 인물 장면으로 컷하기 좋다. 책 위 잉크가 글씨처럼 보일 수는 있어 최종 편집 때 확인 |

- 두 자산은 Google Flow 안에 저장돼 있다. 다른 PC에서 보려면 해당 Flow 프로젝트가 있는 동일 Google 계정으로 접속한다.
- 이전에 다뤘던 아밀리아, 김해원, 려원 영상도 별도 Flow 자산으로 있다. 전체 최종 편집본은 아직 조립하지 않았다.
- 앞서 생성한 말하기 영상은 테스트 단계다. 할머니 목소리의 나이감·온기·자연스러움은 아직 최종 승인되지 않았다.
- Flow 프로젝트의 두 책 영상은 각각 약 10크레딧을 사용했다. 마지막 확인 당시 해당 Flow 계정에 18크레딧이 남아 있었다. 크레딧은 변동될 수 있으니 생성 전 UI에서 확인한다.

## 다음 작업

1. 새 PC에서 저장소를 열고 이 문서와 `PROJECT_STATUS.md`를 읽는다.
2. 같은 Google 계정으로 위 Flow 프로젝트를 열어 자산이 보이는지 확인한다.
3. 사용할 인물 클립을 고른 뒤, 책 → 빗방울 → 인물 장면 순으로 약 15초 편집본을 조립한다.
4. 전환·길이·자막 안전 영역을 확인하고, 실제 로고와 최종 언어별 음성·자막을 넣는다.
5. 한자풍 가짜 문자, 인물 얼굴/손의 왜곡, 자막 가독성, 컷 사이 색감·음향을 검수한다.

## 저장소와 새 PC

- 저장소: <https://github.com/taeam73/pastlife>
- 이 문서는 앱 코드의 Git 저장소에 포함된다. GitHub에 푸시한 뒤 새 PC에서 같은 저장소를 clone/pull하면 읽을 수 있다.
- 저장소 파일을 동기화하는 것과 이 대화의 기록을 동기화하는 것은 별개다. 새 대화에서는 이 문서를 첨부하거나 저장소 경로를 가리켜 맥락을 전달한다.
- 2026-10-30 확인 당시 `marketing/` 디렉터리는 Git 미추적 상태였고, 영상·이미지 및 `.vendor` 라이브러리가 들어 있었다. 이 디렉터리는 문서 커밋에 포함하지 않는다. 필요한 로컬 마케팅 파일은 별도 업로드/동기화가 필요하며, Flow 자산은 Flow 클라우드에서 다시 연다.
