# LAST_STOP_TICKET 마지막 순간 검수 기록

- 2026-10-24 새 편집 기준 보강: 기존 작업실·로즈·애니·노라의 열쇠와 미완성 소매를 살리고, 에디스가 손목의 힘과 호흡 변화를 느끼는 장면 및 애니가 도움을 구하러 나가는 동선을 적었다. 전생록 화자가 그날 사망과 두 사람의 반응을 전한다. 특정 병명과 사망 원인은 미설정이며, 이 장면의 방문·대화·임종은 창작이다. `final-moment:check` 40편 등록 검사는 통과했다. 아래의 4/120, 웹·PDF·PNG 검사는 **이전 판본과 공통 내보내기 코드**에 대한 기록이다. 수정 판본의 소리 내어 읽기·가장 닮은 세 편·삽화 및 실제 화면 검수는 남았으므로 새 기준 승인으로 세지 않는다.
- 작성·확인: 2026-10-23
- 시기·장소: 1963년 잉글랜드 런던 서더크, 당시 영국(그레이트브리튼 및 북아일랜드 연합왕국)
- 인물: 에디스 리드(1890~1963, 73세), 여동생 로즈(1892년생), 조카 애니(1928년생). 세 인물은 창작이다.
- 기존 원고와의 연결: 03에서 1954년 노라 사별, 1957년 혼자 바닷가 여행, 1963년 런던 사망을 확인했다. 04의 두 작업실 열쇠·노라와 바닷가·로즈 및 애니의 기억을 마지막 장면에 사용했다. 1917년 버스에서의 화해를 마지막 사건으로 다시 쓰지 않았다.
- 새로 지은 사건: 죽는 날 로즈와 애니가 작업실에 찾아와 함께 앉는 일, 재킷 소매·찻잔·엽서·마지막 대사, 사후 애니가 소매를 마치는 일은 모두 소설적 창작이다. 특정 사인과 날짜, 실존인의 기록이라고 주장하지 않는다.
- 생활·그림 고증 범위: [Historic England의 1961년 런던 의류 작업장 기록](https://historicengland.org.uk/images-books/photos/item/BB037666)과 [1956년 여성 양장 작업장 사진 기록](https://historicengland.org.uk/images-books/photos/item/CC020811)은 해당 시기 런던의 옷 작업장이라는 생활 배경을 뒷받침한다. 에디스의 실제 작업실이나 도구 배열을 입증하지는 않는다. 기존 원고의 1922년 수선집 설립이 이어졌다는 창작 설정을 따른다. 그림은 기존 27세 에디스 초상 얼굴을 참고해 73세 모습으로 재생성했고, 서더크의 실제 거리 풍경을 재현한 사진은 아니다.
- 그림: `apps/mobile/assets/stories/v3/last-stop-ticket-final-moment.jpg` (1536×1024, 264104B). ImageGen 생성 후 두 번째 시안에서 노년 얼굴을 보정했다. 기존 1917년 차장 복식이나 현대 장치가 보이지 않는지 육안 검사했다.
- 자동 검사: 최신 `final-moment:check` 4/120, 콘텐츠 검사와 모바일 타입 및 API E2E 2건을 통과했다.
- 실제 웹 여정(2026-10-24): 인메모리 3.0 API의 여섯 답변으로 107번째 시도에서 에디스 결과를 선택했다. 320px에서 저장·공유 잠금 → 두 번째 테스트 광고 → 마지막 순간 읽기 → API `finalMomentRead=true` → 저장·공유 해제를 확인했다. 768px 화면에도 삽화·본문·끝 영역이 보이고 가로 넘침·브라우저 오류가 없었다.
- 파일 검사: 실제 앱 버튼으로 공유 PNG 1080×1800과 PDF를 내려받았다. 첫 PDF의 마지막 쪽이 문단 중간에서 시작하고 첫 편집 수정의 04 끝 문장만 별도 쪽에 남아 작성기를 조정했다. **최종 재검사 PDF는 10쪽, 1,913,877바이트**다. 04 전체와 별도 `전생록의 기록` 마지막 쪽을 렌더링해 줄바꿈과 맺음말을 확인했다. PDF는 이미지형이라 글자 검색·복사가 안 된다. 산출물은 `output/pdf/full-final-last-stop-ticket-*`, `output/playwright/full-final-last-stop-ticket-*`에 있다.
