# 전생록 추가 디자인 시안

기존 디자인 가이드의 A/B/C 비교를 보완하기 위한 추가 방향이다.

## D. 고서·도서관형

- 양피지, 잉크, 봉인, 책장 중심
- 시작과 결과를 오래된 기록지처럼 표현
- 전생·기록·역사 콘셉트를 가장 직관적으로 전달

## E. 별자리 운명 지도형

- 별자리 궤적, 노드, 지도선 중심
- 질문 진행을 별자리 연결 과정처럼 표현
- 결과 공유 카드와 진행감 강화에 적합

## F. 박물관 전시 카드형

- 전시 패널, 유물 카드, 설명 라벨 중심
- 전생 결과와 아카이브 컬렉션 확장에 적합
- 결과 화면을 전시품처럼 구조화

## 타이틀 로고 시안

생성된 투명 배경 로고 3종을 비교 자산으로 추가했다.

- `apps/mobile/assets/branding/title-logo-archive.png`: 금색 천문·기록 보관소형
- `apps/mobile/assets/branding/title-logo-book.png`: 고서·도서관형
- `apps/mobile/assets/branding/title-logo-celestial.png`: 별자리·운명 지도형

현재는 비교용 자산으로만 보관하고 앱 기본 타이틀에는 적용하지 않는다. 선택 후 모바일 헤더와 태블릿 타이틀 영역에서 가독성을 검증하고 적용한다.
