# 107번째 이야기 검수: 소 앞에 펼친 삼베

- **설정과 창작 범위:** 1120년 고려 수도 개경. [한국민족문화대백과의 개경 상업](https://encykorea.aks.ac.kr/Article/E0027204), [유통 역사](https://encykorea.aks.ac.kr/Article/E0041935), [연등회 역사](https://encykorea.aks.ac.kr/Article/E0036751), [고려시대 옷](https://encykorea.aks.ac.kr/Article/E0038892), [국립중앙박물관 고려실](https://www.museum.go.kr/ENG/contents/E0201040200.do?schM=list&showHallId=759&showroomCode=DM0036)을 2026-10-23 확인했다. 고려의 수도·시장·직물 거래·연등회는 역사적 조건이다. 연화 가족·좌판·소의 돌발 상황·대사는 창작이다. 1120년 특정 날짜·행렬이나 실존 장터의 사고라고 제시하지 않는다.
- **평생과 02:** 연화는 1080년에 태어나 마을에서 삼을 손질하며 자랐다. 개경 장터로 옮겨 삼베를 팔고 도윤과 솔의 살림을 꾸렸다. 뒤에는 나무 그릇도 함께 팔았고, 딸이 독립하고 남편을 먼저 보낸 뒤 이웃에게 베 짜는 법을 알려 주며 1149년까지 살았다. 01은 이 평생을 세 쪽으로 소개한다. 02는 연등회 날 놀란 소를 빈 마당으로 돌리기 위해 새 삼베를 펼친 한 사건이다. 천은 찢어지고 한 필 값을 다 되찾지 못한다. 사람들의 칭찬과 다음 장날의 손실을 모두 남겼다.
- **신호·정합성:** `notice`는 빈 마당과 소의 앞길을 봄, `speak`는 사람들에게 길을 비키라고 외침, `connect`는 수레꾼 은석에게 마당 쪽을 맡김이다. 1120년 40세, 1149년 69세로 01~04가 일치한다. 03에는 사건 밖의 일·가족·노년이 있고 04에는 도윤·솔·은석의 다른 평가가 있다. 여섯째와 다섯째 보기를 실제로 선택해 결과까지 이동했다.
- **그림과 검증:** 별도 1254×1254 시장 배경과 1254×1254 실제 투명 알파 연화 인물을 API·모바일에 매핑했다. 시대에 맞춘 분위기의 창작 그림이며 복식·건축의 정확한 복원은 아니다. 타입·콘텐츠/107개 그림쌍·다양성·단위·API E2E·320×720/768×1024 브라우저 결과 화면 검사가 통과했다. 01 세 쪽과 02~04, 그림 로드·가로 넘침을 확인하고 화면을 직접 살폈다. 실기기와 실제 독자의 흥미는 별도 검증 전이다.
