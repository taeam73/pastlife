# 86번째 원고·그림 검수 — 일터보다 먼저 닿은 곳

- ID: `PIER_BEFORE_WORK`. 할릴(1835~1910)은 1892년 오스만 제국 이스탄불 베식타시의 선박 수리공이었을 법한 **창작 인물**이다. 현 [이스탄불 공영 여객선 회사의 역사](https://sehirhatlari.istanbul/en/corporate/sirketi-hayriye-overview-102)는 19세기 보스포루스 증기선 운항을, [선착장·회사 계약 기록](https://sehirhatlari.istanbul/en/corporate/economic-structure-392)은 베식타시·위스퀴다르 선착장과 선박 유지 업무를, [선박 기록](https://sehirhatlari.istanbul/en/corporate/sirketi-hayriye-ships-393)은 1890년 외륜 증기선을 뒷받침한다. [메트로폴리탄 미술관](https://www.metmuseum.org/essays/the-later-ottomans-and-the-impact-of-europe)의 복식 개관도 참고했다. **2026-10-23 확인.** 실존 배편·수리 가게·가족·부상·대화·생애는 주장하지 않는다. 원고보다 앞선 [설정 대장](story-setting-register.md)에 시대·정치권·생애를 확정했다.
- 01은 아버지에게 목공을 배워 배의 나무 부품을 고친 일, 혼인과 두 아이, 손 부상 뒤 바뀐 일터, 아내를 먼저 보낸 노년까지 세 쪽으로 소개한다. 배에서 딸에게 말한 하루로 삶 전체를 규정하지 않는다. 화면에 쓰는 요약은 74자로 80자 계약 안이다.
- 02는 새 일자리를 구하러 가는 배에서 딸 에스마를 만나, 감춰 둔 실직을 알리는 하루다. `notice`는 딸의 시선을 알아보고 쪽지를 펴기, `speak`는 먼저 직접 말하기, `connect`는 다음 선착장에서 함께 내리자고 청하기로 시작 행동을 갈랐다. 셋 다 정기 일을 잃은 사실을 말하며, 딸의 화는 바로 풀리지 않는다. 할릴은 일자리 약속에 맞출 배를 보내는 비용을 치른다. 원고의 초반 쪽지·도구·앞치마 단서와 이후 반응, 전생록 화자의 도입·마무리를 대조했다.
- 03은 1835년 출생부터 1910년 사망까지 17개 사건으로 일뿐 아니라 부모·혼인·자녀·이사·아내 돌봄·부상·딸의 독립·손녀·상실·노년을 담았다. 04는 아내, 딸, 아들, 동료의 다른 평가를 남긴다. 집필 중 설정 대장과 연도 차이를 찾아 03의 수련·혼인·이사·아내 돌봄·집 수리 탁자 시기를 선행 설정에 맞췄다. 1892년 57세와 1910년 75세도 맞는다.
- 그림: `apps/mobile/assets/stories/v3/ottoman-besiktas-ferry-bg.jpg`(1254×1254)와 `ottoman-halil.webp`(1024×1536, 알파 0~254)를 별도 생성했다. 증기선·선착장, 페즈·작업복·대패·쪽지가 원고의 시기와 역할에 맞는다. 특정 실존 증기선의 정확한 모양이나 모든 노동자의 복식이라고 단정하지 않는다. 직전 타비의 14세기 농가와 시대·지역·나이·성별·직업·그림 구성이 다르다.
