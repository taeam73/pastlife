# 63번째 라이브 검수 — 얼음 위의 과자

**아말리아 로하스 · 여성 · 1881~1951년 · 1910년 아르헨티나 공화국 부에노스아이레스.** [선행 설정 대장](story-setting-register.md)에 실제 시기·장소·정치권과 창작 인물의 성별·생몰·평생의 흐름을 원고보다 먼저 확정했다. [아르헨티나 정부의 팔레 드 글라스 건축사](https://www.argentina.gob.ar/archivo-con-foco-en-el-salon-nacional-de-artes-visuales/el-edificio)는 1910년 7월 개장한 실내 빙상장, 주변 관람석·위층 카페·오르간·냉각 설비를 설명한다(2026-10-23 확인). 과자 주문, 아말리아·이네스·손님과 사고는 창작이다. 삽화는 실내 공간의 분위기를 그린 것이며 실제 건물의 세부 복원이 아니다.

## 원고 자체 검수

- **01** 세 쪽에 신원·생몰·장사, 성격·취향·솜씨, 아낀 물건·관계·바람·걱정을 짧게 배치했다. 삶 한 줄은 부모에게 배운 일에서 자기 좌판·이네스와의 동업·언니와 조카의 귀환·가게 인계까지 이어진다. 빙상장의 과자 사고를 삶 전체로 정의하지 않는다.
- **02** 전생록의 도입·마무리 사이에 열두 개 주문, 일곱 개와 다섯 개의 분리, 난간 너머로 떨어진 금속 접시, 얼음에 들어가 치우는 행동, 손님과의 대금 협상과 좌판에서의 장부 확인이 이어진다. `notice`는 미끄러져 올 사람을 보고, `speak`는 위험과 손님에게 줄 수 없는 과자를 알리고, `connect`는 스케이트를 신은 이네스에게 도움을 청한다. 각 답 뒤에 실제로 과자를 수거하며 얼음에 닿은 것과 남은 일곱 개를 구분한다. 여섯 개를 잘라 열두 조각으로 내고 남은 한 개를 생일 맞은 사람에게 주지만, 주문 값을 줄이고 손님의 불평도 남긴다. 사고가 장사의 대성공으로 바뀌지 않는다.
- **03** 1881년 출생부터 1951년 사망까지 14개의 간결한 사건에 부모·언니, 좌판·동업·각자의 가게, 조카와의 동거, 손목 통증·가게 인계·노년을 넣었다. 1910년 29세, 사망 때 70세가 맞다.
- **04** 계량컵·좋아한 소리·가게·남긴 말과 언니·친구·조카·손님의 다른 평가로 평생을 되돌아본다. 낯선 독자도 과자 수와 선택의 결과를 따라갈 수 있도록 낱말과 인과를 검수했다.

## 그림과 검증

- 고유 배경 `cakes-on-ice-palais-bg.jpg` **1254×1254, 243KB**, 알파 인물 `cakes-on-ice-amalia.webp` **1024×1536, 93KB**를 API·모바일에 연결했다. 첫 배경에 전경 인물이 중복돼 별도 배경으로 다시 만들었다. 첫 인물 생성본은 가로가 긴 1295×1215 형태라 미승격하고, 세로형 투명 인물을 새로 제작했다. 전경의 작은 접시·과자와 별도 인물의 남은 과자 접시가 원고의 두 접시와 연결된다.
- 카드·원고·API 그림 매핑 **63/63**, 고유 그림 **63쌍** 검사 통과. 콘텐츠·API·모바일 타입, 집중 단위·콘텐츠 도달성 **27개**, 다양성 **4개**, API E2E **2개** 통과. 첫 인물 그림이 세로형 자산 검사를 통과하지 못해 교체 후 재검사했다.
- `e2e/mobile-cakes-on-ice.spec.ts` 통과. 320px·768px 실제 결과 화면에서 원본 그림 로드, 01 세 쪽, 02~04 본문 도달, 가로 넘침과 제목/양피지 비겹침을 확인했다. `output/playwright/story-cakes-on-ice-320-1.png`와 `story-cakes-on-ice-768-1.png`를 육안 점검했다. 320px에서 얼굴과 글자가 읽히며 과자 접시와 빙상장 전체는 768px에서 더 분명하다.
- 실제 독자 반응·실기기 검증과 기존 44편의 01·03 전수 보강은 남아 있다. 커밋·푸시·배포는 하지 않았다.
