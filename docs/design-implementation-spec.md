# 전생록 디자인 구현 명세

## 적용 방향

판타지 기록 보관소를 기본으로 한다. 화면은 어두운 기록 보관소의 배경 위에 금빛 강조와 역사 장면 이미지를 배치하고, 질문은 짧고 분명하게, 결과는 기록 카드와 챕터로 보여준다.

## 디자인 토큰

| 항목 | 값 | 사용 |
|---|---|---|
| 배경 | `#0D1420` | 전체 화면 |
| 표면 | `#172235` | 카드와 입력 영역 |
| 강조 표면 | `#21314A` | 선택된 카드·결과 카드 |
| 본문 | `#F4F0E7` | 제목과 주요 문장 |
| 보조 텍스트 | `#AAB7C9` | 설명·상태·보조 정보 |
| 금빛 강조 | `#D6B36A` | 제목 포인트·진행·테두리 |
| 오류 | `#F09A8A` | 오류 상태 |
| 간격 | 8 / 12 / 20 / 32 / 48px | 일관된 여백 체계 |
| 모서리 | 12–20px | 카드·버튼·히어로 |

## 화면 규칙

### 시작 화면

- 제목은 텍스트로 유지하고 기록 문양은 보조 장식으로 사용한다.
- 첫 행동은 하나의 주요 버튼으로 제한한다.
- 실제 전생 판정이 아닌 창작 엔터테인먼트라는 고지를 시작 전에 제공한다.

### 질문 화면

- 상단에 `현재 단계 / 전체 6단계`를 표시한다.
- 선택지는 실제 버튼이며 한 번 선택하면 명확한 선택 상태를 보여준다.
- 문항은 한 화면에서 읽히도록 유지하고 장식보다 선택 가독성을 우선한다.
- 네트워크·저장 실패 시 현재 단계와 선택 상태를 보존한다.

### 결과 화면

- 결과 헤드라인 → 역사 장면 → 인물 카드 → 삶의 기록 → 챕터 순서를 유지한다.
- 이미지가 없어도 텍스트 결과와 행동 버튼은 완전히 사용할 수 있어야 한다.
- 이미지 레이어는 배경·인물·효과를 분리하고 대체 텍스트를 유지한다.
- 기본 결과, 심화 결과, 현생 가이드는 별도 잠금 상태와 재시도 상태를 표시한다.
- 공유 버튼은 결과가 준비된 뒤에만 활성화한다.

## 모션

- 질문 전환은 짧은 fade 또는 slide만 사용한다.
- 결과 공개는 이미지와 텍스트를 순차적으로 표시하되 1초 이상 지연하지 않는다.
- 모션을 사용할 수 없는 환경에서도 정보 순서와 의미가 유지되어야 한다.

## 접근성 및 품질 기준

- 본문 대비를 충분히 유지하고 금빛만으로 상태를 구분하지 않는다.
- 버튼은 텍스트 라벨과 접근성 역할을 갖는다.
- 이미지에는 의미에 맞는 대체 텍스트를 제공한다.
- 320px 폭에서도 제목·버튼·카드가 잘리지 않아야 한다.
- 로딩·오류·재시도 상태를 시각적으로 구분한다.

## 구현 순서

1. 시작·질문·결과 토큰과 공통 컴포넌트 점검
2. 결과 화면의 카드 순서·이미지 레이어·공유 상태 점검
3. 좁은 화면과 긴 문장에 대한 레이아웃 검증
4. 브라우저 E2E 및 수동 스크린샷 검토
5. 콘텐츠 문구 변경은 별도 콘텐츠 승인 단위로 처리
