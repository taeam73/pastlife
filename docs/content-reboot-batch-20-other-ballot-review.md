# 60번째 라이브 검수 — 다른 표

**마거릿 홀 · 여성 · 1851~1926년 · 1893년 11월 28일 영국령 자치 식민지 뉴질랜드 크라이스트처치.** [선행 설정 대장](story-setting-register.md)에 당시 정치권과 한 사람의 평생을 원고 집필 전 확정했다. [뉴질랜드 문화유산부](https://nzhistory.govt.nz/page/women-vote-first-general-election)는 1893년 11월 28일 첫 여성 총선 투표를, [뉴질랜드 의회](https://www3.parliament.nz/mi/visit-and-learn/how-parliament-works/fact-sheets/participation/)와 [1893년 선거법](https://www.legislation.govt.nz/act/public/1893/18/en/latest/)은 일반 선거구의 비밀투표를 뒷받침한다. [Te Ara의 의복업 자료](https://teara.govt.nz/en/clothing-and-footwear-manufacturing/page-1)는 시대의 여성 양장업을 확인해 준다. **2026-10-23 확인.** 마거릿·애니·클라라·손님, 개인의 표와 작업실 사건은 창작이다.

## 원고 자체 검수

- **01** 이름·성별·연대·장소·일, 성격·취향·관계·바람·걱정을 세 쪽에 짧게 제시했다. 77자의 삶 요약은 바느질을 배운 젊은 시절, 딸 양육과 사별, 작업실 운영, 애니에게 일 넘기기와 딸 가족 곁 노년을 잇는다. 02의 투표나 한 가지 성향으로 평생을 규정하지 않는다.
- **02** 전생록 화자의 도입과 마무리 안에 잃어버린 단추, 정오까지의 외출복 약속, 애니의 긴 투표 줄, 마거릿의 선택, 손님 앞에서 드러난 미완성 안쪽 여밈, 고쳐서 늦게 전달한 대가를 장면과 대화로 썼다. `notice`는 줄과 남은 일을 보고 애니를 다시 보내고, `connect`는 돌아온 뒤 점검할 일을 맡기며 보내고, `release`는 후보 쪽지를 접고 애니에게 선택을 맡긴다. 어느 경로에서도 애니의 투표 기회와 마거릿이 진 작업 위험이 사라지지 않는다. 마거릿이 자신의 투표를 이른 아침에 마쳤다는 시점도 통일했다. 애니의 다른 선택은 두 사람의 관계를 즉시 교훈으로 정리하지 않으며, 손님의 덜 받은 돈은 돌아오지 않는다.
- **03** 1851년 출생부터 1926년 사망까지 16개의 간단한 사건. 어머니, 학교, 견습, 혼인, 딸, 사별, 독립 작업실, 청원·투표, 딸의 독립, 애니와 공동 운영, 손의 통증, 외손자, 일 인계와 노년을 포함한다. 1893년 42세, 1926년 75세가 맞는다.
- **04** 바늘집, 편지와 천, 작업실, 일할 때 남긴 말, 딸·애니·이웃 손님의 서로 다른 평가로 평생의 여러 면을 남겼다. 첫 투표 에피소드만 반복하지 않는다.
- 크라이스트처치의 투표소·작업실·옷·가족은 당대에 있을 법한 창작 재현이다. 특정 실존 후보·선거구·득표 결과나 실제 인물의 일화로 주장하지 않는다.

## 그림과 검증

- 고유 배경 `other-ballot-christchurch-bg.jpg` **1254×1254, 256KB**, 투명 인물 `other-ballot-margaret.webp` **1024×1536, 106KB**를 API·모바일에 연결했다. 작업대의 짙은 외출복·단추, 목조 작업실의 창밖 투표 줄과 실용적인 1890년대 옷이 원고의 단서와 맞는다. 최근 아크라 경기장·킬와 항구·오사카 무대와 장소와 옷의 형태가 뚜렷하게 다르다. 인물 WebP에 실제 알파 채널이 있다.
- 카드·원고·API 그림 매핑 **60/60**, 고유 1024px급 배경·투명 인물 **60쌍** 검사 통과. 콘텐츠·API·모바일 타입, 집중 단위·콘텐츠 도달성 **27개**, 다양성 **4개**, API E2E **2개** 통과.
- `e2e/mobile-other-ballot.spec.ts`로 320px·768px 실제 결과 화면의 원본 그림 로드, 01 세 쪽, 02~04 본문 도달, 가로 넘침 없음과 제목/양피지 비겹침을 확인했다. `output/playwright/story-other-ballot-320-1.png`와 `story-other-ballot-768-1.png`를 육안 점검했다. 휴대폰에서 소개문이 인물의 몸통 위를 지나지만 얼굴과 글자는 구별되고, 작업실 전체와 투표 줄은 태블릿에서 더 선명하다.
- 실제 독자와 실기기 검증, 기존 44편의 01·03 전수 보강은 남아 있다. 커밋·푸시·배포는 하지 않았다.
