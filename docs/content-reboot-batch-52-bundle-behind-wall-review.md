# 92번째 원고·그림 검수 — 벽 뒤의 꾸러미

## 선행 설정과 역사 경계

- 원고 집필 전에 [설정 대장](story-setting-register.md)에 **서기 400년 무렵 중앙멕시코 테오티우아칸 도시 정치권**, 여성 나야(368~431)의 출생부터 노년까지를 확정했다.
- [유네스코 테오티우아칸](https://whc.unesco.org/en/list/414/), [메트로폴리탄 미술관의 도시·주거·흑요석 설명](https://www.metmuseum.org/TOAH/hd/teot/hd_teot.htm), [멕시코 국립인류역사연구소의 도시 생활·전문 노동](https://visitateotihuacan.inah.gob.mx/aprende/teotihuacan-ritualidad-urbanismo/)을 **2026-10-23** 확인했다. 도시·시기·공동 안마당 주거와 흑요석 작업이 역사 근거다. 이름 나야·이타, 가족, 꾸러미 사건, 대화와 평가, 개인의 생몰 연도는 창작이다. 당시의 자칭 국가명이나 언어를 단정하지 않았다.

## 원고 검수

- 01은 아버지에게 일을 배우고, 혼인·딸·사별·이웃과의 일·손자와 노년까지를 세 쪽에 담았다. 꾸러미 사건의 교훈으로 평생을 규정하지 않았다.
- 02는 전생록 화자가 시작과 끝을 맡고, 친구의 이사 준비 → 꾸러미 은닉 → 이웃의 의심 → 자백 → 이타의 실제 이사와 끊긴 신뢰를 장면·대화로 이어 간다. 답변별 첫 행동 셋 모두 꾸러미를 회수하고 사실을 밝히는 공통 장면에 도달한다. 나야의 사과가 관계를 곧바로 회복시키지는 않는다.
- 03은 368~431년 사이의 가족·친구·일·상실·재회·이주·노년 15개 사건을 출생부터 사망까지 한 줄씩 적었다. 04에는 딸·이타·옆집 사람·손자의 서로 다른 기억이 있다. 원고와 설정 대장의 연도·관계·이사의 원인과 대가를 대조하고, 설정 대장에 남아 있던 ‘의심이 생기기 전’, ‘말없이 떠남’이라는 모순을 바로잡았다.

## 그림·도달성·화면

- 별도 배경 `teotihuacan-shared-courtyard-bg.jpg` **1254×1254**, 인물 `teotihuacan-naya.webp` **1024×1536**. 인물의 실제 알파 범위는 **0~254**다. 첫 배경은 직사각형이라 검사에서 거부되어 원 장면을 정사각형으로 확장 생성한 뒤 다시 검사했다.
- API·모바일 자산 경로를 연결했고, 자산 검사에서 **92개 별도 1024px급 그림 쌍**을 확인했다. 타입·단위·콘텐츠·다양성·API E2E와 전용 320×720·768×1024 브라우저 결과 화면 검사 통과. 세 쪽 소개, 02~04 도달, 이미지 로드와 가로 넘침·패널 겹침을 확인하고 실제 스크린샷을 열어 검토했다.
- 배경·복식은 시대와 지역에 맞춘 창작적 시각화이며 정확한 5세기 생활복 재현을 증명하지 않는다. 실제 독자 반응, 실기기와 기존 44편의 01·03 전수 보강은 미검증이다. 커밋·푸시·배포하지 않았다.
