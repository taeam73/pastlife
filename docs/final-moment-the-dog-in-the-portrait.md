# 아스타 욘스도티르 · 마지막 순간 검수

- 2026-10-24 확인. `THE_DOG_IN_THE_PORTRAIT`의 아스타는 1863~1937년생, 사망 때 74세다. 중심 02 사건인 1895년은 덴마크 국왕 통치 아래의 아이슬란드, 마지막 1937년은 1918년 주권국이 된 뒤 덴마크 국왕과 동군연합한 **아이슬란드 왕국**으로 구분했다. [아이슬란드 의회 알팅의 역사](https://www.althingi.is/pdf/Althingi2017_enska.pdf)를 확인했다.
- 19세기 후반 아이슬란드 여성 사진가의 활동은 [아이슬란드 국립박물관의 니콜리네 웨이와트 전시](https://www.thjodminjasafn.is/en/syningar/nicoline-weywadt)와 [여성 사진가 전시](https://thjodminjasafn.is/en/syningar/i-skugganum)로 확인했다. 건판 촬영·인화의 기술적 맥락은 [미국 의회도서관](https://www.loc.gov/static/collections/civil-war-glass-negatives/articles-and-essays/taking-photographs-during-the-civil-war/)을 참고했다. 1937년 아스타의 사진·작업실·가족·대사와 마지막 날은 모두 창작이다. 특정 실존 사진가의 생애를 재현하지 않는다.
- 02의 개가 끼어든 가족사진을 재연하지 않았다. 사진관을 조카에게 넘긴 노년, 여동생과 검은 천, 이름을 적지 않은 항구 일꾼의 사진을 중심에 놓았다. 인물의 이름을 지어 쓰지 않겠다는 선택, 여동생·조카의 짧은 반응, 전생록 화자의 마무리를 01~04와 대조했다. 여동생과 조카의 생존·동석은 창작 설정이다.
- 기존 투명 인물의 얼굴·옷차림과 사진관을 참조해 74세 모습의 고유 **1536×1024** 삽화를 생성했다. 이는 1937년 레이캬비크의 특정 사진관이나 복식을 정확히 복원한 그림이 아니다.
