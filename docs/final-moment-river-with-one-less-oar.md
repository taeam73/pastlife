# 마리아나 데 라 크루스 마지막 순간 검수 기록

**2026-10-25 갱신:** 아래는 종전 길이자·푸른 천 결말과 당시 개별 내보내기 검사 이력이다. [생애 감사](life-deep-audit-river-with-one-less-oar.md)에서 1840년 베니토의 쌀 손실을 보강했고, 기존 마지막 원고의 사망 경위 누락은 [재작업 감사](final-moment-deep-audit-river-with-one-less-oar.md)의 고열·이사벨 장면으로 고쳤다. 아래 PDF·공유 결과는 현재 원고의 최종 승인 근거가 아니며, 120편 원고·데이터·삽화 확정 뒤 일괄 생성·검수한다.

2026-10-24 기준. `RIVER_WITH_ONE_LESS_OAR`의 마리아나·페드로·로사·이사벨은 **창작 인물**이며 마지막 날, 대화, 사후 반응도 창작이다. 실재 배경은 **1857년 스페인 제국 통치 아래 필리핀 마닐라 비논도**다. [미국 의회도서관의 마닐라 식민지 설명](https://blogs.loc.gov/international-collections/2021/10/negotiating-empire-part-i-from-magellan-to-the-founding-of-manila-16th-18th-centuries/)은 스페인의 마닐라 지배와 지역 교역의 형성을 설명한다. [필리핀 국립역사위원회의 비논도 등대 기록](https://philhistoricsites.nhcp.gov.ph/registry_database/parola-ng-binondo/)은 파시그강 하구와 비논도의 수변 지리·항해 표지를 뒷받침한다. 1832년 강변 창고·화물선은 [원고 집필 전 설정 대장](story-setting-register.md)에 기록한 당시 여행 자료와 대조했다. 어느 자료도 이 가족의 특정 마지막 날을 기록하지 않는다.

## 01~04와의 연결

- 1790~1857년·67세, 딸 로사는 1813년생이므로 마지막 장면에서 44세다. 남편 페드로는 1848년에 먼저 사망했고, 어린 시절 친구 이사벨은 말년에도 왕래했다. 기존 연대기와 관계를 유지했다.
- 04의 **아버지 나무 길이자**, 이사벨과 천을 고르던 취향, 페드로와 듣던 물소리, 로사가 어머니에게 만들어 준 옷을 소재로 삼았다. 마지막 날의 푸른 천과 세 사람의 대화, 사후 로사가 만든 옷은 창작 선택이다.
- 02의 딸 첫 출근·짐 선적과 유급 일손 갈등을 되풀이하지 않았다. 마리아나는 강가의 일과 이미 떠난 사람을 더 붙들고 싶어 하면서도, 딸이 자기 손으로 옷을 지을 시간을 기대한다. 전생록 화자가 남은 사람들의 짧은 행동을 전하고 다음 삶으로 장을 넘긴다.

## 그림·앱 검사

- 기존 마리아나의 얼굴·복장과 비논도 강변 배경을 참조해 일상적인 강가의 마지막 저녁을 제작했다. 첫 생성본에서 주인공이 67세보다 젊게 보이고 오랜 친구도 젊어 보여 둘의 얼굴과 머리 나이 표현을 보정했다. `apps/mobile/assets/stories/v3/river-with-one-less-oar-final-moment.jpg`는 **1536×1024, 355,572바이트**다. 세 인물의 옷·수변 집·날씨 세부는 창작 시각화다.
- `final-moment:check` **14/120**, `content:check`, 모바일 타입, API E2E **2건** 통과. 실제 여섯 답변으로 마리아나를 선택해 첫 테스트 광고 → 320px 결과 저장 잠금 → 두 번째 테스트 광고 → 마지막 순간과 그림 → 읽음 기록 → 결과 PDF·PNG 해제의 웹 E2E가 통과했다. 320px·768px에서 가로 넘침이 없었다.

- 실제 Android/iOS 저장·공유창, 운영 광고, 영속 DB, 남은 **106편**의 마지막 순간과 전편 실제 기기 화면 검사는 남았다. 전체 출시 경험 완료는 **0/120**이다.
