# 102번째 원고·그림 검수 — 배에 남은 빈자리

- **집계:** `storyCards` 102개, 각 편에 대응하는 원고와 고유 배경·인물 그림 102쌍. 120편까지 18편 남았다. API 이미지 매핑과 모바일 정적 자산 목록에 `RIVER_WITH_ONE_LESS_OAR`를 연결했다.
- **선행 설정:** 집필 전에 [설정 대장](story-setting-register.md)에 1832년 스페인 통치 아래 마닐라 비논도, 여성 마리아나 데 라 크루스(1790~1857), 강가의 일·가족·친구·딸의 독립·노년을 확정했다. 이전 작품의 아바나·야구·조카의 약속과 시기·장소·관계·소품이 다르다.
- **역사 근거:** [미국 의회도서관의 스페인 통치 아래 마닐라 개관](https://blogs.loc.gov/international-collections/2021/10/negotiating-empire-part-i-from-magellan-to-the-founding-of-manila-16th-18th-centuries/)과 [1832년 마닐라 여행 기록](https://tile.loc.gov/storage-services/service/gdc/gdclccn/05/01/20/55/05012055/05012055.pdf)을 2026-10-23 확인했다. 후자는 비논도와 산타크루스 쪽 수로·창고·카스코 화물선을 묘사한다. 마리아나와 가족·친구·직업 계약·대화는 창작이며 당시 모든 여성의 삶을 대표한다고 주장하지 않는다.
- **원고:** 01은 02의 선택으로 평생을 규정하지 않고 출생부터 강가 노년까지 생활·관계·취향을 세 쪽에 담았다. 02는 로사의 바느질 첫날과 이미 받은 선적 약속이 겹친 아침을 장면과 대화로 진행한다. 마리아나는 딸을 붙잡는 대신 마테오에게 삯을 주고 짐을 나눠 싣는다. 돈을 잃고 모녀의 서운함은 곧바로 풀리지 않는다. 답변의 첫 행동은 짐 확인·딸에게 묻기·일손 찾기이며, 03은 13개 사건으로 이후 삶까지 보여 준다. 04는 딸·친구·일꾼의 서로 다른 평가를 남긴다.
- **그림:** `binondo-river-empty-place-bg.jpg`는 1254×1254의 인물 없는 강변·카스코 배경이다. `binondo-mariana-de-la-cruz.webp`는 1024×1536의 실제 알파를 가진 별도 인물이다. 첫 가로형 인물 후보는 세로형 제작 기준에 맞지 않아 사용하지 않았다. 두 번째 그림은 비논도의 물가와 어울리는 빛을 지녔으나 복식·건축의 세부 복원은 전문가 검증 전이다.
- **검사:** 타입, 102개 그림쌍·콘텐츠 다양성·매핑·도달성, 전체 단위 테스트, API E2E가 통과했다. 전용 브라우저 테스트에서 320×720과 768×1024의 01 세 쪽, 02~04 접근, 이미지 로드·가로 넘침을 확인하고 캡처를 시각 검사했다. API 이미지 공급자도 정확한 배경·인물 URI를 반환한다.
- **한계:** 실제 독자의 흥미·이해도, 실기기, 특정 창고·복식의 정확한 복원은 별도 검증이 필요하다. 초기 44편의 01·03 전수 보강도 남아 있다.
