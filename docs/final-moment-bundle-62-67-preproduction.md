## 02·그림 연결 확인

- 여섯 편 모두 `storyCards`의 `notice`·`connect`·`speak`와 02 본문이 존재한다. 선행 65~74번 국소 감사에서 02에 없는 대사·동작·손실을 카드에서 고쳤고, 62~64번의 세부 오류도 별도로 바로잡았다. 이번 대조에서 62번 설정 대장의 `도난 의심`·`이틀치 추가 삯`을 현 02의 딸 찾기·다음 날 별도 삯으로 맞췄다. 63번 설정 대장의 1926년 `헤어짐`도 동업 종료와 계속된 방문으로 명시했다.
- 제작 전에는 62~67번 모두 마지막 삽화 URI가 없었다. 현재는 62~64번의 고유 그림·URI가 연결됐고 65~67번은 미등록이다. 기존 02의 기본 삽화와 최종 순간의 그림을 혼동하지 않는다. 원고·설정·03 사망 행을 확정한 뒤 고유 그림을 제작하고 작품별 URI와 실제 파일을 연결한다.
- 마지막 순간 원고는 먼저 **언제·어디서·누가 곁에 있는지, 주인공이 무엇을 보고 듣고 말하고 하는지, 끝이 어떻게 닥치는지**를 네다섯 장면으로 써서 서로 나란히 비교한다. 화자는 사후 주변인의 짧고 서로 다른 반응을 전한다. 02의 소품·직업·노년의 일 인계를 여섯 편의 공통 결말로 쓰지 않는다.
- 그림은 각 장면에서 다른 거리·시점·인물 배치를 정한다. 높은 수직 시점, 문 밖에서 안을 보는 시점, 원거리 측면, 주인공의 시야에 가까운 시점 등은 후보일 뿐 본문에 맞을 때만 쓴다. **쓰러진 주인공을 옆 사람이 부축하고 다른 사람이 도움을 부르러 뛰어가는 구도는 금지**한다. 인물을 모두 같은 병상과 동일한 얼굴 거리로 놓지 않는다.
- 역사 자료는 각 설정 대장에 연결된 장소·시기·생활 조건의 근거다. 여섯 인물의 개인 생애·대화·새로 정할 사망 경위는 창작으로 분리한다. 정확한 병명·의학적 사인은 근거 없이 붙이지 않는다.

이 대조는 제작 순서를 잡기 위한 기록이다. 62~64번은 기술 등록 뒤에도 작품별 낭독·시대 세부·실제 화면 확인이 남는다. 65~67번 세 편은 마지막 원고·그림도 남는다. 기술 등록 **64/120**, 생애 수정 초안 **97/120**, 새 편집 기준 승인·전체 출시 경험 **0/120**이다. PDF와 공유 이미지는 120편 원고·데이터·삽화 확정 후에만 일괄 생성·열어 검수한다.

## 64번 제작안 기각 — 2026-10-25
