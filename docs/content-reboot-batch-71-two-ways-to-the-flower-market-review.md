# 111번째 원고 검수 — 꽃 시장으로 가는 두 물길

2026-10-23. `TWO_WAYS_TO_THE_FLOWER_MARKET`은 1518년 멕시카 삼국동맹 지배권의 소치밀코에서 꽃을 가꾼 창작 인물 소치틀의 이야기다. 집필 전에 [설정 대장](story-setting-register.md)에 당시 정치권·장소·생몰·평생·출처와 창작 범위를 기록했다.

## 역사 조건과 창작

- [INAH 소치밀코 역사 자료](https://inah.gob.mx/images/suplementos/20201612_tlacuache_964.pdf)는 멕시카 삼국동맹 지배권을, [INAH 수로 연구](https://arqueologia.inah.gob.mx/publico/especifico.php?id=MTAx)와 [템플로 마요르 농업 전시](https://www.templomayor.inah.gob.mx/salas-del-museo/sala-7-agricultura)는 치남파 농업·배의 이동과 시장을 설명한다. [유네스코 소치밀코](https://whc.unesco.org/en/list/412)와 [INAH 티틀라텔롤코 시장 안내](https://difusion.inah.gob.mx/images/guias/117_tlatelolco.pdf)는 수로와 꽃 거래의 배경이다. [메트 시대 연표](https://www.metmuseum.org/de/toah/ht/08/canm.html)는 이후 1521년 정치권 변화를 확인하는 자료다. 2026-10-23 확인했다.
- 소치틀·가족·갈림 수로·꽃을 기다리던 손님·대화는 창작이다. 실제 1518년의 개인·뱃길·장날 기록을 재현하지 않는다. 이미지의 배와 복식은 역사 자료를 바탕으로 한 상상이며 정확한 유물 복원은 아니다.

## 원고와 그림

- 01은 어린 시절 아버지의 밭, 남편과 딸과 함께한 생활, 전쟁 뒤의 밭일, 남편을 보낸 뒤의 노년을 요약한다. 02의 노를 건네받은 날 하나로 평생을 정의하지 않았다.
- 02는 꽃배가 잘못된 갈림 수로로 들어선 걸 알아본 순간부터, 아버지의 체면과 두 사람의 대화, 늦어진 시장과 팔지 못한 꽃, 돌아오는 길에 나눈 일을 장면으로 썼다. `notice`·`speak`·`connect`의 행동을 나눴다. 03은 1490~1559년 생애 13지점, 04는 아버지·딸·친척의 다른 기억이다.
- 1254×1254px 고유 소치밀코 수로 배경과 알파 채널이 있는 1254×1254px 전신 인물을 API·모바일에 연결했다. 사용자가 요청한 기존 사실적 회화 화풍을 인물 그림에 유지했다.

## 확인 범위

타입, 콘텐츠·그림·다양성, 단위, API E2E, 여섯째·다섯째 보기를 선택한 320px·768px 결과 브라우저 검사가 통과했다. 휴대전화의 세 프로필 페이지와 태블릿 결과 스크린샷을 직접 확인했다. 실제 독자 반응·물리적 기기·복식 및 식물 종의 정밀 고증은 미검증이며 초기 44편의 01·03 전수 점검도 남았다.
