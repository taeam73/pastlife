# 105번째 이야기 검수: 계단에 선 달

- **설정과 사실·창작 구분:** 1900년 칠레 공화국 발파라이소의 세로 콘셉시온. [칠레 국립도서관의 발파라이소 연대기](https://www.memoriachilena.gob.cl/602/w3-article-7670.html), [당시 공연 생활](https://www.memoriachilena.gob.cl/602/w3-article-3550.html), [유네스코의 항구·언덕 자료](https://whc.unesco.org/en/list/959)를 2026-10-23 확인했다. 승강기·언덕길·공연 문화와 1906년 지진 뒤의 이주는 역사적 배경이다. 마누엘과 가족·친구·달 소품·공연·대사는 창작이며 실존 극장이나 실제 공연 기록으로 소개하지 않는다.
- **한 사람의 삶:** 마누엘은 1862년 발파라이소에서 태어나 항구의 짐길과 간판 그림을 배웠다. 누나 필라르와 조카 루스를 가까이 두고 낮에는 짐을, 밤에는 공연 소품을 맡았다. 1906년 지진 뒤 비냐델마르로 옮겼고, 무릎이 아파진 뒤에는 간판 작업과 작은 화분에 시간을 썼다. 1935년에 사망했다. 01은 이 생활·일·관계·변화를 세 쪽 프로필로 소개한다. 달 소품의 실수를 평생의 정의로 삼지 않는다.
- **02의 독립성:** 무대에 올릴 천 달을 어떻게 만들었는지와 공연 시간을 먼저 보여 준다. 승강기 문보다 큰 소품을 접자 젖은 페인트가 갈라지고, 무대에서 금이 벌어지자 루스가 즉석 대사로 웃음을 만든다. 마누엘의 선택은 공연을 제시간에 시작하게 했지만 아우렐리오가 원한 조용한 장면을 잃게 하고 보수 일부를 줄인다. 웃음을 모두의 승리로 포장하지 않는다. 화자의 도입과 마무리, 대화와 선택·대가를 갖춘다.
- **질문·결과 연결:** 3.0의 질문 24개와 질문당 보기 6개를 유지한다. 이 편의 `notice`는 접을 수 있는 틀과 젖은 페인트 확인, `speak`는 승강기 직원에게 묻기, `connect`는 다른 짐꾼에게 계단 운반을 부탁하는 장면이다. 브라우저에서 첫 질문의 여섯째 보기와 둘째 질문의 다섯째 보기를 실제로 선택해 결과에 도달했다. 기존 2.5 질문과 초기 44편은 보기 확장만을 위해 수정하지 않았다.
- **연대·관계:** 사건 때 38세, 사망 때 73세. 루스는 1888년생으로 1900년 12세이며 1906년 이주 때 18세다. 필라르·루스·아우렐리오의 관계는 01~04에서 일치한다. 03은 02 밖의 배움·가족·이주·건강·노년을 담고, 04는 세 사람이 서로 다른 면을 기억한다.
- **그림:** `valparaiso-moon-on-stairs-bg.jpg`는 1254×1254, `valparaiso-manuel-ibarra.webp`는 1024×1536의 실제 알파 채널을 가진 인물이다. API와 모바일에 각각 매핑했다. 배경은 빈 승강기 역과 계단, 접히는 달을 보여 주고, 인물은 짐꾼이자 소품 제작자다. 생성 그림의 복식·승강기 세부가 정확한 학술 복원이라고 주장하지 않는다.
- **검증:** `pnpm typecheck`, `pnpm content:check`(105개 고유 그림쌍·도달성·다양성), `pnpm test`(API 111개 포함), `pnpm test:e2e`(API 2개), Edge Playwright 320×720·768×1024 결과 화면 검사가 통과했다. 01 세 쪽, 02~04 도달성, 그림 로드와 가로 넘침을 확인했다. 첫 320px 검사에서 01 첫째 쪽의 긴 소개가 로고 가까이 올라간 것을 발견해 문장을 줄였고 재검사와 이미지 확인을 통과했다. 실제 독자 이해도·실기기·역사적 그림 세부는 별도 검증 전이다.
