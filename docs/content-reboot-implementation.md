# 전생록 이야기 중심 콘텐츠 3.0

2026-10-21 구현 기록. 이 문서는 과거의 종이 시안이 아니라 현재 코드에 연결한 콘텐츠의 기준이다. 실제 사용자 반응을 측정한 결과는 아니다.

## 경험의 목적

- **흥미:** 첫 문장에서 이상한 사건 또는 낯선 삶의 궁금증을 만든다.
- **재미:** 웃음만이 아니라 추리·긴장·경이·두려움·탐험·회복처럼 다음 장면을 읽고 싶은 감정을 포함한다.
- **공감:** 선택한 행동 한두 개가 이야기 속 행동으로 되돌아오고, 마지막에 지금의 자신을 떠올릴 질문을 남긴다. 성격·질병·트라우마의 실제 원인을 전생이라고 판정하지 않는다.

## 실제 적용

- 새 세션의 콘텐츠 버전은 `3.0.0`이다. 예전 세션의 `2.5.0` 질문·결과는 읽을 수 있도록 별도로 유지했다.
- 한 번에 답하는 길이는 6문항 그대로다. 후보 풀은 단계마다 4개, 총 24개이며 각 문항에는 4개의 서로 고를 만한 보기가 있다. 학교나 특정 직업을 전제하지 않는다.
- 질문의 답을 직업으로 직결하지 않고 `살핀다·함께한다·쉰다·탐색한다·고친다·말한다·지킨다·놓아준다`의 행동 신호로 읽는다. 결과 후보 중 답과 가까운 이야기를 결정론적으로 고르고, 실제 선택한 신호에 맞는 별도 장면을 넣는다.
- 결과는 사람의 삶 11편과 드문 특별 결과 1편으로 구성한다. 광대·여관 주인·서기관·탐정·밤길 안내자·거울 수선공·약초지기·용의 꿈 기록자·우주선 통신 기록관·그늘 천막 배달자·바다 길잡이, 그리고 해안가 바위다. 사실에 기초한 역사 해설로 포장하지 않는다.
- 비인간 결과는 세 신호가 모두 맞고 별도의 안정적인 희소 게이트를 통과할 때에만 나온다. 빈도는 실제 이용자 분포가 아닌 코드의 후보 경로만 검사했다.
- 결과 화면에는 원고의 네 장면이 이어진다. 심화·가이드 해금에는 결과의 다른 면, 남은 질문을 실었다. 독자에게 보이는 이미지에는 새 이야기와 맞지 않는 기존 역사 인물 그림을 재사용하지 않고, 여러 세계로 이어지는 책의 공통 배경을 쓴다.

## 자체 감수와 남은 검증

질문 24개·결과 12편에 대해 쉬운 말, 사건의 의외성, 선택의 장면 반영, 인물의 대가, 현재를 단정하지 않는 여운을 점검했다. 1,024개 가상 응답 경로에서 사람 이야기 11편 모두 도달하고 특별 결과가 드물게 나오는지를 자동 검사한다. 기존 세션과 새 세션의 API 전체 흐름을 각각 검사한다. 이는 **개발 검증과 AI 자체 검수**이지 실제 독자의 만족도 검증은 아니다.

추후 실제 독자에게 읽힐 때에는 특히 심화 결과의 길이, 질문 반복감, 7번 방의 천식 설정, 약초지기의 오해 장면, 중립 배경의 시각적 몰입을 관찰해야 한다. 운영 배포용 `scripts/staging-env.mjs`는 이전 출시 버전 `2.5.0`을 고정하고 있으므로 이번 로컬 콘텐츠 전환을 배포 승인으로 해석하지 않는다.

## 실제 화면에서 발견해 고친 점

로컬 모바일 웹에서 새 여정을 직접 진행하자 첫 질문이 표시되지 않았다. 서버 응답은 정상인 4개 보기였으나 모바일의 응답 계약은 이전 버전의 6개만 허용하고 있었다. 계약을 두 버전 모두 허용하도록 바꾸고, API 전체 흐름 검사에서 같은 계약으로 새 질문을 파싱하도록 추가했다.

또 결과 화면에서는 단순 종이 질감만 쓰면 몰입감이 떨어지고, 첫 장에서 같은 문장이 반복되며, 선택과 여운에 채점 설명 같은 문구가 보였다. 공통 배경을 기존의 여러 세계로 이어지는 책 이미지로 바꾸고, 첫 장의 본문을 인물의 하루로 교체했다. 마지막 문장은 선택 해설 대신 이야기 안에서 남은 감각과 질문으로 고쳤다. 짧은 끝 문장만 별도 페이지에 떨어지는 읽기 방식도 조정했다. 광대 결과로 6문항과 4장 화면을 다시 확인했다.

## 2차 원고 감수 — 2026-10-21

아래는 **AI가 독자 입장에서 읽은 자체 검토**다. 실제 이용자의 평가나 선호도로 해석하지 않는다. 각 원고의 첫 문장부터 사건, 선택 장면, 대가, 마지막 문장까지 화면에 나오는 순서로 읽고, 세 신호별 삽입 문장이 본문 행동과 충돌하는지 살폈다.

모든 결과가 같은 일반적인 채점 여운으로 끝나는 문제를 줄이기 위해, 결과별 `presentEcho`를 따로 썼다. 선택 신호는 이야기 속 행동 한 장면에 반영하고, 마지막은 그 이야기만의 양면적인 마음과 독자 질문으로 연결한다. 현재의 몸·성격·경험이 실제 전생 때문에 생겼다고 말하지 않는다.

고정된 규칙으로 만든 1,024개 **가상 답변 경로**에서는 사람 이야기 11편 모두 나왔고, 각 편 빈도는 42~150회였다. 바위는 2회였다. 이는 질문 후보와 선택 생성 방식에 따른 개발용 분포일 뿐, 실제 독자에게서 같은 비율이 나온다는 뜻은 아니다. 이야기를 강제로 균등 배분하면 선택과 결과의 연결이 약해질 수 있어 이번 감수에서는 채점 가중치를 바꾸지 않았다. 실제로 특정 이야기가 지나치게 반복되는지는 이후 이용 경로에서 별도로 확인해야 한다.
