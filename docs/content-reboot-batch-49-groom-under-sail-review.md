# 89번째 원고·그림 검수 — 돛 아래 잠든 신랑

## 역사 조건과 창작 범위

- 1472년 말레이반도 믈라카 항구는 믈라카 술탄국의 국제 교역항이었다. 항구의 교역과 15세기 말레이 손북 문화의 존재는 [말레이시아 문화유산청](https://www.heritage.gov.my/en/iii-sejarah-melayu.html), [믈라카 주 정부](https://melaka.gov.my/kerajaan/info-negeri/sejarah.html?highlight=WyJkaSIsMTUxMV0%3D), [말레이시아 문화예술 기관](https://pemetaanbudaya.jkkn.gov.my/en/senibudaya/detail/863), [유네스코 실크로드 자료](https://en.unesco.org/silkroad/sites/default/files/knowledge-bank-article/foreign_documents_and_the_descriptions_of_melaka_between_a.d._1505-1511_0.pdf)를 근거로 확인했다. 2026-10-23 확인.
- 하피즈와 살마·자녀·파리스·나디라, 특정 배·혼례 행렬·대화와 품삯은 모두 창작이다. 그림의 배와 복식은 이 시대 항구를 바탕으로 한 시각적 재구성이며 특정 실존 배·개인의 복원도가 아니다. 포르투갈 식민지 시대 건물·도구는 넣지 않았다.

## 원고 자체 검수

- **01:** 1430~1502년 항구 출생과 아버지의 일, 북을 배운 시기, 살마와 두 자녀, 아내의 병과 사별 뒤 노년까지 세 쪽에 담았다. 한 혼례의 손해로 평생을 정의하지 않는다.
- **02:** 전생록 도입 → 사라진 신랑과 기다리는 신부 → 밤일과 붉은 천 → 배의 돛 아래 잠든 파리스 → 널판에서 파리스를 붙잡느라 젖은 북 → 손뼉 행렬과 깎인 품삯 → 다음 날에도 남은 신부의 화 → 화자의 삶 전체를 짚는 마무리 순서다. `notice`는 단서를 따라가고, `speak`는 짐꾼에게 묻고, `connect`는 아들과 짐꾼에게 역할을 나눈다. 각각 실제 행동이 다르고 모두 북을 잃는 대가로 이어진다. 신부의 기다림을 축제 분위기로 없애지 않았다.
- **03:** 출생·아버지 일·음악·혼인·두 아이·부모의 죽음·딸의 혼인·아들의 독립·손녀·살마의 병과 사별·사망까지 15개 연대기다. 1472년 사건 밖의 삶을 포함한다.
- **04:** 살마는 돌봄을, 카마리아는 아버지가 자기 혼례에서 북을 내려놓은 일을, 이드리스는 늘 북을 지닌 버릇을, 파리스는 대신 사과해 주지 않은 일을 기억한다. 서로 다른 평가가 된다.
- **정합성:** 사건 때 하피즈 42세, 이드리스 12세. 원고와 선행 설정의 생몰·혼인·관계·순서가 맞는다. 유럽 식민지 시대의 악기·건물·제도는 묘사하지 않았다. 쉬운 단어와 구체적 장면으로 자체 문장 검수를 했다. 실제 독자 평가는 아직 없다.

## 연결·검사

- `GROOM_UNDER_SAIL` 카드·원고·API 자산·모바일 정적 자산 매핑이 일치한다. 배경 `melaka-sail-harbor-bg.jpg`는 1254×1254, 인물 `melaka-hafiz.webp`는 1024×1536의 실제 투명 알파(0~254)다.
- `corepack pnpm typecheck`, `corepack pnpm content:check`, `corepack pnpm test`, `corepack pnpm test:e2e` 통과. 고유한 배경·인물 89쌍과 다양성 검사가 통과했다.
- `e2e/mobile-groom-under-sail.spec.ts`에서 질문→결과, 320×720과 768×1024의 01 세 쪽, 02·03·04 마지막 부분, 그림 로드·원본 폭, 가로 넘침과 인용문/양피지 간격을 확인했다. 두 화면의 합성 스크린샷을 직접 확인했다. 실제 단말기와 실독자 반응, 역사 건축·복식의 세부 복원까지는 검증하지 못했다.

검증을 통과한 89번째 라이브 편. 기존 44편 01·03 전수 보강은 별도 작업으로 남아 있다. 커밋·푸시·배포 없음.
