# 116번째 「당나귀가 돌아간 골목」 검수

- **완료:** 2026-10-23. 착수 때 실제 `storyCards`·원고·그림 매핑 115쌍을 다시 세었다. 직전 베를린 제빵사와 시대·지역·직업·정서가 다르며 1722년 베네치아 뱃사공, 16세기 수로 석공과도 사건이 겹치지 않는다. 신규 등록 뒤 116편과 배경/인물 116쌍을 확인했다.
- **선행 설정:** [설정 대장](story-setting-register.md)에 1870년 알라위 왕조 술탄 무함마드 4세가 다스리던 모로코 페스, 유수프의 창작한 1837~1908년 생애, 가족·옛 스승·일의 변화와 당나귀가 돌아간 하루를 집필 전에 확정했다.
- **역사와 창작:** [모로코 외교부 역사](https://uk.diplomatie.ma/en/history), [UNESCO 페스 메디나](https://whc.unesco.org/en/list/170/), [UNESCO 페스 영상 자료](https://whc.unesco.org/fr/documents/6445)를 2026-10-23 확인했다. 당시 정치권, 오래된 좁은 도시 길과 짐 운반을 역사 배경으로 삼았다. 유수프·가족·사디크·당나귀 하림·고객, 골목 배치·대화·배달 사건은 창작이다. 당나귀가 사람의 이사를 초자연적으로 알았다고 설명하지 않는다.
- **원고 검수:** 01 세 쪽은 생몰·일·생활, 성격·취향·가족·스승·바람·걱정을 짧게 보여 준다. 삶 한 줄은 어릴 때의 빨래 운반, 짐꾼이 된 청년기, 두 아이와 아내, 자녀들의 다른 길, 무릎이 아픈 노년과 손자까지 이어지고 02의 결론을 앞세우지 않는다. 02에는 전생록 화자의 도입·마무리와 붉은 천·거듭 꺾는 당나귀·낡은 대문의 흠집·옆집 이웃·늦은 배달·아내와의 대화가 있다. 선택의 대가는 다음 일감과 뒤늦게 안부를 묻는 부끄러움이며 재회는 확정하지 않는다. 03은 출생부터 1908년 사망까지 사건 밖 가족·건강 변화를 포함한다. 04는 오래 한 일·남긴 말과 아내·딸·아들·스승의 서로 다른 평가다. 1870년 33세, 1908년 71세와 가족 관계를 대조했다.
- **그림:** 사람 없는 1254×1254px 창작 페스 골목·당나귀·붉은 천과 별도 1024×1536px 투명 유수프를 제작했다. API·모바일에서 고유 경로를 연결했고, 만화식 외곽선 없는 사실적 화풍·알파 범위 0~254를 확인했다. 특정 실존 골목이나 1870년 건물의 정밀 복제는 아니다.
- **검증:** `pnpm typecheck`, `pnpm content:check`, `pnpm test`, `pnpm test:e2e` 통과. 점수 경로 테스트가 4개 보기만 샘플링해 116편 등록 후 기존 한 편의 도달성을 놓친 것을 발견했다. 현재의 6개 보기 전체에서 2048개 경로를 확인하도록 바로잡은 뒤 116편의 도달성과 희귀 결과 비율을 통과했다. 첫 브라우저 검사에서는 API의 80자 인물 소개 제한을 넘어 실패해 소개를 줄였다. 재검사에서 질문당 보기 6개, 첫 질문 여섯째·둘째 질문 다섯째 선택, 01 세 쪽과 02~04 도달성, 320×720px·768×1024px 이미지 로드·가로 넘침을 확인하고 두 폭의 실제 화면을 육안 확인했다. 그림 도달성 검사는 116쌍+오류 배경 1개, 총 233개 모바일 자산을 확인했다.
- **한계:** 320px 첫 화면에서는 프로필 카드가 인물 몸 대부분을 가린다. 내용·페이지 이동은 가능하다. 실제 독자·실기기, 1870년 페스의 정확한 골목·복식·운송 관례, 기존 44편의 01·03 전수 점검은 미검증이다. 커밋·푸시·배포 없음.
