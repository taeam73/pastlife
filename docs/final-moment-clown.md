# `CLOWN` 루보 마지막 순간 검수 기록

**2026-10-24 재작업 판정:** 아래는 생애 보강 전의 기술·웹 화면 검사 기록이다. 새 01·03·04에서는 44세 나미의 무대에 끼어든 일과 49세 피노의 떠남이 서로 다른 관계의 비용으로 남는다. 55세 이후 루보는 젊은 배우를 지도하지 않고 발목 통증 때문에 무대에서 내려와 소품을 고친다. 아래의 61세 큰 신발·나무 자·제자에게 바느질을 가르치는 임종 장면과 삽화는 새 생애와 맞지 않아 **원고·삽화 모두 재작업 대상**이다. 아래 과거 웹·PDF 검사는 새 편집 기준의 승인이나 현 버전의 결과 품질 증거로 세지 않는다.

검수일: 2026-10-24 (KST)

- 기존 01·03·04 기준: 에르단 세계 장터력 142~203년, 남성 루보, 남부 바람골 장터. 수레 제작자의 집에서 자라 광대가 되었고 피노와 공연했다. 49세 이후 피노와 편지를 주고받았으며 55세부터 발목이 아파 젊은 배우의 연습을 지도했고 61세 바람골에서 삶을 마쳤다. 큰 신발과 아버지의 짧은 나무 자를 아꼈다.
- 새 장면: 203년 장터 무대 뒤에서 루보가 제자의 신발 수선을 지켜본다. 피노에게 답하지 못한 편지와 아직 보고 싶은 공연을 생각하다 무대의 발소리를 듣는다. 사망 원인이나 피노·아버지의 사망 여부는 새로 단정하지 않는다. 제자 성별도 지정하지 않았다.
- 02와 구분: 피노의 첫 단독 공연을 루보가 객석에서 본 봄 장터 사건을 다시 쓰지 않는다. 큰 신발을 평생 이어진 소품으로만 사용한다. 제자가 의자를 객석으로 돌리고 신발을 다시 신는 장면은 창작한 사후 반응이다.
- 창작·사실 구분: 에르단 세계, 장터력, 바람골, 인물과 사건은 기존 작품의 허구 설정이다. 실존 역사나 확인된 사망 장면으로 설명하지 않는다.
- 전용 그림: 기존 바람골 장터 배경과 새로 교체한 남성 루보 그림을 참조했다. 첫 시안의 얼굴이 61세보다 젊어 보여 회색 머리·주름·손을 보정한 두 번째 그림을 사용했다. 최종 `clown-final-moment.jpg`는 1536×1024, 354,575바이트다. 자주·남색·황토색 누빔옷, 큰 신발, 짧은 나무 자, 제자, 장막과 빈 객석을 눈으로 확인했다.
- 자동 검사: `final-moment:check` 4/120, 120쌍 기본 그림 검사, content/mobile 타입, 콘텐츠 검사와 API E2E 2건 통과. 출시 이미지 검사기가 마지막 삽화를 기본 배경·인물 쌍으로 잘못 계산하던 점을 분리해 전체 `content:check`도 재통과했다.
- 실제 웹 여정: 인메모리 3.0 API의 여섯 답변으로 237번째 시도에서 루보 결과를 선택했다. 320px에서 저장·공유 잠금 → 두 번째 테스트 광고 → 마지막 순간 읽기 → API `finalMomentRead=true` → 저장·공유 해제를 확인했다. 768px에서도 삽화·본문·끝 영역 도달과 가로 넘침 없음(`document=viewport=768`)을 확인했다. 두 크기 모두 브라우저 오류가 없었다.
- 파일 검사: 실제 앱 버튼으로 공유 PNG 1080×1800과 PDF를 내려받았다. 첫 PDF의 마지막 쪽이 문단 중간에서 시작해 작성기를 수정했다. **최종 재검사 PDF는 9쪽, 1,814,052바이트**이며 별도 `전생록의 기록` 마지막 쪽을 렌더링해 맺음말 전체가 처음부터 읽히는지 확인했다. PDF는 이미지형이라 글자 검색·복사가 안 된다. 산출물은 `output/pdf/full-final-clown-*`, `output/playwright/full-final-clown-*`에 있다.
- 남은 한계: 운영 광고, 네이티브 파일 처리와 운영 DB 검사는 아직 하지 않았다. 전체 경험 완료 편수는 0/120이다.
