# 88번째 원고·그림 검수 — 바퀴 달린 집

## 역사 조건과 창작 범위

- 1960년 4월 브라질 합중국 연방구 브라질리아. 수도 개장일은 4월 21일이다. 노동자 마을의 목조 거주지와 자녀를 위한 학교가 있었다. [연방구 입법의회 마을 기록](https://www.cl.df.gov.br/-/candangolandia-completa-66-anos-com-sessao-solene-da-cldf), [1960년 교육 자료](https://biblioteca.cl.df.gov.br/dspace/bitstream/123456789/440/1/v.%204%20n.%2040%20abr.%201960.pdf), [상원 개장 기록](https://webstories.senado.leg.br/web-stories/a-sessao-de-instalacao-do-congresso-em-brasilia/), [1946년 헌법](https://www.planalto.gov.br/ccivil_03/constituicao/constituicao46.htm). 2026-10-23 확인.
- 마리아 아우베스와 가족·주앙·베라·교장, 학급 전시·그림·대화는 창작이다. 실존 학교의 특정 행사나 교사 기록이라는 주장을 하지 않는다. 배경은 목조 교실·붉은 흙·당시 수도 건축의 모습에 맞췄다.

## 원고 자체 검수

- **01:** 1925~2000년, 아나폴리스에서 자라 교사가 된 시기, 혼인과 딸, 새 수도로의 이주, 남편을 먼저 보내고 손자·이웃과 지낸 노년을 세 쪽에 담았다. 주앙의 하루로 평생을 규정하지 않는다.
- **02:** 전생록 화자의 도입과 마무리 사이에 그림 공개 → 주앙의 이사 계획 → 전시 제목과 충돌 → 제목과 설명 수정 → 딸의 발표를 놓친 대가 → 바로 풀리지 않는 관계를 장면으로 이었다. `notice`는 그림의 화살표를 확인하고, `speak`는 교장에게 먼저 말하며, `connect`는 주앙·동료와 함께 움직이는 서로 다른 실제 행동이다. 세 갈래 모두 리아와의 약속을 놓치는 사실을 지우지 않는다.
- **03:** 출생·동생 돌봄·교육·혼인·딸·이주·수업·남편의 일 변화·딸의 진학·남편의 사망·손자·노년·사망까지 17개 사건이다. 02 밖의 일생이 더 길다.
- **04:** 리아는 놓친 발표와 다음 발표를 모두 기억하고, 파울루는 가족에게 부족했던 시간을, 주앙은 자기 집을 고치라 하지 않은 일을, 베라는 교실에서의 태도를 기억한다. 모두 같은 칭찬으로 평탄하게 만들지 않았다.
- **정합성:** 사건 당시 마리아 35세, 리아 9세. 설정 대장과 01~04의 이동·관계·생몰 연도가 맞는다. 역사적 사건과 가상 인물을 분리했다. 중학생이 이해할 수 있는 문장과 구체적인 그림·교실 장면으로 읽었다. 실제 독자 검증은 아직 없다.

## 연결·검사

- `storyCards`·원고·API 그림 매핑·모바일 정적 자산이 `HOUSE_WITH_WHEELS`로 연결된다. 고유 배경 `brasilia-school-1960-bg.jpg`는 1254×1254, 인물 `brasilia-maria.webp`는 1024×1536이며 인물 실제 알파 범위는 0~254다.
- `corepack pnpm typecheck`, `corepack pnpm content:check`, `corepack pnpm test`, `corepack pnpm test:e2e` 통과. 처음 콘텐츠 검사는 카드 소개에 `home` 문자열이 없는 문제를 잡았고, 브라질리아를 넣어 다시 통과시켰다.
- `e2e/mobile-house-with-wheels.spec.ts`가 320×720과 768×1024 실제 브라우저 결과에서 질문→결과, 01 세 쪽, 02·03·04의 끝, 이미지 로드·원본 폭, 가로 넘침과 문장/양피지 겹침을 확인했다. 두 화면의 합성 스크린샷을 직접 확인했다. 320px에서 인물과 소개문이 일부 겹치지만 글자가 읽히고 양피지와 인용문은 겹치지 않는다.
- 실제 독자 반응, 물리적 휴대전화 렌더링, 당시 특정 교실의 외관까지 일치하는지는 아직 확인하지 못했다. 기존 44편의 01·03 전수 보강도 남아 있다.
