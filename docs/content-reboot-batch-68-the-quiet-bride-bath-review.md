# 108번째 원고 검수 — 노래를 멈춘 목욕탕

2026-10-23. `THE_QUIET_BRIDE_BATH`는 1718년 오스만 제국 이스탄불을 배경으로 한 창작 인물 제이네프의 이야기다. 집필 전 [설정 대장](story-setting-register.md)에 시대·장소·정치권·생몰·평생·근거를 먼저 확정했다.

## 역사 조건과 창작

- 이스탄불대학교의 [II. 바예지드 하맘 역사](https://turkhamamkulturu.istanbul.edu.tr/tr/content/kurumsal/tarihce), 케임브리지의 [오스만 이스탄불 하맘 사회사](https://www.cambridge.org/core/books/abs/social-history-of-ottoman-istanbul/hamam/4CDFEB0822ACD6AD331DDE2C9A6A18E0), 메트로폴리탄 미술관의 [하맘 문화](https://www.metmuseum.org/ko/essays/baths-and-bathing-culture-in-the-middle-east-the-hammam)와 [18세기 오스만 수건](https://www.metmuseum.org/art/collection/search/450975)을 2026-10-23 확인했다. 하맘의 여성 모임과 혼례 전 목욕, 수건은 시대적 조건이다.
- 제이네프·하산·에다·나지예와 혼례 손님, 소규모 하맘, 신부의 사별과 침묵 요청, 품삯과 대화는 창작이다. 배경 그림은 실제 하맘의 정밀 복원도가 아니며 복식도 특정 유물의 재현으로 주장하지 않는다.

## 원고와 그림

- 01은 비누 장수의 딸에서 하맘 일꾼, 아내·어머니, 사별 이후 동료와의 일, 조카에게 가르치는 노년까지의 생활을 요약한다. 한 사건의 교훈으로 평생을 규정하지 않는다.
- 02는 신부의 고요를 바라는 부탁, 이모의 노래 준비, 제이네프의 선택, 줄어든 품삯과 불완전한 여운을 장면과 대화로 썼다. `notice`·`speak`·`connect`는 서로 다른 행동을 보인다. 03은 1672~1741년의 생애 13지점을, 04는 하산·에다·나지예의 서로 다른 기억을 담았다.
- 고유 1254×1254px 하맘 배경과 투명 인물 그림을 API와 모바일 자산 목록에 연결했다. 인물 PNG 원본을 알파 채널이 있는 WebP로 옮겼다.

## 확인 범위

타입 검사, 콘텐츠·그림·다양성 검사, 단위 검사, API E2E, 질문의 여섯째·다섯째 보기 선택을 포함한 320px·768px 브라우저 결과 검사가 통과했다. 모바일의 세 소개 페이지와 태블릿 결과 화면을 직접 확인했다. 실제 독자 반응, 물리적 기기, 복식·건축의 정밀 고증은 미검증이다. 기존 44편의 01·03 전수 점검도 별도 과제다.
