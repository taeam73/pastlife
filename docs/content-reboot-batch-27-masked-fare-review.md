# 67번째 「가면 쓴 손님」 원고·그림 검수

2026-10-23. 작업 전 실제 카드·원고·그림 매핑은 66쌍, 마지막 ID는 EMPTY_PHOTO_SEAT였다. 이 편의 설정과 원고·그림을 분리해 작성한 뒤 중복 없이 67번째로 연결했다.

## 실제 시대와 창작의 경계

- 배경은 **1722년 베네치아 공화국의 베네치아 카니발**이다. 메트로폴리탄 미술관의 1722년 산마르코 광장 판화에는 가면·가판·무대·행렬이 보인다. 같은 미술관의 자료로 18세기 베네치아 공화국, 바우타 가면, 당시 곤돌라의 형태를 확인했다. 베네치아 시 공식 안내로 오래된 리알토 시장의 위치와 채소·과일 거래도 확인했다. 각 근거와 확인일은 [선행 설정 대장](story-setting-register.md)의 MASKED_FARE 항목에 기록했다.
- 마테오·루치아·로사·카를로·안젤로와 상인, 뱃삯·화물 운항·가면 쓴 손님 사건은 창작이다. 특정 실존 축제 하루나 인물의 일화를 재현하지 않는다. 곤돌라 그림에 오늘날 뱃머리 장식을 필수 역사 사실인 것처럼 묘사하지 않았다.
- 원고보다 먼저 아버지에게 배운 일, 어머니의 죽음, 혼인과 두 아이, 배 수리 빚, 루치아의 채소 좌판, 자녀들의 다른 진로, 손목 통증과 노년 일을 평생으로 확정했다. 02는 그중 부부가 약속한 카니발 오후 하나만 고른다.

## 01~04 원고 점검

- **01 전생의 나:** 세 쪽에 정체와 평생 흐름, 성격·취향·잘하는 일, 물건·관계·바람·걱정을 나눴다. 한 줄 삶은 아버지의 배부터 가족·빚·배 인계·시장 일까지 담고, 카니발의 교훈으로 인생을 규정하지 않는다.
- **02 에피소드:** 카니발의 익명성과 약속이 두 겹인 뱃사공의 현실을 충돌시킨다. 손님으로 나타난 루치아의 바구니 매듭을 알아봄 → 상인의 예약도 도착 → 안젤로에게 화물을 부탁하고 자기 몫으로 비용 지불 → 부부가 미뤄 온 말을 함 → 아이들이 합류 → 상인의 일감이 잠시 안젤로에게 넘어간다. 세 답변 갈래는 각각 관찰 후 행동, 동료와 협의, 상인에게 직접 설명하는 선택이다. 한 오후가 이전의 미뤄 온 약속을 지우지는 않는다.
- **03 삶의 기록:** 1690~1759년 출생부터 사망까지 17건. 02 밖의 부모·부부·자녀·동료·빚·건강·일 인계를 시간순으로 담고 연도와 나이를 대조했다.
- **04 전생의 기억:** 오래된 노, 물길과 일의 어려움, 남긴 말과 아내·딸·아들·동료의 서로 다른 평가를 담았다. 평생을 한 번의 나들이로 환원하지 않는다.
- 중학생이 바로 볼 수 있는 바구니 매듭·짐 상자·두 배·뱃삯으로 갈등을 풀었다. 01~04의 생몰·나이·가족 이름·선택·손해를 자체 대조했다.

## 그림·앱 검증

- 별도 고유 배경은 **1280×1280 JPEG**, 베네치아의 축제 물가와 당시 형태를 참고한 곤돌라. 별도 인물은 **1024×1536 WebP, 실제 알파 채널**, 32세 일꾼 복장의 마테오다. 배경과 인물을 API 및 Expo 정적 매핑에 연결했다. 그림은 분위기용 창작 이미지이며 건축물의 배치를 정밀 역사 지도로 보장하지 않는다.
- content·api·mobile 타입 검사, 그림 67쌍 검사, 다양성 검사, 관련 Vitest 27개, API E2E 2개 통과.
- 첫 브라우저 검사는 결과 계약의 상단 문구 80자 제한을 발견해 평생 요약문을 줄인 뒤 재실행했다. Playwright 결과 화면 **320×720**과 **768×1024**에서 배경·인물 자연 폭 1024px 이상, 01 세 쪽 이동, 가로 넘침 없음, 소개문과 양피지의 수직 분리, 02~04 후반 문구 도달성을 확인했다. 두 크기의 첫 화면 이미지도 직접 봤다. 휴대전화에서는 인물의 일부가 상단 소개문 뒤에 오지만 얼굴과 글자를 알아볼 수 있다.

실제 독자 반응, 실기기 성능, 배포 환경은 미검증이다. 기존 44편의 01·03 전수 보강도 여전히 별도 작업이다.
