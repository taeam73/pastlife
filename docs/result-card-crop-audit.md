# 결과 카드 120편 크롭 자산 점검

검사일: 2026-10-24. 이 문서는 3.0 결과 화면의 **01~04 작은 카드**에 같은 배경을 서로 다른 초점·배율로 표시하는 자산 수준 검사다. 표지와 본문 전체, 실제 휴대폰 화면 검사는 별도다.

## 방법과 결과

- `node scripts/check-story-art.mjs`: 배경·투명 인물 120쌍과 모바일 매핑 통과.
- `scripts/audit-story-crops.py`: API 기본 크롭 네 값 `(0.38, 0.50, 1.18)`, `(0.63, 0.42, 1.27)`, `(0.44, 0.64, 1.32)`, `(0.65, 0.60, 1.20)`을 적용했다. 320px 결과 카드와 같은 64:93 비율로 120편 × 4장 = 480장 미리보기를 만들었다.
- `output/crop-audit/contact-01.jpg`~`contact-06.jpg`의 120행을 눈으로 확인했다. 빈 카드, 배경이 빠진 카드, 눈에 띄는 검은 여백은 보이지 않았다. 일부 장면은 카드마다 중심 사물이 달라지지만, 같은 배경의 다른 부분이라는 관계는 읽힌다.
- 각 편 네 카드의 **모든 여섯 쌍**, 총 720쌍을 16×24 축소 RGB 평균 차이로 비교했다. 5 미만인 근접 동일 쌍은 **0쌍**이었다. 최솟값은 `TASTER` 03–04 카드의 11.35다. 이 편은 접촉 시트 다섯째 장에서 그릇·식탁과 뒤쪽 실내의 시점 차이를 눈으로 확인했다.
- 검사 기록은 `output/crop-audit/metrics.json`에 있다. 이 출력은 작업 산출물이며 Git 추적 대상이 아니다.

## 완료로 세지 않는 범위

이 검사는 이미지 매핑과 수학적 크롭 미리보기만 재현한다. 실제 320px·태블릿 브라우저에서 **각 120편**의 결과 카드, 표지의 인물 합성, 01~04 본문과 텍스트 대비·가로 넘침을 검증한 것이 아니다. Android/iOS 실제 기기의 자산 로딩·크롭도 아직 확인되지 않았다. 따라서 이번 결과로 `120/120` 화면 검증이나 3.0 전 여정 완료 수를 올리지 않는다.

재실행: `python scripts/audit-story-crops.py` (Pillow 필요).
